0.4.2 只修了 Windows 一个问题，其他平台和 0.4.1 相同。HD 包没有变化，仍是 HD 1.0，已经装了的不用重新下载。

## 本版更新

- **Windows：修复程序一打开就退出。** 0.4.0 和 0.4.1 在 Windows 上无论双击 `Marchwind64.exe` 还是运行 `Marchwind64.cmd`，窗口都一闪就关，也不留任何日志。原因是程序启动第一步设置输出缓冲时用了 Windows C 运行库不接受的参数，进程在还没写日志之前就被系统结束了。现已修复，并在 Windows 11 上验证过；以后每次构建都会先在 Windows 上实际启动一次程序再打包。
- 0.4.1 说的「双击 `Marchwind64.exe` 开始游戏」从这一版起才真正可用。

感谢反馈 Windows 打不开的玩家。如果还有问题，请到 [GitHub Issues](https://github.com/dyzz/srw64-recomp/issues) 反馈，游戏里「选项 → 反馈」可以复制平台信息、导出问题报告。
