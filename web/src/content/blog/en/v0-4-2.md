0.4.2 fixes one problem, on Windows; the other platforms are the same as 0.4.1. The HD pack has not changed and is still HD 1.0; if you have it installed, there is nothing to download again.

## What's new

- **Windows: the program no longer closes as soon as it opens.** In 0.4.0 and 0.4.1, whether you double-clicked `Marchwind64.exe` or ran `Marchwind64.cmd`, the window flashed and closed, leaving no log. The very first thing the program does, setting up its output buffering, passed a value the Windows C runtime does not accept, and the system ended the process before anything was logged. This is fixed and checked on Windows 11, and every build now starts the program on Windows once before it is packaged.
- Double-clicking `Marchwind64.exe` to start the game, announced in 0.4.1, works from this version on.

Thanks to everyone who reported that Windows would not start. If you still have trouble, please open an issue on [GitHub](https://github.com/dyzz/srw64-recomp/issues); in the game, Options → Report copies your platform info and exports a problem report.

Download from the [Install](/en/install/) page or from [GitHub](https://github.com/dyzz/srw64-recomp/releases/tag/v0.4.2). On Windows, unzip over the old folder; your saves are in the user directory and are not touched.
