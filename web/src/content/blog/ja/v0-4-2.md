0.4.2 は Windows の問題をひとつ修正したバージョンで、ほかのプラットフォームは 0.4.1 と同じです。HD パックは変わらず HD 1.0 のままなので、導入済みの方は再ダウンロード不要です。

## 更新内容

- **Windows：起動直後に終了する問題を修正しました。** 0.4.0 と 0.4.1 では、`Marchwind64.exe` をダブルクリックしても `Marchwind64.cmd` を実行しても、ウィンドウが一瞬開いて閉じ、ログも残りませんでした。起動直後の出力バッファの設定で Windows の C ランタイムが受け付けない値を渡していたため、ログを書く前にプロセスが終了していました。修正後、Windows 11 で動作を確認しています。今後はビルドのたびに、パッケージ前に Windows で実際に一度起動して確かめます。
- 0.4.1 で案内した「`Marchwind64.exe` のダブルクリックで起動」は、このバージョンから実際に使えます。

Windows で起動しないと報告してくださった皆さん、ありがとうございました。まだ問題がある場合は [GitHub Issues](https://github.com/dyzz/srw64-recomp/issues) にお寄せください。ゲーム内の「オプション → 報告」で環境情報のコピーと不具合レポートの書き出しができます。
