这类 MOD 只改游戏里**显示**的名字和头像：对白、说话人、状态页、战前确认、图鉴、地图标签都会跟着变。存档里存的还是原版名字，停用包就回到原来的样子，存档拿给别人或原版游戏也照常能读。

包的安装和管理见 [MOD 包：安装与制作](../mods/)。需要 0.5.2 或更新的版本。

## 包里放什么

```text
yourname.heroes/
  mod.json
  dialogue/names.json          名字
  art/portraits/133.png        头像，文件名是人物号
```

两样可以只放一样。

## 名字（dialogue/names.json）

```json
{
  "schema": "srw64.mod-names.v1",
  "heroes": {
    "super-male": {
      "hero":    { "zh-Hans": { "name": "拓真", "surname": "天野", "nickname": "拓真" },
                   "en": { "name": "Takuma", "surname": "Amano" } },
      "partner": { "zh-Hans": { "name": "湊", "surname": "北条" } }
    }
  },
  "unit": { "zh-Hans": "晓风", "en": "Daybreak" },
  "pilots":  { "133": { "zh-Hans": { "name": "真吾", "full": "北条真吾" } } },
  "units":   { "184": { "zh-Hans": "豪将军改" } },
  "weapons": { "731": { "zh-Hans": "超级火箭筒" } }
}
```

每一项都按语言写：`zh-Hans`（简体中文）、`zh-Hant`（繁体中文，没写时用简体那份）、`en`、`ja`。没写的语言照旧显示原来的名字。几个包改了同一个名字时，MOD 管理列表上面的包优先。

### 原创主角、搭档和部队名（heroes、unit）

- `heroes` 按四条路线写：`super-male`（超级系男）、`super-female`（超级系女）、`real-male`（真实系男）、`real-female`（真实系女），每条有 `hero`（主角）和 `partner`（搭档）。
- 每种语言写 `name`（名字，必填）、`surname`（姓氏）、`nickname`（昵称，没写就用名字）。全名按语言自动拼，中文用「·」，英文用空格，日文用「・」。
- 台词里提到主角的地方原版就是按名字填进去的，所以台词会跟着变。
- 改了部队名时，起名那一场剧情会改走「我不喜欢」那条分支：主角嫌「三月风」不合适，自己提出包里的名字。这一场已经演过的话不会重演。

### 其他人物、机体、武器（pilots、units、weapons）

- 按编号写，编号查 [ID 表](/zh/mods/ids/)。人物写 `name`（简称，必填）和 `full`（全名，没写就用简称）；机体和武器直接写名字。
- 武器菜单里的「格」「射」和 P、B、MAP 标记会自动加上。
- 改的是名字本身，所以说话人、状态页、地图上都会变；**台词正文里提到这个名字的地方不会变**。

### 长度

名字不写存档，所以不受原版格数限制，但有的地方很挤：地图标签、战斗画面的名字条宽度是固定的。

- 主角的名字、姓氏、昵称超过原版格数（名字和姓氏 7 格、昵称 5 格），或比现有最长的译名还宽，部队名超过 10 格，日志里会有一行 `SRW64_MOD_NAMES_WARNING` 提醒，名字照样会用。昵称用得最多，最好控制在 5 格左右。
- 硬上限：主角的名字、姓氏、昵称 16 个字符，部队名和其他名字 24 个字符。超过、写错字段或语言，**整份文件都不用**，日志写 `SRW64_MOD_NAMES_PROBLEM`。
- 名字里不能有换行、全角空格和 `< > { }`，首尾不能有空格。

日文配合原版画面（图片设为原版）时，原版界面用游戏自带的字模画字，画不出包里的名字；这时这几个名字改用本移植版自己的字体画，旁边的文字还是原版字模。

## 头像（art/portraits）

- 文件名是**人物号**加 `.png`，例如 `art/portraits/133.png`。
- 正方形，边长 96 到 2048 像素，必须是 96 的倍数（96、192、384、768……）。可以带透明通道，透明的地方露出后面的画面。
- 对白、战斗、状态页、战前确认、图鉴都用这张。不论图片设为原版还是 HD 都显示 MOD 的头像。
- 几个人物用的是同一张原版头像时（例如同一个人的不同编号），换一个就会都换掉。
- 文件名不是有头像的人物号、尺寸不对，日志里有 `SRW64_MOD_PORTRAITS_PROBLEM`，这张不用。
