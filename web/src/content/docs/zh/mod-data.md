数值 MOD 改的是机体和驾驶员本身的数值。游戏读到这些数值的地方都会跟着变：实战结算、状态页、图鉴。

**现在能改的只有地形适应**。HP、装甲、武器等别的数值还没开放，放进包里会被忽略。

包的安装和管理见 [MOD 包：安装与制作](../mods/)。需要 0.5.1 或更新的版本。

## 包里放什么

```text
yourname.space/
  mod.json
  data/
    units.json      按机体号改机体
    pilots.json     按人物号改驾驶员
```

两个文件可以只放一个。`mod.json` 的写法和别的包一样。

## 写法

```json
{
  "262": { "terrain": { "space": "A" } },
  "184": { "terrain": { "sea": "A", "land": "B" } }
}
```

- 最外层的键是**编号**：`units.json` 写机体号，`pilots.json` 写人物号，十进制、不补零。编号查 [机体与人物 ID 表](/zh/mods/ids/)。
- `terrain` 里只写要改的地形：`air`（空）、`land`（陆）、`sea`（海）、`space`（宇）。值是 `A`、`B`、`C`、`D` 或 `-`。没写的地形保持原版。
- 几个包改了同一项时，MOD 管理列表上面的包优先。

规则很严：不认识的字段、地形或等级，编号超出范围，都算错，**一个文件有错就整份不用**。游戏日志里会有一行 `SRW64_MOD_DATA_PROBLEM`，写明是哪个包、哪个文件、什么原因。

## 实战里怎么算

机体这一侧的适应，是**机体等级和驾驶员等级相加再分档**：

| 等级 | A | B | C | D | - |
| --- | --- | --- | --- | --- | --- |
| 分数 | 4 | 3 | 2 | 1 | 0 |

| 两者之和 | 8 以上 | 6–7 | 4–5 | 1–3 | 0 |
| --- | --- | --- | --- | --- | --- |
| 实战按 | A（120%） | B（100%） | C（80%） | D（60%） | -（0%） |

攻击方的攻击力和防御方的装甲各乘自己的这个倍率。所以**机体本身已经是 A 时，要改驾驶员才能让实战变成 A**。例如豪将军（184）机体宇宙是 A，真吾（133）是 B，合起来 7，原版在宇宙只按 B 算；把真吾的宇宙改成 A，就是 A。

武器的地形适应只看武器自己，另外再乘一次。武器也有编号，但现在还不能改。

## 什么时候生效

- 装上、启用或停用包后不用重启游戏。
- **读场间存档时**，全部机体和驾驶员都按新数值重建，所以已有的存档读进来就是新数值。
- 其他时候，机体在游戏下次重算它的能力时更新（改造、换乘、装卸部件等），驾驶员在升级时更新。关卡里中途启停包，要等这些时机才变，最好在关卡外操作。
- 图鉴也显示改过的数值。

## 共用能力记录

有些人物共用同一条能力记录，多是同一个人物的另一份编号（例如多蒙的 4、273、274）。改其中一个，共用的人一起变。ID 表的「共用能力记录」一栏列出了这些人。

表里同名的条目是不同的编号，可能是变形形态、敌方版本或剧情专用的那一份，改之前对一下原来的等级。

## 示例

[`space-a`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/space-a) 把我方主力里宇宙不到 A 的 20 名驾驶员和 21 台机体的宇宙改成 A：魔神系、孔巴特拉V、盖塔3、豪将军、大铁人、丹拜因系、钢加农、钢坦克等。

### 交给 AI 做

仓库的 [`docs/guide/data-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/data-mods) 文件夹里有格式说明和 CSV 版的机体表、人物表，可以整个交给 AI 助手，让它按你的要求写 `units.json` 和 `pilots.json`。
