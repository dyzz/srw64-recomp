数值 MOD 改的是机体、驾驶员和武器本身的数值。游戏读到这些数值的地方都会跟着变：实战结算、状态页、图鉴。

不想手写可以用 [数值 MOD 制作工具](/zh/mods/data/)：在网页上挑机体、人物、武器改数值，直接导出 .srw64mod。编号查 [机体](/zh/mods/ids/units/)、[人物](/zh/mods/ids/pilots/)、[武器](/zh/mods/ids/weapons/) ID 表。

包的安装和管理见 [MOD 包：安装与制作](../mods/)。地形适应 0.5.1 起就能用，其余字段需要 0.5.2 或更新的版本。

## 包里放什么

```text
yourname.balance/
  mod.json
  data/
    units.json      按机体号改机体
    pilots.json     按人物号改驾驶员
    weapons.json    按武器号改武器
```

三个文件放哪几个都行。`mod.json` 的写法和别的包一样。

## 写法

```json
{
  "184": { "hp": 5200, "armor": 1300, "terrain": { "sea": "A" } },
  "262": { "terrain": { "space": "A" }, "abilities": ["i_field"] }
}
```

- 最外层的键是**编号**，十进制、不补零：`units.json` 写机体号，`pilots.json` 写人物号，`weapons.json` 写武器号。编号和原版数值查 [ID 表](/zh/mods/ids/)。
- 每个编号下只写要改的字段，没写的保持原版。
- 几个包改了同一项时，MOD 管理列表上面的包优先。

规则很严：不认识的字段、超出范围的值、编号超出范围，都算错，**一个文件有错就整份不用**。游戏日志里会有一行 `SRW64_MOD_DATA_PROBLEM`，写明是哪个包、哪个文件、什么原因。

### 机体（units.json）

| 字段 | 含义 | 范围 |
| --- | --- | --- |
| `hp`、`en` | 最大 HP、EN | HP 1–65535，EN 0–65535 |
| `move` | 移动力 | 1–30 |
| `mobility`、`armor`、`limit` | 运动性、装甲、限界 | 0–65535 |
| `repair_cost` | 修理费 | 0–65535 |
| `upgrade_cap` | 改造上限 | 0–15 |
| `terrain` | 地形适应，见下 | |
| `size` | 尺寸 | `SS`、`S`、`M`、`L`、`LL` |
| `shield`、`sword` | 有没有盾、剑（盾防、切落用） | `true` 或 `false` |
| `parts_slots` | 强化部件槽数 | 0–4 |
| `abilities` | 特殊能力，**写全**：数组里没有的就去掉 | 见下表 |

特殊能力的键：

| 键 | 能力 | 键 | 能力 |
| --- | --- | --- | --- |
| `beam_coat` | 光束涂层 | `mach_special` | 马赫特技 |
| `i_field` | I 力场 | `true_mach_special` | 真·马赫特技 |
| `planet_defensor` | 行星防御器 | `god_shadow` | 神之影 |
| `aura_barrier` | 奥拉屏障 | `getter_vision` | 盖塔幻影 |
| `afterimage` | 分身 | `shungensoku` | 瞬幻足 |
| `hyper_jammer` | 超级干扰器 | `hp_regen_10`、`hp_regen_20` | HP 回复 10%、20% |

变形、合体、分离不能用 MOD 加减，它们要有对应的形态数据，原版有的照样保留。

### 驾驶员（pilots.json）

| 字段 | 含义 | 范围 |
| --- | --- | --- |
| `melee`、`ranged`、`evade`、`hit`、`reaction`、`skill` | 格斗、射击、回避、命中、反应、技量（1 级时的值） | 0–255 |
| `sp` | 1 级时的 SP 上限 | 0–255 |
| `double_move` | 到这个等级起可以再动 | 0–99 |
| `terrain` | 地形适应，见下 | |
| `skills` | 技能，见下 | |
| `spirits` | 精神，见下 | |

能力值写的是 1 级时的值，之后每升一级照原版成长（格斗、射击、反应、技量 +1，回避、命中 +2，SP +2）。

**技能**写成「技能键: 习得等级的数组」，第 N 个数是学会 LN 的等级，最多 9 个，从小到大；写 `null` 去掉这个技能：

```json
{ "133": { "skills": { "newtype": [1, 4, 8, 12, 18, 24, 30, 38, 45], "parry": null } } }
```

| 键 | 技能 | 键 | 技能 |
| --- | --- | --- | --- |
| `newtype` | NT | `esp` | 超能力 |
| `enhanced` | 强化人 | `potential` | 底力 |
| `holy_warrior` | 圣战士 | `parry` | 切落 |
|  |  | `shield_defense` | 盾防 |

NT、强化人、圣战士、超能力、底力在原版里用的是同一行等级表，一个人只能有其中一个；写了新的就替换掉原来的那个。没写的技能保持原版。

**精神**写全：最多 6 项，每项 `[精神键, 习得等级]`，等级从小到大：

```json
{ "133": { "spirits": [["focus", 1], ["guts", 5], ["valor", 12], ["soul", 40]] } }
```

精神键：`self_destruct` 自爆、`scout` 侦察、`accel` 加速、`mercy` 手下留情、`focus` 集中、`alert` 必闪、`guts` 毅力、`strike` 必中、`trust` 信赖、`wall` 铁壁、`cover` 替身、`valor` 热血、`spirit` 气合、`great_guts` 大毅力、`luck` 幸运、`drain` 脱力、`effort` 努力、`soul` 魂、`stealth` 隐身、`awaken` 觉醒、`refuel` 补给、`provoke` 挑衅、`encourage` 激励、`disrupt` 扰乱、`friendship` 友情、`love` 爱、`reactivate` 再动、`miracle` 奇迹、`prayer` 祈祷、`revive` 复活。

### 武器（weapons.json）

| 字段 | 含义 | 范围 |
| --- | --- | --- |
| `power` | 威力（改造前） | 0–25500，100 的倍数 |
| `range_min`、`range_max` | 最小、最大射程 | 最小 0–30，最大 1–30，最小不能大于最大 |
| `hit` | 命中修正 | -128–127 |
| `critical` | 暴击修正 | -128–127 |
| `ammo` | 弹数，`-1` 表示不用弹数 | -1–99 |
| `en` | 消耗 EN | 0–255 |
| `morale` | 需要气力 | 0–255 |
| `terrain` | 武器自己的地形适应 | |

改造照原版加威力。**同一件武器挂在好几台机体上时，改它会让这些机体一起变**，ID 表的「带它的机体」一栏列出了这些机体。

### 地形适应（terrain）

`terrain` 里只写要改的地形：`air`（空）、`land`（陆）、`sea`（海）、`space`（宇）。值是 `A`、`B`、`C`、`D` 或 `-`，没写的地形保持原版。机体、驾驶员、武器都用这个写法。

## 实战里怎么算地形

机体这一侧的适应，是**机体等级和驾驶员等级相加再分档**：

| 等级 | A | B | C | D | - |
| --- | --- | --- | --- | --- | --- |
| 分数 | 4 | 3 | 2 | 1 | 0 |

| 两者之和 | 8 以上 | 6–7 | 4–5 | 1–3 | 0 |
| --- | --- | --- | --- | --- | --- |
| 实战按 | A（120%） | B（100%） | C（80%） | D（60%） | -（0%） |

攻击方的攻击力和防御方的装甲各乘自己的这个倍率。所以**机体本身已经是 A 时，要改驾驶员才能让实战变成 A**。例如豪将军（184）机体宇宙是 A，真吾（133）是 B，合起来 7，原版在宇宙只按 B 算；把真吾的宇宙改成 A，就是 A。

武器的地形适应只看武器自己，另外再乘一次。

## 什么时候生效

装上、启用或停用包后不用重启游戏。游戏不在内存里留这些数值，每次用到都从数据里重新读，所以：

- **读档时**（场间存档和关卡里的中断存档都一样），全部机体、武器和驾驶员都按当前启用的包重建。装上包读档就是新数值，停用包再读档就回到原版，存档本身不会被改。
- 机体的数值，以及武器的威力、最大射程、空中适应，进地图或进场间时就更新。
- 武器的其他字段、驾驶员的一切，要读一次档（或开新游戏）；驾驶员升级时也会更新。关卡里中途启停包，最好存个档再读。
- 图鉴也显示改过的数值。

## 共用记录

有些人物共用同一条能力记录（能力值、地形、技能），多是同一个人物的另一份编号（例如多蒙的 4、273、274）。改其中一个，共用的人一起变。ID 表的「共用能力记录」一栏列出了这些人。精神有自己的一套记录，也可能几人共用。

表里同名的条目是不同的编号，可能是变形形态、敌方版本或剧情专用的那一份，改之前对一下原来的数值。

## 示例

示例包「主力宇宙适应 A」可以在 [MOD 下载](/zh/mods/#srw64.space-a)页下载，源文件在 [`config/recomp/mods/space-a`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/space-a)。它把我方主力里宇宙不到 A 的 20 名驾驶员和 21 台机体的宇宙改成 A：魔神系、孔巴特拉V、盖塔3、豪将军、大铁人、丹拜因系、钢加农、钢坦克等。

改名字和头像见 [名字与头像 MOD](../mod-names/)。
