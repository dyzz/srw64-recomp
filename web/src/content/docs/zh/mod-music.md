音乐 MOD 用一个音频文件替换原版的一首歌。游戏里所有放这首歌的地方都会跟着换：战斗曲、关卡曲、剧情曲、标题和音乐鉴赏。还可以指定某个人物或机体打仗时放哪首歌。

包的安装和管理见 [MOD 包：安装与制作](../mods/)。

## 用网页工具制作

[BGM MOD 制作](/zh/mods/bgm/)工具在浏览器里完成全部步骤，**音频不会上传到任何地方**：

1. 填包的信息：ID、版本、名称、作者、许可证。
2. 在 49 首曲目的列表里，把音频文件拖到要替换的那一行。mp3、wav、flac、m4a、ogg 都可以，工具会转成游戏用的格式；已经是 Ogg Vorbis 的文件原样使用。
3. 点那一行展开设置（行里的 ▶ 可以直接试听）：
   - **循环**：整首循环、只循环其中一段，或者只放一次。循环区间可以在波形上拖动蓝线（起点）和金线（终点），松手时自动对齐到最近的过零点，「试听接缝」可以听循环处接得顺不顺。
   - **音量修正**：旁边会显示这首和其他已替换曲目的平均电平，方便调到一样响。
   - **曲名**：音乐鉴赏里显示的名字，可以按语言分别写。
4. 需要的话，在「战斗曲」里指定某个人物或机体打仗时放哪首。
5. 点「导出 .srw64mod」，把文件拖进游戏窗口安装。

以后想改，用「打开已有的 .srw64mod」把包读回来继续编辑。

## 在游戏里

- 音乐鉴赏里，被替换的曲目右边标「MOD」，写了曲名的显示包里的曲名。
- 设置的「通用」页有「MOD 音乐」开关和音量（25%～100%），从下一首歌开始生效。
- 卡拉OK 仍然放原曲，因为歌词是按原曲的节奏走的。

## 原版怎么选歌

- **战斗曲**：只要交战双方有一方是我方，就放**我方主驾驶员**的战斗曲，不管谁攻谁守；双方都不是我方时，放攻方机体的战斗曲。
- 以下情况原版固定放某一首，MOD 指定的战斗曲不会改变它们：ゴッドガンダム 的明鏡止水形态、シャッフル同盟 的 S 形态、V-MAX 发动中，以及ヴァル＝ア、アヴィ＝ルー、ジェイ＝レン 三人中有人参战。但这些固定曲目本身也可以被替换。
- 战斗结束后不会换回关卡曲，战斗曲会一直放到下一个阶段开始，做循环时要考虑这一点。
- 关卡曲在每个阶段开始时重新播放。
- 敌人增援登场时的短曲（歌号 38）默认只放一次，放完游戏自己换回关卡曲。

## 手工制作

网页工具生成的就是下面这些文件。

```text
yourname.bgm/
  mod.json
  audio/
    music/<歌号>.ogg
    music.json        可选
```

- 文件名是**歌号**（十进制、不补零），例如 `7.ogg` 替换 7 号「メインテーマ」。49 首歌的歌号、曲名和用途见[歌号对照表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/songs.csv)。
- 格式只能是 **Ogg Vorbis**，采样率不限，单声道、立体声都可以。只用 Vorbis 是为了让循环点精确到每个采样：MP3 的开头和结尾会多出一段补白，循环处会有空隙。其他格式先转换，例如：

  ```bash
  ffmpeg -i in.wav -c:a libvorbis -q:a 6 out.ogg
  ```

`music.json` 可以不写。只放 `.ogg` 时就是整首循环、原音量、原曲名。要细调时这样写：

```json
{
  "schema": "srw64.music.v1",
  "tracks": {
    "7":  { "loop": [441000, 5292000], "gain": -2.0,
            "title": { "zh-Hans": "…", "en": "…", "ja": "…" } },
    "38": { "loop": false }
  },
  "battle": {
    "pilot": { "36": 7 },
    "unit":  { "97": 12 }
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `tracks.<歌号>.loop` | `[起点, 终点]`，单位是**采样数**（不是秒），放到终点就跳回起点。`false` 表示只放一次，`true` 表示整首循环。不写时读文件里的 `LOOPSTART`／`LOOPLENGTH` 标签，标签也没有就整首循环 |
| `tracks.<歌号>.gain` | 音量修正，单位 dB，负数表示调小 |
| `tracks.<歌号>.title` | 音乐鉴赏里显示的曲名，按语言写 |
| `battle.pilot.<人物号>` | 这个人物作为我方主驾驶员时，战斗放哪首（值是歌号） |
| `battle.unit.<机体号>` | 双方都不是我方时，这台机体作为攻方，战斗放哪首 |

人物号和机体号见[人物表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/pilots.csv)和[机体表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/units.csv)，表里也列了每个人物、机体原本的战斗曲。几个包都设置了同一首歌或同一个人物时，列表上面的包优先。

### 交给 AI 做

仓库的 [`docs/guide/audio-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/audio-mods) 文件夹里有完整的格式说明和全部对照表，可以整个交给 AI 助手，让它帮你改文件名、转格式、写 `mod.json` 和 `music.json`。

## 战斗语音

0.5.2 起，包里还可以放战斗台词的配音：战斗演出里台词框一打开，就放这句的语音。

最简单的做法是用[战斗语音 MOD 制作工具](/zh/mods/voices/)，同样全在浏览器里完成：

1. 填好包信息，需要的话设音量修正和延迟。
2. 选一个人物，列出他的全部战斗台词，每句都写着什么时候出现和原文。把录音拖到对应的那一行，或点「选择文件」。录音会自动转成 Ogg Vorbis，点 ▶ 试听。
3. 录音很多时，把文件名改成以记录号开头（例如 `7018.wav`、`7018_攻击.wav`），一次全部拖到「批量加入」里。
4. 点「导出 .srw64mod」。之后可以用「打开已有的 .srw64mod」接着加。

自己手工打包时，文件是这样放的：

```text
yourname.voices/
  mod.json
  audio/
    voice/battle/<记录号>.ogg
    voice.json        可选
```

- 文件名是战斗台词的**记录号**（5799–17346），全部 11548 句的记录号、说话人、什么时候出现和三语原文都在[台词对照表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/battle-voices.csv)里。格式同样只能是 Ogg Vorbis。
- 多页的台词只在第一页放。下一句台词开始、战斗结束或中止演出时，正在放的语音停止。
- 台词框照原版的节奏翻页，不等语音放完，每句最好控制在两三秒内。
- 关掉战斗动画时没有台词，也就没有语音。语音不分语言，换阅读语言放的都是同一个文件。
- 随机台词要配全才会每次都有声音，例如「攻击（通用，3/14）」是从 14 句里随机抽一句。
- `voice.json` 可以不写：`{"schema": "srw64.voice.v1", "gain": -3.0, "delay": 150}`，`gain` 是音量修正（dB，-30 到 12），`delay` 是台词框打开后等多少毫秒再放（0 到 2000）。
- 设置「通用」页有「MOD 战斗语音」开关和音量。
