这类 MOD 往游戏里加**原版没有的**机体、武器和人物。它们有自己的编号，排在原版全体人物和机体旁边，不顶替谁；照抄一台原版机体或一个原版人物做起点，再改名字、数值、武器、图和台词。

一个包可以加：

- **会变形的机体**，每个形态有自己的武器和地图图标；
- **在地图上合体的机体**：按包里写的配方合体，可以再分离，也可以合体状态出击。合体后的改造不会冲掉各部件自己的改造；
- **新武器**，包括**合体技**：搭档、EN、气力的检查和原版一样，武器页、图鉴和战斗查看器会列出搭档；
- **新人物**，有自己的头像、**战斗台词和语音**（平常的战斗场面，或者用某件武器、对上某个对手时说的），以及自己的**战斗曲**；
- **敌方的新机体、新人物**，由剧情安排登场；
- **自己的立绘、战斗图和 cut-in**：站姿、招式里的场景，HD 画面和原版画面各一张。

新机体、新人物会出现在图鉴和战斗查看器里，带自己的图和作品。

需要 0.5.4 或更新的版本。包的安装和管理见 [MOD 包：安装与制作](../mods/)。

## 用机体制作器

官网的[机体制作器](/zh/mods/units/)在浏览器里写出这样的包，**图片和录音不会上传到任何地方**：

1. 从原版照抄一个人物、一台机体或一件武器，改四种语言的名字、数值、武器、形态、乘员和合体技。
2. 从自己的图里框出头像；给机体加站姿、带 cut-in 的战斗图和地图图标，浏览器会把它们缩成游戏用的颜色数。
3. 写四种语言的战斗台词，每句可以配一段语音，在波形上裁剪；可以加战斗曲。
4. 用游戏自带的特效拼武器演出：移动每个演员或整体挪发射点，从任意原版武器借演员，加 cut-in，给原版特效换颜色。选了本机的 ROM，舞台上会画出原版特效的样子（ROM 只在浏览器里读，不上传）。
5. 写这台机体什么时候加入、包自己的增援；导出 `.srw64mod`，也可以导出成 Thunderstore 的包。

制作器里有现成的模板可以从它开始。关于页有一个开关（默认关），打开后制作器可以把包直接发给正在运行的游戏，在战斗查看器里试；游戏接收前会先问你。

制作器现在只提供常见的通用武器来照抄、借演出和加到机体上（光束步枪、光束军刀、火神炮、机枪、导弹、火箭筒、光束加农炮、加农炮、拳脚、冲撞、斧、军刀），以及机体自己原型机的武器；其他武器以后再开放。更复杂的包可以照下面的格式手工写，或者交给 AI 助手。

## 包里放什么

```text
yourname.rival/
  mod.json
  data/new_units.json            新机体、新武器、新人物、新战斗图（必需）
  data/units.json、pilots.json、weapons.json
                                 可选：改它们照抄过来之后的数值（数值 MOD 的写法）
  dialogue/names.json            名字（名字 MOD 的写法）
  dialogue/battle_quotes.json    可选：新人物自己的战斗台词
  art/…                          立绘、战斗图、头像、地图图标
  audio/…                        可选：语音、战斗曲
  story/…                        可选：什么时候加入、敌方登场（剧情 MOD）
```

## new_units.json

```json
{
  "schema": "srw64.new-units.v2",
  "scenes":  { "cannon-pose": [2560, 1716, 2118] },
  "weapons": { "cannon": { "copy": 875, "inherits_from": 875,
                           "animation": { "camera": 1, "hit": 59, "action": 84, "defender": 125, "sounds": [219],
                                          "actors": [ { "scene": "@cannon-pose", "h4": 1, "h5": 255, "behavior": 359 } ] } } },
  "units":   { "final": { "copy": 224, "pose": [2324, 1724, 2016], "icon": 978,
                          "weapons": [870, 871, "@cannon"], "inherits_from": 224,
                          "crew": [171, 168, 170, 169, 166] } }
}
```

新机体、新武器、新人物、新战斗场景都**用名字写**，编号由游戏给：机体在 400–998，武器在 1400–2399，人物在 400–511，场景接在原版之后。原版的编号一个都不占。

- 名字只用小写字母、数字和 `-` `_` `.`。包里其他文件用 `@名字` 指本包的新东西：`data/units.json` 写 `"@final": {"hp": 8000}`，`dialogue/names.json` 的 `units` 写 `"@final"`，地图图标叫 `art/icons/@final.png`，剧情 MOD 写 `"with": "@final"`、`"unlock": "@cannon"`。指别的包的写 `包id@名字`，并把那个包写进 `mod.json` 的 `requires`。
- 编号按「包 id@名字」算出来，同样的包在哪台机器上、按什么顺序装都一样。只有两个名字算到同一个号时，一个往后挪一位。存档旁边会记下每个编号是哪个包的哪个名字：后来装的包让编号挪了，读档时自动改成现在的编号；停用了这个包，读这种存档会回到标题，并提示需要哪个包。

### 机体（units）

| 字段 | 说明 |
| --- | --- |
| `copy` | 照抄的机体（原版机体号，要有自己的战斗记录，或者另一台新机体）。数值、武器、图都先从它来。照抄时去掉变形、分离、合体 |
| `pose` | 站姿：原版的 `[场景, 图集, 调色板]` 三个资源号，或者包里的 `"@图片名"`（见[自己的战斗图](#自己的战斗图)） |
| `icon` | 地图图标：原版图标号；包里有 `art/icons/@名字.png` 时用那张 |
| `weapons` | 武器表：原版武器号和 `@新武器` |
| `inherits_from` | 剧情里换成这台机体时（剧情 MOD 的 `replace`），改造段数从这台旧机体搬过来 |
| `crew` | 1–5 个人物号，第一个是主驾驶。这台机体登记给主驾驶时，其余人物成为它的乘员 |
| `combine` | 由部件合体，见下 |
| `forms` | 变形，见下 |
| `work` | 图鉴详情里写的原作，原版作品号 0–24；不写就跟照抄的机体。图鉴里的型号行写在 `dialogue/names.json` 的 `models`（最多 48 字） |

包加的机体和人物在图鉴里排在最后的「MOD」组。新机体的台数没有上限。

**合体**：`"combine": {"parts": [2–5 台部件], "over": [原版合体机]}`。部件的顺序就是乘员的顺序（各部件的主驾驶）。地图上原版合体机（`over`）的「合体」成立、其余部件（例如黑翼）也在旁边且未行动时，合出来的是这台新机体；「分离」放回全部部件。这台机体由剧情 MOD 的 `build` 建出来（[剧情 MOD](../mod-story/)），自己不会在关开始时出击。

**变形**：写在基本形态上，`"forms": ["@wr"]` 列出 1–2 个别的形态（同一文件里的新机体），各形态照旧写自己的 `weapons`、`pose`、`icon`。各形态的武器合成一张共用列表，每件武器只在列了它的形态下能用；全族共用改造段数、武器段数和乘员，和原版一样。地图菜单出现「变形」（三个形态时弹出选单）；关开始时出击的是基本形态。一台机体只能在一个变形族里，原版机体不能加进来。

### 武器（weapons）

- `copy` 照抄一件原版武器；`inherits_from` 指出这件新武器的改造段数从旧机体的哪件武器来（旧机体本来就有的武器照原样搬）。
- `animation` 是战斗演出：镜头、命中效果、动作、防守方的反应、音效和演员（演员的 `scene` 可以写包里的 `@场景`）。这部分用机体制作器拼最方便。
- 照抄的武器在 `data/weapons.json` 里改了格斗／射击、移动后、光束，菜单名前后的「格／射」「P」「B」跟着改。

**合体技**：`"combination": {"units": ["@z", 228], "parts": [196, 899], "multiplier": 1.5}`。`units` 是参加的 2–5 台机体（原版号或 `@名字`），`parts` 按同样的顺序写每台的组成武器，威力是它们当前威力的平均乘 `multiplier`；可选 `pilots: [[人物, 人物], …]`，主驾驶里要凑齐其中一组。武器表里有这件武器的参加机体都能领队；参加者要全员在场、连成一片（八方向相邻），各自 EN、气力够。打出后每台都扣这件武器的 EN，不扣弹药，所以照抄耗弹药的武器时，在 `data/weapons.json` 里给它设 `en` 和 `"ammo": -1`。搭档不在时，地图上的武器页把它显示成灰字，并提示缺谁。合体技和原版一样不能改造。记得在 `dialogue/names.json` 的 `weapons` 里给它起名，不然显示的是照抄武器的名字。

### 人物（pilots）

```json
"pilots": { "kai": { "copy": 166, "voice": 166,
                     "portrait": { "image": "art/kai.png", "hd": "art/kai-hd.png" } } }
```

| 字段 | 说明 |
| --- | --- |
| `copy` | 照抄的原版人物（要有能力记录）：能力、技能、精神、头像、战斗曲都从它来 |
| `voice` | 战斗里借谁的台词，不写就是 `copy`。包里给了它自己的战斗台词时，没写的场面仍说这个人的 |
| `portrait` | 包里的头像：`image` 是 96×96、最多 63 种颜色的像素图，`hd` 是边长为 96 整数倍的正方形高清图（可不写）；也可以写两个原版资源号 `[图, 调色板]`；不写就用照抄人物的头像 |
| `love` | 可选，恋爱／友情补正：`[{"with": 166, "mutual": true}]`，相隔 2 格内攻击 +30%、受到的伤害 −30%，`mutual` 让对方也有 |
| `combo_as` | 可选，在合体技的驾驶员条件里算作哪个原版人物 |

所有包合计最多 112 名新人物。数值、技能、精神用 `data/pilots.json` 的 `"@kai"` 改，名字用 `dialogue/names.json` 的 `pilots."@kai"`，入队用剧情 MOD 的 `{"join": {"pilot": "@kai", "unit": 9}}`。

`image` 可以用仓库里的工具从大图缩出来：

```bash
python3 tools/mods/sprite_pixels.py 大图.png kai.png --size 96 96 --colors 63
```

## 新人物自己的战斗台词

```json
{
  "schema": "srw64.battle-quotes.v1",
  "pilots": {
    "@kai": {
      "attack":  [{"ja": "「カイ、行くぞ!」", "zh-Hans": "“凯，上了！”", "en": "\"Kai, here I come!\"", "voice": "kai-attack.ogg"},
                  {"ja": "「これでも食らえ!」", "zh-Hans": "“吃我这招！”"}],
      "evade":   [{"ja": "「見切った!」", "zh-Hans": "“看穿了！”"}],
      "special": [
        {"weapon": 49, "lines": [{"ja": "「全力の一撃だ!」", "zh-Hans": "“全力一击！”"}]},
        {"opponent": 298, "situation": "evade", "lines": [{"ja": "「そんな攻撃が当たるか!」", "zh-Hans": "“这种攻击打不中我！”"}]}
      ]
    }
  }
}
```

放在 `dialogue/battle_quotes.json`。只能给包里的新人物写（`@名字`，或别的包的 `包id@名字`），原版人物的台词不能改。

- 九种场面，和原版一样每次从这一组里随机说一句：`attack` 攻击、`shot_down` 被击坠、`heavy` 重伤（剩余 HP 不到 30%）、`medium` 中伤（30–90%）、`light` 轻伤（90% 以上）、`evade` 回避、`no_damage` 攻击无效（护罩、装甲）、`no_ammo` 弹药或 EN 不足不能反击、`out_of_range` 射程外不能反击。**没写的场面说 `voice` 那个人的台词**，台词框里也是那个人的名字和头像。
- 每句是一个对象：各语言的台词（`ja` 必须有，最多 42 字，正好一页三行；其他语言最多 200 字，阅读器按台词框宽度排）；可选 `voice` 是 `audio/voice/battle/` 里的 `.ogg` 文件名，这句显示时放（只认 Ogg Vorbis，见[音乐 MOD](../mod-music/#战斗语音)）。
- `special` 是有条件的台词，条件成立时一定说它：
  - `"weapon": 武器`：用这件武器攻击时（原版武器号或 `@新武器`）。同名武器算同一件，新武器算它照抄的那件。加 `"sometimes": true` 就和原版的部分武器台词一样，常被普通攻击台词顶掉。
  - `"opponent": 原版人物`：对手是这个人时，`situation` 写九种场面之一（默认 `attack`）。
  - 每个人物的条件台词合计最多 119 句；同时成立的几条随机选一条。
- 台词的编号由游戏分配（所有包合计最多 2048 句），存档里不记；停用包后照原样回到借来的台词。

新人物的战斗曲写在包的 `audio/music.json` 里：`"battle": {"pilot": {"@kai": "@kai-theme"}}`，曲子放 `audio/music/kai-theme.ogg`，见[音乐 MOD](../mod-music/)。

## 自己的战斗图

新机体的站姿、招式里的场景、cut-in 都可以用包里的 PNG，在 `new_units.json` 里写 `sprites`：

```json
"sprites": {
  "stand":  { "image": "art/battle/stand.png", "origin": [59, 90], "hd": "art/battle/stand-hd.png" },
  "cutin":  { "image": "art/battle/cutin.png", "origin": [56, 48], "mirror": false, "ticks": [22], "hd": "art/battle/cutin-hd.png" }
},
"scenes": { "cutin": "@cutin" },
"units":  { "final": { "pose": "@stand" } }
```

- `image` 是游戏里实际大小的像素图（站姿约 128×96），最多 127 种颜色，半透明以下当透明。可以用 `python3 tools/mods/sprite_pixels.py 大图.png 小图.png --size 128 96` 从大图缩小、减色得到。
- `hd` 是每帧一张的高清图：HD 画面下画它，原版画面下画 `image`。改造、能力等页面和图鉴也用这两张。
- `origin` 是图里对应场景原点的像素，站姿写脚下中间。
- `mirror` 默认 `true`：机体和招式里的东西按敌我翻转；cut-in 这类不该翻的写 `false`。
- 多帧写 `"frames": [...]`，配 `"ticks"`（每帧几拍）和 `"loop"`（播完回到第几帧）。
- `"around": [前, 后]`：有的武器效果会换到「下一张场景」（比如光束会依次换成光束身、光束尾），把自己的图放到这种演员上时要写它；机体制作器的「换图」会自动写好。少数武器（约 95 件，比如几个人配合的大招）的演出按场景号互相计算，这些武器的演员不能换图（cut-in 可以加），制作器会锁住「换图」，游戏也不会加载这样的包。
- 站姿 `pose`、场景总表 `scenes` 写 `@图片名`，也可以照旧写原版的三个资源号。
- 换色：`scenes` 里写 `{"recolor": 56, "colors": {"2": "#20e060"}}`，用原版战斗场景 56（光束）的图和动作，只把调色板里列出的几格换成新颜色（格号 0–255，透明的格仍透明）。原版画面和 HD 画面都跟着换。**要 0.5.4 之后的下一版游戏**，`mod.json` 的 `game` 写 `">=0.5.5"`；制作器在「战斗演出 → 颜色」里点着改，导出时自动写好。

借原版图、靠 HD 包换图的包，在 `mod.json` 写 `"requires": {"srw64.hd": ">=1.3"}`：没装 HD 包或图片设成原版时，整包不加载，MOD 页显示「需要 HD 画面」；在游戏里切换图片要重启才算。

## 让它加入、让敌人用它

新机体、新人物装上之后不会自己出现，要用剧情写什么时候加入（[剧情 MOD](../mod-story/)）：

- `{"join": {"pilot": "@kai", "unit": "@rz"}}`：人物和机体加入我方；
- `{"replace": {"pilot": 171, "unit": 224, "with": "@final"}}`：名册里的旧机体换成新机体，改造段数按 `inherits_from` 搬过去；
- `{"build": "@final"}`：给我方建一台合体机（写了 `combine` 的新机体）；
- `{"unlock": "@cannon"}`：解锁剧情解锁的新武器；
- 剧情文件的 `deployments`：敌方、第三方也可以用包里的新机体和新人物。

[追加剧本](../mod-campaign/)的出击记录也可以写 `@名字`。

## 示例

- 「终极断空我」：[`config/recomp/mods/final-dancouga`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/final-dancouga)。新机体照抄原版终极断空我，五名乘员，自己的站姿、cut-in 和地图图标；在地图上由断空我和黑翼合体，可以分离再合体，也能合体状态出击。可以在 [MOD 下载](/zh/mods/#srw64.final-dancouga)页下载。
- 「卡茨与超级夺地者」：[`config/recomp/mods/super-earthgain`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/super-earthgain)。通关布拉德篇「了断之时」后卡茨入队，夺地者和斩空者合体成超级夺地者（布拉德主驾驶、卡茨副驾驶），继承夺地者的改造；出击时是合体状态，在地图上分离后两台可以用合体技「招雷 天龙魔灭阵」，相邻时可以再合体。可以在 [MOD 下载](/zh/mods/#srw64.super-earthgain)页下载。

### 交给 AI 做

仓库的 [`docs/guide/data-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/data-mods) 文件夹里有完整的格式说明（「新机体与新武器」一节）和 CSV 版的机体表、人物表、武器表；每个字段写进哪张表、游戏怎么读，见 [`docs/design/new-unit-ids.md`](https://github.com/dyzz/srw64-recomp/blob/main/docs/design/new-unit-ids.md)。可以连同示例包一起交给 AI 助手，让它照你的想法写。写好后用 `python3 tools/mods/validate.py 包.srw64mod` 检查。
