追加剧本是一个独立的小战役：几关按你定的顺序连起来，关与关之间照常进场间（改造、换乘、存档），可以用剧情中的选项分出不同结局。它装在 MOD 包里，从标题画面的「MOD → 追加剧本」进入，**存档与本篇完全分开**。

每一关有四层：**地图**（原版地图，或者你自己画的整张图）、**单位**（按组摆在格子上）、**剧情**（开场、战斗中、过关后的事件和台词）、**流程**（过关后去哪一关、结局，或者让玩家选）。

本页写的新格式需要 0.5.4 或更新的版本。0.5.1–0.5.3 做的旧格式战役照旧能玩。

## 现在能做什么

| 能做 | 还不能做 |
| --- | --- |
| 多关串联、选项分支、多个结局 | 在主线中间插进新的关 |
| 原版地图，或自己画的整张地图（每格的地形自己定） | 同一关里换到第二张自己画的地图；自己画的海面不会动 |
| 新台词、新写的选项文字和作战目标文字，三语分别写；原版的「???」剪影说话人 | 原版带殖民地动画的地图当自绘地图的模板 |
| 每关的我方、敌方、第三方单位，增援，敌人的行动方式、掉落的强化部件、登场时的残量 | 从中间某一关开始试玩 |
| 胜败条件：全灭、击破某人、到达区域、回合数、剩余台数、HP、说服……可以组合 | |
| 战斗里人物的新台词；出击选择 | |
| 包里的新机体、新人物（[新机体、新人物与新武器 MOD](../mod-units/)） | |
| 资金、剧情变量、关与关之间保留的部队 | |

## 用关卡编辑器

官网的[关卡编辑器](/zh/mods/editor/)在浏览器里一关一关地写战役，**不需要 ROM，也不上传任何东西**。原版的地图、机体、人物、曲子都和图鉴一样从官网读。

- **总览**：关卡列表和流程图（连线是过关后的去向）、检查结果、包的信息和主角路线。
- **地图**：直接用原版地图；或者导入自己的图（PNG、JPEG、WebP），切成格子，再给每格选地形（画笔、矩形、填充相连、吸取，可以先「按颜色猜」一遍再改），选一张原版地图来顶替，看原版画面下的样子。
- **单位**：按组摆单位，组有阵营和登场时机；改选中单位的机体、驾驶员、等级加成、改造段数；敌方和第三方可以设行动方式（自由进攻、只追打某人、走向某格、固定防御、护卫某人等）、原地不动几回合、被击破时掉落的部件、登场时的 HP／EN。
- **剧情**：出发前、进入战场、战斗中的各个事件、战后；每个事件选时机和条件，一步步加动作（台词、登场、离场、入队、音乐、镜头、选项、变量……），台词按中／日／英分别写，旁边是在游戏里的样子；另有一栏「战斗台词」。
- **胜败与增援**：胜利和失败条件、作战目标文字、每组的登场时机、过关后的去向（结局、下一关、让玩家选）、战场音乐。

工程会自动存在浏览器里；顶栏的「保存工程」把它存成 `.srw64edit` 文件，没做完也能存，「打开工程」接着改。每一步都能撤销（Ctrl／⌘+Z）。「模板」载入一个两关的现成战役，可以从它开始。做好了点「导出 .srw64mod」，导出前页面会先检查（单位出界、站在进不去的格、重叠、每阵营最多 30 个、有没有敌我双方等）。导出的包里带着源文件，也能用「打开工程」读回来。

## 交给 AI 做

能读写文件的 AI 智能体（Claude Code、Codex 等）可以照着本页做出整个战役。在[源代码仓库](https://github.com/dyzz/srw64-recomp)目录里打开它，复制下面这段话，把「剧情」那一段换成你的大纲：

```text
请帮我给 Marchwind 64（《超级机器人大战64》的 PC 重编译版）做一个追加剧本 MOD（自定义战役），最后打包成可以直接安装的 .srw64mod 文件。

先读这些，严格按里面的格式和规则做：
- https://srw64.dreamquest.club/zh/docs/mod-campaign.md（战役和关卡的格式、地图、打包）
- https://srw64.dreamquest.club/zh/docs/mod-story.md（事件的时机、条件和动作，关卡里的事件用同一套写法）
- 仓库里的示例战役 config/recomp/campaigns/sample，照它的结构写

要求：
- 新台词每句都写 ja 和 zh-Hans，日文用「」，中文用 “”
- 人物号、机体号、地图号查仓库 docs/guide/data-mods/ 里的表和 docs/guide/story-mods/scenes.csv
- 剧情变量只用 60–99

剧情：
（几关；每关用哪张地图、谁加入我方、敌人是谁、什么时候增援、胜利和失败条件；哪里出选项、分几个结局）

做法：
1. 先给我关卡表和每关的设计，我确认后再写文件
2. 写完用 tools/mods/pack.py 打包（它会编译并检查整个战役），有错就改
3. 告诉我生成的文件在哪、怎么安装
```

几点经验：

- **大纲越具体越好。**写到「第 2 关用原版第 5 话的地图，阿姆罗和卡缪出击，敌人 6 台，第 3 回合增援，全灭敌人胜利」这种程度。让 AI 自己挑编号很容易出错。
- **先在关卡编辑器里打开看看。**AI 写好的包可以用编辑器的「打开工程」读进来，地图、单位位置一眼就能看出对不对。
- **一关一关玩一遍。**单关能进、能打赢、过关能接到下一关，再串起来玩。

## 文件结构

```text
my-campaign/
  mod.json                 包的信息
  campaign.json            战役：名字、开局关、主角路线、关卡顺序
  stages/<关卡名>.json      每一关
  stages/<关卡名>.meta.json 可选：本关情报页的内容
  status.json              可选：本关情报页的完成状态规则
  maps/<地图名>/            可选：自己画的地图
```

`mod.json` 的写法见 [MOD 包](../mods/#modjson)；`game` 写 `">=0.5.4"`。打包时这些源文件会被编译成包里的 `campaign/`，源文件不进包（编辑器导出的包另带一份源文件，给编辑器读回来用）。本关情报页的两个可选文件照示例战役里的抄。

## campaign.json

```json
{
  "schema": "srw64.campaign.v2",
  "id": "yourname.my-campaign",
  "name": {"zh-Hans": "我的战役", "en": "My Campaign", "ja": "マイキャンペーン"},
  "description": {"zh-Hans": "一句话简介。", "en": "One line about it.", "ja": "ひとことで紹介。"},
  "author": "yourname",
  "version": "1",
  "start": "valley",
  "route": 1,
  "stages": ["valley", "showdown"]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 必须和 `mod.json` 的 `id` 一样。它也是战役存档文件夹的名字，**发布后不要再改** |
| `name`、`description` | 追加剧本页上显示的名字和简介，可以是一个字符串，也可以按语言分别写（`zh-Hans`、`zh-Hant`、`en`、`ja`、`ko`，以及[语言包](../mod-language/)的语言） |
| `start` | 第一关是哪一关 |
| `route` | 主角路线，必须写：0 布拉德、1 玛娜米、2 阿克、3 塞蕾茵。原版有些台词会画主角组的头像，没有路线时会崩溃；各关可以在 `setup` 里另写 |
| `stages` | 关卡名的数组，对应 `stages/<关卡名>.json`。关卡名用小写字母、数字和 `-` `_` |
| `status` | 可选，本关情报页的状态规则文件 |

游戏按「场景号」记录进度，编译器按 `stages` 的顺序给每关分配一个原版的场景号（避开不能借的号），你不用管。但**存档里记的就是这个号**，所以发布以后要加关，就加在 `stages` 末尾，不要插在中间，否则旧存档会指到别的关。一个战役最多大约 115 关。

## 关卡文件

```json
{
  "schema": "srw64.stage.v1",
  "title": {"ja": "分かれ道", "zh-Hans": "岔路", "en": "Crossroads"},
  "map": 19,
  "units": {
    "place": [
      {"group": 0, "x": 14, "y": 14, "pilot": 36, "unit": 55, "faction": 0},
      {"group": 1, "x": 6, "y": 3, "pilot": 69, "unit": 317, "faction": 1, "level": 1,
       "ai": {"mode": "goto", "to": [14, 14]}, "drop": 3}
    ]
  },
  "objective": {"win": {"ja": "敵の全滅", "zh-Hans": "全灭敌人"}, "lose": {"ja": "アムロの撃墜", "zh-Hans": "阿姆罗被击破"}},
  "events": [
    {"when": "opening", "do": [
      {"bgm": 49}, {"fade": "in"},
      {"say": 36, "text": {"ja": "「行くぞ」", "zh-Hans": "“上了。”"}},
      {"fade": "out"}, {"to_map": true},
      {"op": "3D65", "args": [127, 127]},
      {"fade": "in"}, {"deploy": 0}, {"deploy": 1}, {"bgm": 27}, {"op": "3D48"}
    ]},
    {"id": "all-down", "when": {"enemies_gone": true}, "do": [{"win": true}]},
    {"id": "amuro-down", "when": {"defeated": 36}, "do": [{"lose": true}]},
    {"when": "end", "do": [
      {"say": 36, "text": {"ja": "「次はどうする？」", "zh-Hans": "“接下来怎么办？”"}},
      {"choose": {"text": {"ja": ["進む", "戻る"], "zh-Hans": ["前进", "回去"]},
                  "options": [[{"next": "onward"}], [{"next": "back"}]]}}
    ]}
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `title` | 标题，显示在标题卡、场间和存档列表上。不要写「第几话」：场间和存档列表会按已通关的关数自己加上「第N话」 |
| `map` | 原版地图号，或 `maps/` 下自己的地图名（见下） |
| `units` | `place` 是这一关的单位，见下；`copy_from` 整块复制原版某一关的出击记录（要读你的 ROM，见「分享」） |
| `events` | 事件，见下 |
| `objective` | 可选，地图菜单「作战目标」里显示的胜利、失败文字，每句不超过 30 字。写了它，开场要写 `{"op": "3D65", "args": [127, 127]}`（编辑器会自动写）；不写就用原版的说法，开场写 `3D65 胜利号, 败北号` |
| `battle_lines` | 可选，这一关战斗里的新台词，写法同[剧情 MOD 的战斗台词](../mod-story/#战斗台词)，不写 `scene` |
| `setup` | 可选：`route`（这一关的主角路线）、`story_vars`（进关时的剧情变量）、`last_choice`、`initial_resources` |
| `scene` | 可选，指定借哪个场景号。一般不写 |
| `raw_events` | 可选，原版事件格式的事件（整段复制原版事件时用），见[关卡脚本指令参考](../script-commands/) |

### 单位（units.place）

每条记录一台单位：

| 字段 | 说明 |
| --- | --- |
| `group` | 组号。开场用 `{"deploy": 组号}` 让这一组登场，增援也是到时候 `deploy` |
| `x`、`y` | 格子坐标，从左上角 0 开始 |
| `pilot`、`unit` | 人物号、机体号；包里的新人物、新机体写 `"@名字"`（这个包自己的）或 `"别的包id@名字"`（写进 `requires`） |
| `faction` | 阵营：0 我方、1 敌方、2 或 4 第三方 |
| `level` | 在这一关基准等级上的加成 |
| `upgrade` | 改造段数 |
| `ai` | 敌方、第三方的行动方式：`{"mode": …, "wait": 回合, "target": 人物号, "to": [x, y]}`。`mode` 是 `attack`（自由进攻，先打装甲和 HP 低的）、`accurate`（自由进攻，按命中率挑，不用命中低于 30% 的武器）、`hunt`（只追打 `target`）、`goto`（走向 `to`，途中不主动攻击、被打会还手）、`flee`（同 `goto`，被打不还手）、`guard`（护卫 `target`，射程内照打）。`wait` 是原地不动的回合数，31 是一直不动 |
| `drop` | 被击破时掉落的强化部件号（0–37），过关才入库；不写就不掉 |
| `entry` | 登场时的残量：1 HP 10%、EN 和弹药 0；2 HP 和 EN 10%；3／4／5 HP 和 EN 30／50／70%；6 HP 满、EN 和弹药 0；7 HP 10%、EN 满。不写就是满的 |

不写 `copy_from` 时每个阵营最多 30 台。我方单位登场后会永久入队，带到下一关。

### 事件（events）

`when` 有两种写法：

- 字符串 `"opening"`、`"setup"`、`"end"`：这一关自己的开场、初期配置、结束事件，各最多一个，总会执行，不写 `id` 和 `if`（要判断就在 `do` 里写 `if`）。**每关必须有开场**；结束事件在胜利结算之后执行。
- 对象：和[剧情 MOD](../mod-story/) 的事件完全一样（回合、击破、HP、交战、敌方全灭、剩余台数、到达区域、说服……），要有 `id`，不写 `scene`。`fired`、`not_fired` 指同一关的事件。

`do` 能用剧情 MOD 的全部动作（台词、选项、登场、离场、入队、换机、变量、音乐、镜头、等待……），另外还有五个只在战役里能用的：

| 动作 | 意思 |
| --- | --- |
| `{"win": true}` | 过关，进胜利结算，然后执行结束事件 |
| `{"lose": true}` | GAME OVER，玩家可以重试这一关。不要在开场中途执行 |
| `{"next": "关卡名"}` | 过关后去哪一关，写在结束事件里；分支就是在选项或 `if` 的不同分支里写不同的 `next` |
| `{"ending": true}` | 进入结局，结局播完回到标题。只写在最后一关的结束事件里 |
| `{"to_map": true}` | 开场里从世界地图切到战场 |

开场的一般顺序：在世界地图上演对白，`to_map` 切到战场，设作战目标，`deploy` 让各组登场，最后 `{"op": "3D48"}` 关掉对白窗口、交给玩家（示例战役就是这样写的）。新台词也可以写在 `story/<语言>/*.txt` 里，`text` 写 `"@名字"`，同[剧情 MOD](../mod-story/#台词写在纯文本文件里)。

原版指令照旧可以写，例如 `{"op": "3D5B", "args": [10]}` 加 1 万资金，`{"op": "3D3D", "args": [0, 0, 0, 最多几台, 组号]}` 让玩家从部队里选人出击、放在那一组第一条记录的位置（编辑器的「出击选择」就是这条）。指令见[关卡脚本指令参考](../script-commands/)。

## 自己画的地图

`maps/<地图名>/map.json` 和一张底图放在一起，关卡里写 `"map": "地图名"`：

```json
{"schema": "srw64.map.v1", "like": 20, "image": "base.png", "scale": 4,
 "terrain": [[99, 99, 99], [99, 5, 1]]}
```

- `image`：整张地图，尺寸是格数 × 16 × `scale`（`scale` 默认 4，可以 1–8）。28×32 格、`scale` 4 就是 1792×2048。HD 画面下画这张图，原版画面下画工具降级出来的样子。
- `terrain`：每格一个地形号（63 是墙），行数、列数和底图的格数一样。最外两圈是地图边框，写什么都按边框算。编辑器里的地形下拉列出了每种地形的名字、防御、命中、回复和移动消耗。
- `like`：顶替哪一张原版地图。这一关的 BGM、宇宙与否、战斗背景、水面颜色都照那张地图来，所以挑同一类场所的。只能挑没有殖民地动画的地图；宇宙地图只有 66、74、112、137、157 可选。
- 大小 20×15 到 128×128 格。

编辑器的地图页做的就是这些事。手写时，`pack.py` 会自动调用地图工具；单独看效果用 `python3 tools/mods/map_tool.py build maps/<地图名> -o 输出目录`，会多出一张原版画面下的 `preview.png`。

## 开局与要避开的

- **开局什么都没有**：名册是空的，主角和搭档没有名字。我方单位靠关卡里放的我方记录登场（登场就永久入队），或者用剧情动作 `join`。
- **部队、资金、改造和变量会带到下一关**，存档里也有。
- **剧情变量**只有 0–3 四个值，0–54 原版剧本一直在读，进关时 100–114、128–139 会被重置。战役自己的变量用 60–99（编辑器「＋ 新变量」就从这里挑）。
- 原版台词里带 `{HeroName}`、`{PartnerName}` 的，以及原创主角自己说的，最好不要借用：开局时主角没有名字。
- **已知会崩溃的写法**：`3D49` 时角色不在地图上；对还在地图上的单位用 `3D5A …, 4000` 删除（先让它离场）。
- 战役里的 リンク 菜单是禁用的。

## 编译和打包

```bash
python3 tools/mods/pack.py my-campaign -o build/mods
```

编译器和官网关卡编辑器是同一份（TypeScript），命令行要装 [Node.js](https://nodejs.org/) 23 或更新的版本，`python3` 会自动调用它。`pack.py` 编译整个战役、生成 `build/mods/<id>-<版本>.srw64mod`，并用和游戏相同的规则检查；写错了会报是哪一关、哪个事件的哪一项。只想看每关编译出了什么：

```bash
python3 tools/mods/stage.py compile my-campaign -o /tmp/out
```

## 安装与游玩

1. 把 `.srw64mod` 拖进游戏窗口安装（或放进 MOD 文件夹，见 [MOD 包](../mods/#安装)）。
2. 在标题画面打开「MOD」，切到「追加剧本」页，点战役那一行的「进入」。
3. 标题画面中间出现「开始战役」和战役名，从这里开始；之后在标题读档就是读这个战役的存档。
4. 回本篇：同一页的「返回本篇」。切换只能在标题画面进行。

战役的存档在用户目录的 `campaigns/<id>/saves/`，和本篇互不影响。

## 分享

编辑器做的包只用编号和你自己写的东西，可以公开分享。手写时用了 `copy_from`、`template` 或原版事件的 `copy_from`，会把你 ROM 里的原版数据复制进包里，这样的包只适合自己玩。文本号、地图号、人物号、机体号只是编号，可以用。自己画的地图要是你有权分发的图。其余照 [MOD 包的版权要求](../mods/#版权)。
