MOD 包是一个文件夹，或者把它压缩成的一个 `.srw64mod` 文件，里面只放数据，不放程序。游戏读到启用的包，就用包里的内容替换原版对应的部分；没有包的地方一切照原版。

**现在能生效的是音乐和地形适应**：替换曲目、指定谁打仗时放哪首歌，做法见[音乐 MOD](../mod-music/)；改机体和驾驶员的地形适应，做法见[数值 MOD](../mod-data/)。追加剧本、美术、台词、语音和其他数值会陆续开放，包格式已经为它们留好了位置。

MOD 功能需要 0.5.0 之后的版本。

## 安装

1. 打开 MOD 管理：点标题画面右下角的「MOD」，或者打开设置，在「通用」页点「MOD」。
2. 把 `.srw64mod` 文件（`.zip` 或包文件夹也可以）**拖进游戏窗口**，游戏会在后台安装，装好后在画面上方提示，并打开「已安装」页。
3. 也可以点「打开文件夹」，把包文件直接放进 MOD 文件夹，下次打开 MOD 管理时会自动安装。

同一个包装新版本时会替换旧版本，旧版本和删除的包都会移到 MOD 文件夹里的 `.trash`，不会直接删掉。

安卓版暂时不能安装 MOD。

## 管理

「已安装」页列出每个包的名字、版本、作者、包含的内容和状态，可以启用、停用或删除（删除要按两次确认）。

- **列表上面的包覆盖下面的**：两个包都替换了同一首歌时，用上面那个包的。
- 一个包依赖另一个包时，会自动排在它上面；缺了依赖、版本不够或者被停用，都会写明原因，这个包暂时不启用。
- 包需要更新的游戏版本时，也会写明。

## 自己做一个包

做音乐包最简单的办法是官网的 [BGM MOD 制作](/zh/mods/bgm/)工具，它会生成下面这些文件。想手工做，或者了解包里有什么，看这一节。

### 包里有什么

```text
mod.json        包的信息（必需）
audio/          音乐与语音
campaign/       追加剧本
art/            美术
dialogue/       台词与语言
data/           数值
```

只放用得到的目录。发布时把整个文件夹压缩成 zip，扩展名改成 `.srw64mod`；`mod.json` 放在压缩包最外层，或者在唯一的一个顶层文件夹里都可以。

### mod.json

```json
{
  "schema": "srw64.mod.v1",
  "id": "yourname.bgm",
  "version": "1.0.0",
  "name": { "zh-Hans": "我的 BGM", "en": "My BGM", "ja": "マイ BGM" },
  "description": { "zh-Hans": "替换了战斗曲。" },
  "authors": ["yourname"],
  "license": "CC-BY-4.0"
}
```

| 字段 | 说明 |
| --- | --- |
| `schema` | 固定写 `srw64.mod.v1` |
| `id` | 包的唯一名字，只能用字母、数字和 `.` `_` `-`，最多 64 个字符。建议写成「作者.名字」，**发布后不要再改** |
| `version` | 版本号，写成 `1.0.0` 这样的格式 |
| `name` | 显示的名字，可以是一个字符串，也可以按语言分别写（`zh-Hans`、`en`、`ja`） |
| `description` | 可选，说明文字，写法同 `name` |
| `authors` | 可选，作者列表 |
| `license` | 许可证，必须是允许再分发的：`CC-BY-4.0`、`CC-BY-SA-4.0`、`CC-BY-NC-4.0`、`CC-BY-NC-SA-4.0`、`CC0-1.0`、`MIT`、`GPL-3.0-or-later` |
| `game` | 可选，需要的游戏版本，例如 `">=0.5.1"` |
| `requires` | 可选，必需的其他包，例如 `{ "someone.base": ">=1.0" }` |
| `optional` | 可选，有就一起用的包，写法同 `requires` |
| `conflicts` | 可选，不能同时启用的包，例如 `{ "someone.old": "*" }` |

版本要求写成 `*`（任意版本），或者用空格隔开的几个条件，比如 `">=1.0 <2"`。`mod.json` 里不认识的字段会被当成错误，不要自己加字段。

### 检查

[源代码仓库](https://github.com/dyzz/srw64-recomp)里的 `tools/mods/validate.py` 用和游戏相同的规则检查一个包，问题会逐条列出：

```bash
python3 tools/mods/validate.py yourname.bgm-1.0.0.srw64mod
```

## 版权

包里的东西必须是你有权再分发的。用原作动画歌曲之类的素材做的包只适合自己使用，不要公开分发；我们也不会收录这类包。
