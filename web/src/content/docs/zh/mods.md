MOD 包是一个文件夹，或者把它压缩成的一个 `.srw64mod` 文件，里面只放数据，不放程序。游戏读到启用的包，就用包里的内容替换原版对应的部分；没有包的地方一切照原版。

**现在能生效的有音乐和战斗语音、数值、名字、头像、地图图标、新机体与新人物、追加剧本、剧情事件和语言包**：替换曲目、指定谁打仗时放哪首歌、给战斗台词配音，做法见[音乐 MOD](../mod-music/)；改机体、驾驶员和武器的数值，见[数值 MOD](../mod-data/)；改名字、换头像和地图图标，见[名字、头像与地图图标 MOD](../mod-names/)；加入原版没有的机体、武器和人物（会变形、会在地图上合体的机体，合体技，自己的立绘、战斗图、战斗台词和语音），见[新机体、新人物与新武器 MOD](../mod-units/)；给原版关卡加事件、让人物加入或改变剧情分支，见[剧情 MOD](../mod-story/)；把几关自己编排的关卡串成战役（可以用自己画的地图、写新台词），见[追加剧本 MOD](../mod-campaign/)；增加新的阅读语言或换掉现有语言的文字，见[语言包 MOD](../mod-language/)。原版其他美术的替换会陆续开放，包格式已经为它们留好了位置。

MOD 功能需要 0.5.1 或更新的版本；音乐和地形适应以外的部分需要 0.5.2，剧情 MOD 和语言包需要 0.5.3，Switch 版需要 0.5.3.1；新机体、新人物、新武器，以及关卡编辑器做的新格式追加剧本需要 0.5.4。

## 安装

1. 打开 MOD 管理：点标题画面右下角的「MOD」，或者打开设置，在「通用」页点「MOD」。
2. 把 `.srw64mod` 文件（`.zip`、包文件夹、从 Thunderstore 下载的包、装着几个 `.srw64mod` 的 zip 也可以）**拖进游戏窗口**，游戏会在后台安装，装好后在画面上方提示，并打开「已安装」页。
3. 也可以点「打开文件夹」，把包文件直接放进 MOD 文件夹，下次打开 MOD 管理时会自动安装。从 0.5.4 起，游戏直接读包文件，不再解压，安装就是把文件放到位，大包也是一瞬间。同样从 0.5.4 起（Switch 版从 0.5.3.1 起），包文件解压出来的文件夹也可以直接放进去，文件夹名不用改。

同一个包装新版本时会替换旧版本，旧版本和删除的包都会移到 MOD 文件夹里的 `.trash`，不会直接删掉（旧的语音包占地方最多，可以自己清空 `.trash`）。装不上的文件会在 MOD 页列出原因，不会被当成坏掉的包，可以在那里直接删掉。

安卓版：把包文件放进「文件」里 Marchwind64 文件夹的 `mods/`，游戏启动或打开 MOD 页时自动安装；也可以在 MOD 页点「从文件安装」直接选文件。

![安卓版安装 MOD：设置 › 通用 › MOD，再点「从文件安装」选文件，或把文件放进 Documents/Marchwind64/mods](/media/android-mod-install-zh.webp)

Switch 版：用读卡器或 FTP 把包文件（或解压出来的文件夹）放进 SD 卡上的 `/switch/Marchwind64/mods/`，再启动游戏或打开 MOD 页就会安装。0.5.4 以前装大的语音包时，启动画面会显示安装进度，可能需要几分钟；0.5.4 起不再需要等。

## 管理

「已安装」页列出每个包的名字、版本、作者、包含的内容和状态，可以启用、停用或删除（删除要按两次确认）。

- **列表上面的包覆盖下面的**：两个包都替换了同一首歌时，用上面那个包的。
- 一个包依赖另一个包时，会自动排在它上面；缺了依赖、版本不够或者被停用，都会写明原因，这个包暂时不启用。
- 包需要更新的游戏版本时，也会写明。
- **用了 MOD 的存档，要启用那个 MOD 才能读**：没启用时游戏会说需要哪个包，然后回到标题画面，存档本身不受影响。包加的新机体、新人物的编号记在存档旁边，后来装的包让编号变了，读档时会自动改过来。

## 自己做一个包

多数包都能用官网的网页工具做，全部在浏览器里完成，直接导出 `.srw64mod`：[BGM](/zh/mods/bgm/)、[战斗语音](/zh/mods/voices/)、[数值](/zh/mods/data/)、[名字与头像](/zh/mods/names/)、[地图图标](/zh/mods/icons/)、[机体制作器](/zh/mods/units/)（新机体、新人物、新武器）和[关卡编辑器](/zh/mods/editor/)（追加剧本）。想手工做，或者了解包里有什么，看这一节。

### 包里有什么

```text
mod.json        包的信息（必需）
audio/          音乐与语音
campaign/       追加剧本
story/          剧情事件（剧情 MOD）
art/            美术
dialogue/       名字、台词与语言
data/           数值、新机体与新人物
```

只放用得到的目录。发布时把整个文件夹压缩成 zip，扩展名改成 `.srw64mod`；`mod.json` 放在压缩包最外层，或者在唯一的一个顶层文件夹里都可以。游戏直接从包里读文件，所以图片（`.png`）和音频（`.ogg`）最好用「仅存储」不压缩（命令行 `zip -0`，7-Zip 选「仅存储」）：它们本来就压缩过，再压一遍不会变小，只会让游戏每次读都要多解一遍。网页上的 MOD 制作工具和仓库的 `tools/mods/pack.py` 已经这样做了。

### mod.json

```json
{
  "schema": "srw64.mod.v1",
  "id": "yourname.bgm",
  "version": "1.0.0",
  "name": { "zh-Hans": "我的 BGM", "en": "My BGM", "ja": "マイ BGM" },
  "description": { "zh-Hans": "替换了战斗曲。" },
  "authors": ["yourname"],
  "license": "CC-BY-4.0"
}
```

| 字段 | 说明 |
| --- | --- |
| `schema` | 固定写 `srw64.mod.v1` |
| `id` | 包的唯一名字，只能用字母、数字和 `.` `_` `-`，最多 64 个字符。建议写成「作者.名字」，**发布后不要再改** |
| `version` | 版本号，写成 `1.0.0` 这样的格式 |
| `name` | 显示的名字，可以是一个字符串，也可以按语言分别写（`zh-Hans`、`zh-Hant`、`en`、`ja`，以及装着的[语言包](../mod-language/)的语言；繁体没写时用简体，其他没写的语言依次找退回语言、日文） |
| `description` | 可选，说明文字，写法同 `name` |
| `authors` | 可选，作者列表 |
| `license` | 许可证，必须是允许再分发的：`CC-BY-4.0`、`CC-BY-SA-4.0`、`CC-BY-NC-4.0`、`CC-BY-NC-SA-4.0`、`CC0-1.0`、`MIT`、`GPL-3.0-or-later` |
| `game` | 可选，需要的游戏版本，例如 `">=0.5.1"` |
| `requires` | 可选，必需的其他包，例如 `{ "someone.base": ">=1.0" }` |
| `optional` | 可选，有就一起用的包，写法同 `requires` |
| `conflicts` | 可选，不能同时启用的包，例如 `{ "someone.old": "*" }` |

版本要求写成 `*`（任意版本），或者用空格隔开的几个条件，比如 `">=1.0 <2"`。`mod.json` 里不认识的字段会被当成错误，不要自己加字段。

### 检查

[源代码仓库](https://github.com/dyzz/srw64-recomp)里的 `tools/mods/validate.py` 用和游戏相同的规则检查一个包，问题会逐条列出：

```bash
python3 tools/mods/validate.py yourname.bgm-1.0.0.srw64mod
```

## 版权

包里的东西必须是你有权再分发的。用原作动画歌曲之类的素材做的包只适合自己使用，不要公开分发；我们也不会收录这类包。
