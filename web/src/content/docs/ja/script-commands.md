ステージの各イベントは 16 ビットのワードの並びです。命令コード `3D31`〜`3D79` のあとにその引数が続き、条件命令 `3E00`〜`3E1D` が条件ブロックを作り、コンテキストマーカー `3DD0`〜`3DDB` が現在の主人公のルートや選択肢に応じて実行する部分を選び、`FFFF` でイベントが終わります。[ミニステージ](../mini-stage/)では命令を `{"op": "3D45", "args": [1]}` のように書き、条件命令とマーカーも同じ書き方です。

このページは [`config/data/original-jp-v1.json`](https://github.com/dyzz/srw64-recomp/blob/main/config/data/original-jp-v1.json) の `stage_scripts` テーブルから生成しています。「コードで確認」はゲームの処理関数から意味を確認済み、「構造を確認」は読み書きする場所は分かっているものの、役割はまだ完全には分かっていないことを示します。

各項目の根拠（どのゲームコードに基づくか）とゲーム内での検証結果は中国語で記録しています。各項目から[中国語のページ](../../../zh/docs/script-commands/)の該当箇所へリンクしています。

## イベントの種類

イベントの種類によって、いつ判定されるかと 4 つの発動条件（`header`）の読み方が決まります。

| 種類 | 名前 | 判定のタイミング | 発動条件 |
|---|---|---|---|
| 0 | ターン開始 | フェイズ 0 | 1. ターン数：現在のターン ≥ この値<br>2. フェイズ：現在のフェイズ 8010F5E8 と一致すること（1 味方 / 2 敵）<br>3. 予約<br>4. 予約 |
| 1 | 遅延カウント（3D52 で開始） | フェイズ 0 | 1. 初期状態：実行時に 3D52 が 0xFD に書き換える<br>2. フェイズ：実行時に 3D52 が書き換える。4 = 任意<br>3. 予約<br>4. 予約 |
| 2 | ユニット撃破／退場 | 常時 | 1. 条件変数：100〜115 の場合、変数が 3 の間は発動しない（8009DE7C が各ステージ開始時に 100〜114 を 3 にし、スクリプトが 0 を書くと有効になる）。それ以外の番号は調べない。0 は条件なし<br>2. キャラクター：このキャラクターが乗る機体の HP 割合が 0 になる<br>3. 予約<br>4. 予約 |
| 3 | HP が割合を下回る | 常時 | 1. キャラクター：キャラクター 138 は特例：機体の HP < 11 のときだけ続行<br>2. 割合：HP% ≤ この値 かつ出撃中<br>3. 予約<br>4. 予約 |
| 4 | 交戦イベント（戦闘後、フェイズ 7） | フェイズ 7 | 1. キャラクター A：0 = 任意<br>2. キャラクター B：0 = 任意<br>3. 予約<br>4. 予約 |
| 5 | 交戦イベント（戦闘前、フェイズ 4） | フェイズ 4 | 1. キャラクター A：0 = 任意<br>2. キャラクター B：0 = 任意<br>3. 予約<br>4. 予約 |
| 6 | 敵全滅 | 常時 | 1. 最終ターン：現在のターン（0 起算）≤ この値 のときだけ発動。8009E834 はこの値 < 現在のターンで戻る<br>2. フェイズ：4 = 任意<br>3. 予約<br>4. 予約 |
| 7 | 陣営の残り数 | 常時 | 1. 陣営の選択：2 → 第三勢力の数 0x9B2、それ以外は敵の数 0x9B1<br>2. 上限数：残り数 ≤ この値<br>3. フェイズ：4 = 任意<br>4. 条件変数：100〜115 の場合、変数が 3 の間は発動しない（8009DE7C が各ステージ開始時に 100〜114 を 3 にし、スクリプトが 0 を書くと有効になる）。それ以外の番号は調べない |
| 8 | エリア到達（3D57 で有効化） | フェイズ 0、フェイズ 1、フェイズ 2、フェイズ 6 | 1. ターンまたはモード：数値 = 現在のターン ≥ この値。0xFF = 到達で発動。0xFE = 味方が全員離脱<br>2. 対象：N×1000 + キャラクター（または 500 + 陣営。21 = リストで最初に出撃中のキャラクター）<br>3. x の範囲：x0×10 + 幅<br>4. y の範囲：y0×10 + 高さ |
| 9 | 説得（0x992、フェイズ 6） | フェイズ 0、フェイズ 1、フェイズ 2、フェイズ 6 | 1. 説得する側：800A4634 が登録順に、未実行・条件成立・両者が上下左右に隣接している最初の枠を探し、engine+0x992 に書き込む<br>2. 相手：相手の陣営は問わない<br>3. 条件変数：0xFFF8（−8）は条件なし。それ以外は 変数 == 条件値 のときだけ「説得」が出る。ステージをまたぐ多段階の説得はこれでつなぐ<br>4. 条件値 |
| 10 | 登録のみ（ポーリングしない） | なし | 1. 予約<br>2. 予約<br>3. 予約<br>4. 予約 |
| 11 | 登録のみ（ポーリングしない） | なし | 1. 予約<br>2. 予約<br>3. 予約<br>4. 予約 |
| 12 | 開幕イベント（フェイズ C1） | engine+4 = 0xC1 | 1. 予約<br>2. 予約<br>3. 予約<br>4. 予約 |
| 13 | フェイズ C2 イベント（初期配置） | engine+4 = 0xC2 | 1. 予約<br>2. 予約<br>3. 予約<br>4. 予約 |
| 14 | 終了イベント（フェイズ C3、3D4A の後） | engine+4 = 0xC3 | 1. 予約<br>2. 予約<br>3. 予約<br>4. 予約 |

## コンテキストマーカー

マーカーに来たとき、現在の状況に合えばそのまま続け、合わなければ次に合うマーカーかイベントの終わりまで飛ばします。

| マーカー | 名前 | 一致の条件 |
|---|---|---|
| `3DD0` | 共通部分（どの状況でも） | 常に |
| `3DD1` | アークライト・ブルー ルート | 現在の主人公 |
| `3DD2` | セレイン・メネス ルート | 現在の主人公 |
| `3DD3` | ブラッド・スカイウィンド ルート | 現在の主人公 |
| `3DD4` | マナミ・ハミル ルート | 現在の主人公 |
| `3DD5` | リアル系主人公（3DD1/3DD2） | 主人公の分類 |
| `3DD6` | スーパー系主人公（3DD3/3DD4） | 主人公の分類 |
| `3DD7` | 男性主人公（3DD1/3DD3） | 主人公の分類 |
| `3DD8` | 女性主人公（3DD2/3DD4） | 主人公の分類 |
| `3DD9` | 選択肢 1 番目 | 選択肢の結果 |
| `3DDA` | 選択肢 2 番目 | 選択肢の結果 |
| `3DDB` | 選択肢 3 番目 | 選択肢の結果 |

## 引数の種類

引数の種類は値の範囲を表します。表にない種類は各命令の引数名を参照してください。

| 種類 | 意味 |
|---|---|
| `actor` | キャラクター番号（base:actors） |
| `text` | テーブル 0 のテキスト番号 |
| `unit` | 機体番号（base:units） |
| `flag` | 2 ビット変数 0〜199 |
| `scene` | シーン番号 |
| `group` | 出撃データのグループ番号 |
| `position` | 上位バイト x／下位バイト y。0x40〜0x44 は 3D54 で記憶した位置からの相対 |
| `x` | マス x |
| `y` | マス y |
| `count` | カウント |
| `frames` | フレーム数 |
| `se` | 効果音番号 |
| `bgm` | 曲番号 |
| `event_slot_type1` | このシーンのタイプ 1 イベントの登録順 |
| `event_slot_type8` | このシーンのタイプ 8 イベントの登録順 |
| `actor_or_group` | 500 未満はキャラクター番号、500 以上はグループ（値 − 500） |
| `bool` | スイッチ |
| `value` | 数値 |
| `side` | フェイズ 1 味方 / 2 敵 / 3 第三勢力（4 = 任意） |
| `deploy_side` | 出撃データの陣営 0/1/2（3 → 0、4 → 2） |
| `raw` | 未解明 |
| `faction` | 陣営 0 味方 / 1 敵 / 2 第三勢力 |
| `map` | マップ番号（base:map_assets。8010F5EE に書き込む） |

## 変数

2 ビット（値 0〜3）の変数が 200 個あり、`0x8015E818` に置かれます。条件命令で読み書きし、ステージをまたいで保持されます。

## 出撃データ（28 バイト）

出撃データはステージのユニット配置で、1 件 14 ハーフワード、グループ番号 999 で終わります。「ミニステージの項目」はステージ定義の `deployments` での項目名です。

| オフセット | バイト | 名前 | ミニステージの項目 | 確認の程度 |
|---|---|---|---|---|
| `+0` | 2 | グループ番号 | `group` | コードで確認 |
| `+2` | 2 | x | `x` | コードで確認 |
| `+4` | 2 | y | `y` | コードで確認 |
| `+6` | 2 | パイロット | `actor` | コードで確認 |
| `+8` | 1 | 未解明のバイト | `byte8` | 未解明 |
| `+9` | 1 | レベル補正 | `level_offset` | コードで確認 |
| `+10` | 2 | 機体 | `unit` | コードで確認 |
| `+12` | 2 | 改造インデックス | `upgrade` | コードで確認 |
| `+14` | 6 | 未解明 | `raw14, raw16, raw18` | 未解明 |
| `+20` | 2 | 陣営 | `faction` | コードで確認 |
| `+22` | 2 | 行動フラグ | `behavior` | 構造を確認 |
| `+24` | 2 | 追加値 | `extra` | 構造を確認 |
| `+26` | 2 | 未解明 | `raw26` | 未解明 |
