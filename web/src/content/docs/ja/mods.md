MOD パッケージは 1 つのフォルダー、またはそれを圧縮した 1 つの `.srw64mod` ファイルです。中身はデータだけで、プログラムは含みません。有効なパッケージがあると、ゲームはその内容で元の対応する部分を置き換えます。パッケージが何も指定していないところは、すべて元のままです。

**現在反映されるのは音楽と地形適応です**。曲の差し替えと、キャラクターやユニットごとの戦闘曲の指定ができます（[音楽 MOD](../mod-music/)）。ユニットとパイロットの地形適応も変えられます（[数値 MOD](../mod-data/)）。追加シナリオ・グラフィック・台詞・ボイス・その他の数値は順次対応する予定で、パッケージの形式にはすでにその場所が用意されています。

MOD 機能にはバージョン 0.5.1 以降が必要です。

## インストール

1. MOD 管理を開きます。タイトル画面右下の「MOD」をクリックするか、設定を開いて「一般」ページの「MOD」をクリックします。
2. `.srw64mod` ファイル（`.zip` やパッケージのフォルダーでも可）を**ゲームのウィンドウにドラッグ**します。バックグラウンドでインストールされ、画面上部に通知が出て「インストール済み」ページが開きます。
3. 「フォルダーを開く」で MOD フォルダーを開き、パッケージのファイルを直接置くこともできます。次に MOD 管理を開いたときに自動でインストールされます。

同じパッケージの新しいバージョンをインストールすると、古いバージョンと置き換わります。古いバージョンや削除したパッケージは、すぐには消さず MOD フォルダー内の `.trash` に移します。

Android 版ではまだ MOD をインストールできません。

## 管理

「インストール済み」ページには、各パッケージの名前・バージョン・作者・内容・状態が並びます。有効・無効の切り替えと削除（確認のため 2 回押します）ができます。

- **一覧で上にあるパッケージが下のものより優先されます**。2 つのパッケージが同じ曲を差し替えている場合は、上のほうが使われます。
- 別のパッケージに依存するパッケージは、自動でその上に並びます。依存先がない・バージョンが足りない・無効になっている場合は理由が表示され、そのパッケージは有効になりません。
- より新しいゲームのバージョンが必要な場合も表示されます。

## パッケージを作る

音楽パッケージをいちばん簡単に作るには、公式サイトの [BGM MOD メーカー](/ja/mods/bgm/)を使います。下のファイルを自動で作ってくれます。手作業で作りたいときや、中身を知りたいときはこの節を読んでください。

### パッケージの中身

```text
mod.json        パッケージの情報（必須）
audio/          音楽とボイス
campaign/       追加シナリオ
art/            グラフィック
dialogue/       台詞と言語
data/           数値
```

使うフォルダーだけを入れます。公開するときはフォルダー全体を zip に圧縮し、拡張子を `.srw64mod` に変えます。`mod.json` は圧縮ファイルの一番上、またはその中にある唯一のフォルダーの直下に置きます。

### mod.json

```json
{
  "schema": "srw64.mod.v1",
  "id": "yourname.bgm",
  "version": "1.0.0",
  "name": { "zh-Hans": "我的 BGM", "en": "My BGM", "ja": "マイ BGM" },
  "description": { "ja": "戦闘曲を差し替えます。" },
  "authors": ["yourname"],
  "license": "CC-BY-4.0"
}
```

| フィールド | 意味 |
| --- | --- |
| `schema` | 常に `srw64.mod.v1` |
| `id` | パッケージ固有の名前。英数字と `.` `_` `-` で 64 文字まで。「作者.名前」の形がおすすめです。**公開後は変えないでください** |
| `version` | バージョン。`1.0.0` の形式で書きます |
| `name` | 表示する名前。1 つの文字列でも、言語ごと（`zh-Hans`・`en`・`ja`）でも書けます |
| `description` | 任意。説明文で、書き方は `name` と同じです |
| `authors` | 任意。作者の一覧 |
| `license` | ライセンス。再配布を認めるもののみ：`CC-BY-4.0`・`CC-BY-SA-4.0`・`CC-BY-NC-4.0`・`CC-BY-NC-SA-4.0`・`CC0-1.0`・`MIT`・`GPL-3.0-or-later` |
| `game` | 任意。必要なゲームのバージョン。例：`">=0.5.1"` |
| `requires` | 任意。必須のパッケージ。例：`{ "someone.base": ">=1.0" }` |
| `optional` | 任意。あれば一緒に使うパッケージ。書き方は `requires` と同じです |
| `conflicts` | 任意。同時に有効にできないパッケージ。例：`{ "someone.old": "*" }` |

バージョンの条件は `*`（どのバージョンでも可）か、スペースで区切った条件をいくつか書きます（例：`">=1.0 <2"`）。`mod.json` に知らないフィールドがあるとエラーになるので、独自のフィールドは追加しないでください。

### チェック

[ソースコードのリポジトリ](https://github.com/dyzz/srw64-recomp)にある `tools/mods/validate.py` は、ゲームと同じルールでパッケージを検査し、問題を一つずつ表示します。

```bash
python3 tools/mods/validate.py yourname.bgm-1.0.0.srw64mod
```

## 著作権

パッケージに入れるものは、すべて再配布する権利があるものにしてください。原作アニメの楽曲などで作ったパッケージは個人利用に限り、公開しないでください。そうしたパッケージは公式にも掲載しません。
