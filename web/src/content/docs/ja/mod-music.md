音楽 MOD は、元の曲を 1 曲ずつ音声ファイルに差し替えます。その曲が流れる場所はすべて差し替わります。戦闘曲・ステージ曲・シナリオの曲・タイトル・サウンドセレクトです。キャラクターやユニットごとに、戦闘でどの曲を流すかも指定できます。

パッケージのインストールと管理は [MOD パッケージ：インストールと作り方](../mods/)を参照してください。

## ウェブツールで作る

[BGM MOD メーカー](/ja/mods/bgm/)は、すべての作業をブラウザー内で行います。**音声はどこにもアップロードされません**。

1. パッケージの情報を入力します：ID・バージョン・名前・作者・ライセンス。
2. 49 曲の一覧で、差し替えたい行に音声ファイルをドロップします。mp3・wav・flac・m4a・ogg が使えます。ゲームで使う形式に自動で変換し、すでに Ogg Vorbis のファイルはそのまま使います。
3. 「編集」でその曲を設定します。
   - **ループ**：曲全体をループ、区間をループ、一回だけ再生から選びます。区間は波形上の青（開始）と金（終了）の線をドラッグして決め、手を離すと近くのゼロクロスに合わせます。「つなぎ目を試聴」でループのつなぎ目を確かめられます。
   - **音量補正（dB）**：この曲と、ほかの差し替え曲の平均レベルが横に表示されるので、音量をそろえられます。
   - **曲名**：サウンドセレクトに表示する名前です。言語ごとに書けます。
4. 必要なら「戦闘曲」で、キャラクターやユニットが戦うときの曲を指定します。
5. 「.srw64mod を書き出す」をクリックし、できたファイルをゲームのウィンドウにドラッグしてインストールします。

あとで直したいときは「既存の .srw64mod を開く」で読み込み直して編集を続けられます。

## ゲーム内での表示

- サウンドセレクトでは、差し替えた曲の右に「MOD」と表示されます。曲名を書いた場合はその名前が出ます。
- 設定の「一般」ページに「MOD 音楽」のオン・オフと音量（25〜100%）があります。次の曲から反映されます。
- カラオケモードは元の曲のままです。歌詞が元の曲のテンポに合わせてあるためです。

## 元のゲームの曲の選び方

- **戦闘曲**：味方ユニットが戦闘に参加していれば、攻撃側か防御側かに関係なく、**味方ユニットのメインパイロット**の戦闘曲が流れます。味方がいない戦闘では、攻撃側ユニットの戦闘曲です。
- 次の場合は元のゲームが決まった曲を流し、MOD の戦闘曲指定では変わりません：ゴッドガンダムの明鏡止水（ゴッドガンダムH）、シャッフル同盟の S 形態、V-MAX 発動中、ヴァル＝ア・アヴィ＝ルー・ジェイ＝レンのいずれかが参加する戦闘。ただし、それらの曲自体は差し替えられます。
- 戦闘が終わってもステージ曲には戻らず、次のフェイズが始まるまで戦闘曲が流れ続けます。ループを作るときは気をつけてください。
- ステージ曲はフェイズの始めに毎回流れ直します。
- 敵増援の登場時に流れる短い曲（曲番号 38）は、既定では一回だけ流れ、終わるとゲームが自動でステージ曲に戻します。

## 手作業で作る

ウェブツールが書き出すのは次のファイルです。

```text
yourname.bgm/
  mod.json
  audio/
    music/<曲番号>.ogg
    music.json        任意
```

- ファイル名は**曲番号**です（10 進数、ゼロ埋めなし）。たとえば `7.ogg` は 7 番「メインテーマ」を差し替えます。49 曲の曲番号・曲名・使われる場所は[曲番号の対照表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/songs.csv)にあります。
- 形式は **Ogg Vorbis** だけです。サンプリングレートは問わず、モノラルでもステレオでも構いません。Vorbis だけにしているのは、ループ位置をサンプル単位で正確にするためです。MP3 は先頭と末尾に余白が付くため、ループのつなぎ目に隙間ができます。ほかの形式は先に変換してください。例：

  ```bash
  ffmpeg -i in.wav -c:a libvorbis -q:a 6 out.ogg
  ```

`music.json` はなくても構いません。`.ogg` だけなら、曲全体をループし、音量も曲名も元のままです。細かく設定するときは次のように書きます。

```json
{
  "schema": "srw64.music.v1",
  "tracks": {
    "7":  { "loop": [441000, 5292000], "gain": -2.0,
            "title": { "zh-Hans": "…", "en": "…", "ja": "…" } },
    "38": { "loop": false }
  },
  "battle": {
    "pilot": { "36": 7 },
    "unit":  { "97": 12 }
  }
}
```

| フィールド | 意味 |
| --- | --- |
| `tracks.<曲番号>.loop` | `[開始, 終了]`。単位は**サンプル数**（秒ではありません）で、終了まで来ると開始に戻ります。`false` は一回だけ再生、`true` は曲全体をループします。書かなければファイルの `LOOPSTART`／`LOOPLENGTH` タグを使い、タグもなければ曲全体をループします |
| `tracks.<曲番号>.gain` | 音量補正（dB）。負の値で小さくなります |
| `tracks.<曲番号>.title` | サウンドセレクトに表示する曲名。言語ごとに書きます |
| `battle.pilot.<キャラクター番号>` | このキャラクターが味方のメインパイロットのとき、戦闘で流す曲（曲番号） |
| `battle.unit.<ユニット番号>` | 味方がいない戦闘で、このユニットが攻撃側のときに流す曲 |

キャラクター番号とユニット番号は[キャラクター表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/pilots.csv)と[ユニット表](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/units.csv)にあり、それぞれの元の戦闘曲も載っています。複数のパッケージが同じ曲や同じキャラクターを指定している場合は、一覧で上にあるパッケージが優先されます。

### AI に任せる

リポジトリの [`docs/guide/audio-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/audio-mods) フォルダーに、形式の詳しい説明とすべての対照表があります（説明は中国語）。フォルダーごと AI アシスタントに渡せば、ファイル名の変更や形式の変換、`mod.json` と `music.json` の作成を任せられます。
