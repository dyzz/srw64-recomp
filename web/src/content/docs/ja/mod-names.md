この MOD はゲームが**表示する**名前と顔グラフィックだけを変えます。会話、話者名、ステータス画面、戦闘前の確認、図鑑、マップのラベルが追従します。セーブには原作の名前のまま残るので、パッケージを無効にすれば元に戻り、セーブはほかの環境や原作でも普通に読めます。

手で書かなくても、[名前・顔グラフィック MOD メーカー](/ja/mods/names/) で名前を入力し画像を選べば、そのまま .srw64mod を書き出せます。画像は自動で切り抜き・縮小されます。

パッケージの導入と管理は [MOD パッケージ](../mods/) へ。0.5.2 以降が必要です。

## パッケージの中身

```text
yourname.heroes/
  mod.json
  dialogue/names.json          名前
  art/portraits/133.png        顔グラフィック。ファイル名はキャラクター番号
```

どちらか一方だけでも構いません。

## 名前（dialogue/names.json）

```json
{
  "schema": "srw64.mod-names.v1",
  "heroes": {
    "super-male": {
      "hero":    { "ja": { "name": "タクマ", "surname": "アマノ", "nickname": "タクマ" } },
      "partner": { "ja": { "name": "ミナト", "surname": "ホウジョウ" } }
    }
  },
  "unit": { "ja": "デイブレイク" },
  "pilots":  { "133": { "ja": { "name": "シンゴ", "full": "北条真吾" } } },
  "units":   { "184": { "ja": "ゴーショーグン改" } },
  "weapons": { "731": { "ja": "ビッグバズーカ" } }
}
```

どの項目も言語ごとに書きます：`zh-Hans`（簡体字中国語）、`zh-Hant`（繁体字中国語。ないときは簡体字のもの）、`en`、`ja`。書かなかった言語はいつもの名前のままです。複数のパッケージが同じ名前を変えるときは、MOD 管理の一覧で上にあるパッケージが優先されます。

### オリジナル主人公・パートナー・部隊名（heroes、unit）

- `heroes` は四つのルートで書きます：`super-male`（スーパー系男性）、`super-female`（スーパー系女性）、`real-male`（リアル系男性）、`real-female`（リアル系女性）。それぞれ `hero`（主人公）と `partner`（パートナー）があります。
- 言語ごとに `name`（名前、必須）、`surname`（姓）、`nickname`（愛称。ないときは名前）を書きます。フルネームは言語に合わせてつなぎます。日本語は「・」、中国語は「·」、英語は空白です。
- 原作は会話の中の主人公の名前を名前の欄から埋めるので、会話も追従します。
- 部隊名を変えると、命名の場面は「気に入らない」の分岐に進みます。主人公がマーチウィンドを断り、パッケージの名前を自分で提案します。すでに見た場面はやり直しません。

### ほかのキャラクター・ユニット・武器（pilots、units、weapons）

- 番号で書きます。番号は [ID 表](/ja/mods/ids/) で。キャラクターは `name`（略称、必須）と `full`（フルネーム。ないときは略称）、ユニットと武器は名前をそのまま書きます。
- 武器メニューの「格」「射」と P・B・MAP の印は自動で付きます。
- 名前そのものが変わるので、話者名・ステータス画面・マップは追従しますが、**会話の本文に出てくるその名前は変わりません**。

### 長さ

名前はセーブに書かないので原作の文字数の制限は受けませんが、狭い場所があります。マップのラベルや戦闘画面の名前欄は幅が決まっています。

- 主人公の名前・姓・愛称が原作のマス数（名前と姓は 7 マス、愛称は 5 マス）を超えるか、今いちばん長い訳名より広いとき、部隊名が 10 マスを超えるときは、ログに `SRW64_MOD_NAMES_WARNING` が出ます。名前はそのまま使われます。愛称はいちばんよく表示されるので、5 マス前後に収めるのがおすすめです。
- 上限：主人公の名前・姓・愛称は 16 文字、部隊名とほかの名前は 24 文字です。超えたとき、知らない項目や言語を書いたときは、**ファイルが丸ごと使われず**、ログに `SRW64_MOD_NAMES_PROBLEM` が出ます。
- 改行、全角スペース、`< > { }` は使えません。前後に空白も置けません。

日本語で画像を原作にしているとき、原作の画面はゲーム内蔵の字形で描くため、パッケージの名前は描けません。そこではその名前だけをこの移植版のフォントで描き、まわりの文字は原作の字形のままです。

## 顔グラフィック（art/portraits）

- ファイル名は**キャラクター番号**と `.png` です。例：`art/portraits/133.png`。
- 正方形で、一辺 96〜2048 ピクセル、96 の倍数（96、192、384、768……）。透明部分があってもよく、そこからは後ろの画面が見えます。
- 会話・戦闘・ステータス画面・戦闘前の確認・図鑑のすべてでこの絵を使います。画像が原作でも HD でも MOD の絵が出ます。
- 同じ原作の顔グラフィックを使うキャラクター（同じ人物の別番号など）は、一緒に変わります。
- 顔グラフィックのあるキャラクター番号でないファイル名や、大きさが合わないものは使われず、ログに `SRW64_MOD_PORTRAITS_PROBLEM` が出ます。

## サンプル

サンプルパッケージ「改名サンプル」のソースは [`config/recomp/mods/hero-names`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/hero-names) です。スーパー系男性主人公とパートナー、部隊名を別の名前にします。

数値は [数値 MOD](../mod-data/) へ。
