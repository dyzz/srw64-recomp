数値 MOD はユニット・パイロット・武器そのものの数値を変えます。その数値を読むところはすべて追従します。戦闘の計算、ステータス画面、図鑑です。

パッケージの導入と管理は [MOD パッケージ](../mods/) へ。地形適応は 0.5.1 から、それ以外の項目は 0.5.2 以降が必要です。

## パッケージの中身

```text
yourname.balance/
  mod.json
  data/
    units.json      ユニット番号でユニットを変える
    pilots.json     キャラクター番号でパイロットを変える
    weapons.json    武器番号で武器を変える
```

三つのうちどれを入れても構いません。`mod.json` はほかのパッケージと同じ書き方です。

## 書き方

```json
{
  "184": { "hp": 5200, "armor": 1300, "terrain": { "sea": "A" } },
  "262": { "terrain": { "space": "A" }, "abilities": ["i_field"] }
}
```

- 一番外側のキーは**番号**で、10 進数、ゼロ埋めなしです。`units.json` はユニット番号、`pilots.json` はキャラクター番号、`weapons.json` は武器番号。番号と原作の値は [ID 表](/ja/mods/ids/) で調べられます。
- 番号の下には変える項目だけを書きます。書かなかった項目は原作のままです。
- 複数のパッケージが同じ項目を変えるときは、MOD 管理の一覧で上にあるパッケージが優先されます。

ルールは厳格です。知らない項目、範囲外の値、範囲外の番号はエラーになり、**一つでもエラーがあるとそのファイルは丸ごと使われません**。ゲームのログに `SRW64_MOD_DATA_PROBLEM` の行が出て、パッケージ・ファイル・理由がわかります。

### ユニット（units.json）

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| `hp`、`en` | 最大 HP、EN | HP 1–65535、EN 0–65535 |
| `move` | 移動力 | 1–30 |
| `mobility`、`armor`、`limit` | 運動性、装甲、限界 | 0–65535 |
| `repair_cost` | 修理費 | 0–65535 |
| `upgrade_cap` | 改造上限 | 0–15 |
| `terrain` | 地形適応（後述） | |
| `size` | サイズ | `SS`、`S`、`M`、`L`、`LL` |
| `shield`、`sword` | 盾・剣の有無（シールド防御・切り払い用） | `true` か `false` |
| `parts_slots` | 強化パーツのスロット数 | 0–4 |
| `abilities` | 特殊能力。**全部書く**ので、配列にないものは外れる | 下表 |

特殊能力のキー：

| キー | 能力 | キー | 能力 |
| --- | --- | --- | --- |
| `beam_coat` | ビームコート | `mach_special` | マッハスペシャル |
| `i_field` | Iフィールド | `true_mach_special` | 真マッハスペシャル |
| `planet_defensor` | プラネイトディフェンサー | `god_shadow` | ゴッドシャドー |
| `aura_barrier` | オーラバリア | `getter_vision` | ゲッタービジョン |
| `afterimage` | 分身 | `shungensoku` | 瞬幻足 |
| `hyper_jammer` | ハイパージャマー | `hp_regen_10`、`hp_regen_20` | HP回復 10%、20% |

変形・合体・分離は MOD で付け外しできません。対応する形態のデータが要るためで、原作で持っているものはそのまま残ります。

### パイロット（pilots.json）

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| `melee`、`ranged`、`evade`、`hit`、`reaction`、`skill` | 格闘・射撃・回避・命中・反応・技量（レベル 1 の値） | 0–255 |
| `sp` | レベル 1 の SP 上限 | 0–255 |
| `double_move` | 再行動できるようになるレベル | 0–99 |
| `terrain` | 地形適応（後述） | |
| `skills` | 技能（後述） | |
| `spirits` | 精神（後述） | |

能力値はレベル 1 の値で、以後はレベルが上がるたびに原作どおり成長します（格闘・射撃・反応・技量 +1、回避・命中 +2、SP +2）。

**技能**は「技能のキー: 習得レベルの配列」で書きます。N 番目の数が LN を覚えるレベルで、最大 9 個、小さい順です。`null` でその技能を外します：

```json
{ "133": { "skills": { "newtype": [1, 4, 8, 12, 18, 24, 30, 38, 45], "parry": null } } }
```

| キー | 技能 | キー | 技能 |
| --- | --- | --- | --- |
| `newtype` | NT | `esp` | 超能力 |
| `enhanced` | 強化 | `potential` | 底力 |
| `holy_warrior` | 聖戦士 | `parry` | 切り払い |
|  |  | `shield_defense` | S防御 |

NT・強化・聖戦士・超能力・底力は原作で同じレベル表の行を使うため、一人が持てるのはどれか一つです。新しく書くと元のものと入れ替わります。書かなかった技能は原作のままです。

**精神**は全部書きます。最大 6 個、それぞれ `[精神のキー, 習得レベル]`、レベルは小さい順です：

```json
{ "133": { "spirits": [["focus", 1], ["guts", 5], ["valor", 12], ["soul", 40]] } }
```

精神のキー：`self_destruct` 自爆、`scout` 偵察、`accel` 加速、`mercy` てかげん、`focus` 集中、`alert` ひらめき、`guts` 根性、`strike` 必中、`trust` 信頼、`wall` 鉄壁、`cover` みがわり、`valor` 熱血、`spirit` 気合、`great_guts` ド根性、`luck` 幸運、`drain` 脱力、`effort` 努力、`soul` 魂、`stealth` 隠れ身、`awaken` 覚醒、`refuel` 補給、`provoke` 挑発、`encourage` 激励、`disrupt` かく乱、`friendship` 友情、`love` 愛、`reactivate` 再動、`miracle` 奇跡、`prayer` 祈り、`revive` 復活。

### 武器（weapons.json）

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| `power` | 攻撃力（改造前） | 0–25500、100 の倍数 |
| `range_min`、`range_max` | 最小・最大射程 | 最小 0–30、最大 1–30、最小は最大以下 |
| `hit` | 命中補正 | -128–127 |
| `critical` | クリティカル補正 | -128–127 |
| `ammo` | 弾数。`-1` で弾数なし | -1–99 |
| `en` | 消費 EN | 0–255 |
| `morale` | 必要気力 | 0–255 |
| `terrain` | 武器自身の地形適応 | |

改造による攻撃力の上乗せは原作どおりです。**複数のユニットが持つ武器は、変えると全員分変わります**。ID 表の「装備ユニット」欄に一覧があります。

### 地形適応（terrain）

`terrain` には変える地形だけを書きます：`air`（空）、`land`（陸）、`sea`（海）、`space`（宇）。値は `A`、`B`、`C`、`D` か `-` で、書かなかった地形は原作のままです。ユニット・パイロット・武器とも同じ書き方です。

## 戦闘での地形の合算

ユニット側の適応は、**ユニットの等級とパイロットの等級を足して段階に分けます**：

| 等級 | A | B | C | D | - |
| --- | --- | --- | --- | --- | --- |
| 点数 | 4 | 3 | 2 | 1 | 0 |

| 合計 | 8 以上 | 6–7 | 4–5 | 1–3 | 0 |
| --- | --- | --- | --- | --- | --- |
| 戦闘での扱い | A（120%） | B（100%） | C（80%） | D（60%） | -（0%） |

攻撃側の攻撃力と防御側の装甲に、それぞれ自分の倍率が掛かります。したがって**ユニットがすでに A なら、パイロットを変えないと戦闘では A になりません**。たとえばゴーショーグン（184）は宇宙 A、真吾（133）は B で、合計 7。原作では宇宙で B 扱いです。真吾の宇宙を A にすれば A になります。

武器の地形適応は武器自身だけで決まり、さらにもう一度掛かります。

## 反映のタイミング

パッケージの導入・有効化・無効化のあと、再起動は要りません。ゲームはこれらの数値をメモリに持たず、使うたびにデータから読み直すので：

- **ロードするとき**（インターミッションのセーブもステージ中の中断セーブも同じ）、すべてのユニット・武器・パイロットが今有効なパッケージで作り直されます。パッケージを入れてロードすれば新しい値、無効にしてもう一度ロードすれば原作の値に戻ります。セーブ自体は変わりません。
- ユニットの数値と、武器の攻撃力・最大射程・空の適応は、マップやインターミッションに入ったときに更新されます。
- 武器のほかの項目とパイロットのすべては、一度ロード（または新しく始める）すると反映されます。パイロットはレベルアップでも更新されます。ステージの途中でパッケージを切り替えたら、セーブしてロードしてください。
- 図鑑も変えた値を表示します。

## 共有する記録

能力の記録（能力値・地形・技能）を共有するキャラクターがいます。多くは同じ人物の別番号です（たとえばドモンの 4、273、274）。一人を変えると共有している全員が変わります。ID 表の「能力記録を共有」欄に一覧があります。精神は別の記録で、こちらも共有されることがあります。

同名の項目は別の番号で、変形後の形態、敵版、シナリオ専用のものなどです。変える前に原作の値を確かめてください。

## サンプル

サンプルパッケージ「主力 宇宙適応A」は [MOD ダウンロード](/ja/mods/#srw64.space-a)ページから入手でき、ソースは [`config/recomp/mods/space-a`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/space-a) です。味方の主力で宇宙適応が A 未満のパイロット 20 人とユニット 21 機の宇宙を A にします（マジンガー系、コン・バトラーV、ゲッター3、ゴーショーグン、ジャイアント・ロボ、ダンバイン系、ガンキャノン、ガンタンクなど）。

名前と顔グラフィックは [名前・顔グラフィック MOD](../mod-names/) へ。

### AI に書かせる

リポジトリの [`docs/guide/data-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/data-mods) フォルダに、書式の説明と CSV のユニット表・キャラクター表・武器表があります。フォルダごと AI アシスタントに渡し、欲しい `units.json`、`pilots.json`、`weapons.json` を書いてもらえます。
