追加シナリオは独立した小さなキャンペーンです。決めた順にステージをつなぎ、ステージの間はいつもどおりインターミッション（改造・乗り換え・セーブ）に入り、シナリオ中の選択肢でエンディングを分けることもできます。MOD パッケージに入れて配り、タイトル画面の「MOD → 追加シナリオ」から始めます。**セーブは本編と完全に別です**。

各ステージは 4 つの層でできています。**マップ**（原作のマップか、自分で描いた 1 枚のマップ）、**ユニット**（グループごとにマスに置く）、**シナリオ**（オープニング・戦闘中・クリア後のイベントと台詞）、**流れ**（クリア後にどのステージへ進むか、エンディングか、プレイヤーに選ばせるか）です。

このページで説明する新しい形式には、バージョン 0.5.4 以降が必要です。0.5.1〜0.5.3 で作った古い形式のキャンペーンもそのまま遊べます。

## 今できること

| できる | まだできない |
| --- | --- |
| 複数ステージの連結、選択肢による分岐、複数のエンディング | 本編の途中に新しいステージを挟む |
| 原作のマップ、または自分で描いた 1 枚のマップ（各マスの地形も自分で決める） | 1 つのステージの中で 2 枚目の自作マップに切り替える。自作マップの海面は動かない |
| 新しい台詞、自分で書いた選択肢と作戦目的の文を言語ごとに。原作の「???」シルエットの話し手 | コロニーのアニメーションがある原作のマップを、自作マップの土台にする |
| 各ステージの味方・敵・第三勢力のユニット、増援、敵の行動、落とす強化パーツ、登場時の残量 | 途中のステージから試遊を始める |
| 勝敗条件：全滅、特定の人物の撃墜、エリアへの到達、ターン数、残り機数、HP、説得……組み合わせも可 | |
| 戦闘中の人物の新しい台詞、出撃選択 | |
| パッケージの新ユニット・新キャラクター（[新ユニット・新キャラクター・新武器 MOD](../mod-units/)） | |
| 資金、シナリオ変数、ステージをまたいで引き継ぐ部隊 | |

## ステージエディターを使う

公式サイトの[ステージエディター](/ja/mods/editor/)では、ブラウザーの中でキャンペーンを 1 ステージずつ書けます。**ROM は要らず、何もアップロードしません**。原作のマップ・ユニット・キャラクター・曲は、図鑑と同じく公式サイトから読み込みます。エディターの画面は今のところ英語で表示されます（以下の「」内は画面の表記です）。

- **総覧（Overview）**：ステージの一覧と流れ図（線はクリア後の行き先）、チェック結果、パッケージの情報と主人公のルート。
- **マップ（Map）**：原作のマップをそのまま使うか、自分の画像（PNG・JPEG・WebP）を読み込んでマスに切り分け、各マスの地形を選びます（ブラシ、矩形、つながった範囲の塗りつぶし、スポイト。先に「Guess from the colours」で色から推測してから直すこともできます）。代わりに使う原作のマップを 1 枚選び、原作の画面での見え方を確かめます。
- **ユニット（Units）**：ユニットをグループごとに置き、グループには陣営と登場のタイミングがあります。選んだユニットの機体・パイロット・レベルの加算・改造段数を変えます。敵と第三勢力には、行動（自由に攻撃、特定の人物だけを狙う、特定のマスへ向かう、その場で防御、特定の人物を護衛など）、その場で動かないターン数、撃墜されたときに落とすパーツ、登場時の HP／EN を設定できます。
- **シナリオ（Story）**：出撃前、戦場に入るとき、戦闘中の各イベント、戦闘後。イベントごとにタイミングと条件を選び、動作（台詞、登場、退場、加入、音楽、カメラ、選択肢、変数……）を一つずつ加えます。台詞は中国語・日本語・英語で別々に書き、横にゲーム内での見え方が出ます。ほかに「Battle lines」（戦闘台詞）の欄があります。
- **勝敗と増援（Rules）**：勝利・敗北条件、作戦目的の文、各グループの登場のタイミング、クリア後の行き先（エンディング、次のステージ、プレイヤーに選ばせる）、戦闘の音楽。

プロジェクトはブラウザーに自動で保存されます。上のバーの「Save project」で `.srw64edit` ファイルとして保存でき、作りかけでも保存できます。「Open project」で続きを編集します。どの操作も取り消せます（Ctrl／⌘+Z）。「Template」で 2 ステージのできあがったキャンペーンを読み込み、そこから始められます。できたら「.srw64mod を書き出す」を押します。書き出す前にページがチェックします（ユニットがマップの外にいる、入れないマスにいる、重なっている、各陣営 30 機まで、敵と味方の両方がいるか、など）。書き出したパッケージにはソースが入っているので、「Open project」で読み込み直せます。

## AI に任せる

ファイルを読み書きできる AI エージェント（Claude Code、Codex など）なら、このページのとおりにキャンペーンを丸ごと作れます。[ソースリポジトリ](https://github.com/dyzz/srw64-recomp)のフォルダーで起動し、下の文をコピーして、「シナリオ」の部分を自分のあらすじに書き換えてください。

```text
Marchwind 64（『スーパーロボット大戦64』の PC 向けリコンパイル版）の追加シナリオ MOD（オリジナルキャンペーン）を作り、そのままインストールできる .srw64mod ファイルにまとめてください。

まず次を読み、書式とルールをそのとおりに守ってください：
- https://srw64.dreamquest.club/ja/docs/mod-campaign.md（キャンペーンとステージの書式、マップ、パッケージ作成）
- https://srw64.dreamquest.club/ja/docs/mod-story.md（イベントのタイミング・条件・動作。ステージのイベントも同じ書き方）
- リポジトリのサンプルキャンペーン config/recomp/campaigns/sample（この構成に合わせる）

条件：
- 新しい台詞はすべて ja と zh-Hans の両方を書く（中国語が要らなければ ja と en）。日本語は「」、中国語と英語は “” で囲む
- 人物番号・機体番号・マップ番号は、リポジトリの docs/guide/data-mods/ の表と docs/guide/story-mods/scenes.csv で調べる
- シナリオ変数は 60〜99 だけを使う

シナリオ：
（何ステージか。各ステージでどのマップを使うか、誰が加入するか、敵、いつ増援が来るか、勝利・敗北条件。どこで選択肢を出し、エンディングはいくつか）

進め方：
1. まずステージ表と各ステージの設計を見せる。確認してからファイルを書く
2. 書き終えたら tools/mods/pack.py でパッケージにし（キャンペーン全体をコンパイルしてチェックする）、エラーがあれば直す
3. できたファイルの場所とインストール方法を教える
```

コツ：

- **あらすじは具体的なほどよい。**「第 2 ステージは元の第 5 話のマップ、アムロとカミーユが出撃、敵 6 機、3 ターン目に増援、敵全滅で勝利」くらいまで書きます。番号を AI に選ばせると間違えやすくなります。
- **まずステージエディターで開いてみる。**AI が書いたパッケージはエディターの「Open project」で読み込めるので、マップやユニットの位置が正しいかがひと目でわかります。
- **1 ステージずつ遊んでみる。**単独で入れて、勝てて、クリア後に次のステージにつながることを確かめてから、通しで遊びます。

ここから下は書式の完全な説明です。

## ファイル構成

```text
my-campaign/
  mod.json                 パッケージの情報
  campaign.json            キャンペーン：名前、開始ステージ、主人公のルート、ステージの順番
  stages/<ステージ名>.json      各ステージ
  stages/<ステージ名>.meta.json 省略可：ステージ情報ページの内容
  status.json              省略可：ステージ情報ページの達成状況ルール
  maps/<マップ名>/            省略可：自分で描いたマップ
```

`mod.json` の書き方は [MOD パッケージ](../mods/#modjson)を見てください。`game` は `">=0.5.4"` にします。パッケージ作成時にこれらのソースファイルはパッケージ内の `campaign/` にコンパイルされ、ソースファイルはパッケージに入りません（エディターが書き出したパッケージには、エディターで読み込み直すためのソースが別に入ります）。ステージ情報の 2 つの省略可能なファイルは、サンプルキャンペーンのものをまねてください。

## campaign.json

```json
{
  "schema": "srw64.campaign.v2",
  "id": "yourname.my-campaign",
  "name": {"zh-Hans": "我的战役", "en": "My Campaign", "ja": "マイキャンペーン"},
  "description": {"zh-Hans": "一句话简介。", "en": "One line about it.", "ja": "ひとことで紹介。"},
  "author": "yourname",
  "version": "1",
  "start": "valley",
  "route": 1,
  "stages": ["valley", "showdown"]
}
```

| 項目 | 説明 |
| --- | --- |
| `id` | `mod.json` の `id` と同じにします。キャンペーンのセーブフォルダー名にもなるので、**公開後は変えないでください** |
| `name`・`description` | 追加シナリオページに出る名前と説明。文字列 1 つか、言語ごと（`zh-Hans`・`zh-Hant`・`en`・`ja`・`ko`、[言語パッケージ](../mod-language/)の言語） |
| `start` | 最初のステージ |
| `route` | 主人公のルート。必須です：0 ブラッド、1 マナミ、2 アーク、3 セレイン。原作の台詞には主人公たちの顔グラフィックを描くものがあり、ルートがないと落ちます。ステージごとに `setup` で別のルートを書けます |
| `stages` | ステージ名の配列で、`stages/<ステージ名>.json` に対応します。ステージ名は英小文字・数字・`-` `_` で書きます |
| `status` | 省略可。ステージ情報ページの状況ルールのファイル |

ゲームは進行を「シナリオ番号」で記録します。コンパイラーは `stages` の順に、各ステージに原作のシナリオ番号を 1 つずつ割り当てるので（借りられない番号は避けます）、気にする必要はありません。ただし**セーブに記録されるのはこの番号**なので、公開後にステージを加えるときは `stages` の最後に足し、途中に挟まないでください。挟むと古いセーブが別のステージを指してしまいます。1 つのキャンペーンは最大でおよそ 115 ステージです。

## ステージファイル

```json
{
  "schema": "srw64.stage.v1",
  "title": {"ja": "分かれ道", "zh-Hans": "岔路", "en": "Crossroads"},
  "map": 19,
  "units": {
    "place": [
      {"group": 0, "x": 14, "y": 14, "pilot": 36, "unit": 55, "faction": 0},
      {"group": 1, "x": 6, "y": 3, "pilot": 69, "unit": 317, "faction": 1, "level": 1,
       "ai": {"mode": "goto", "to": [14, 14]}, "drop": 3}
    ]
  },
  "objective": {"win": {"ja": "敵の全滅", "zh-Hans": "全灭敌人"}, "lose": {"ja": "アムロの撃墜", "zh-Hans": "阿姆罗被击破"}},
  "events": [
    {"when": "opening", "do": [
      {"bgm": 49}, {"fade": "in"},
      {"say": 36, "text": {"ja": "「行くぞ」", "zh-Hans": "“上了。”"}},
      {"fade": "out"}, {"to_map": true},
      {"op": "3D65", "args": [127, 127]},
      {"fade": "in"}, {"deploy": 0}, {"deploy": 1}, {"bgm": 27}, {"op": "3D48"}
    ]},
    {"id": "all-down", "when": {"enemies_gone": true}, "do": [{"win": true}]},
    {"id": "amuro-down", "when": {"defeated": 36}, "do": [{"lose": true}]},
    {"when": "end", "do": [
      {"say": 36, "text": {"ja": "「次はどうする？」", "zh-Hans": "“接下来怎么办？”"}},
      {"choose": {"text": {"ja": ["進む", "戻る"], "zh-Hans": ["前进", "回去"]},
                  "options": [[{"next": "onward"}], [{"next": "back"}]]}}
    ]}
  ]
}
```

| 項目 | 説明 |
| --- | --- |
| `title` | タイトル。タイトルカード・インターミッション・セーブ一覧に出ます。「第何話」は入れないでください。インターミッションとセーブ一覧が、クリアしたステージ数から「第N話」を自動で付けます |
| `map` | 原作のマップ番号か、`maps/` にある自分のマップの名前（後述） |
| `units` | `place` はこのステージのユニット（下を参照）。`copy_from` は原作のあるステージの出撃レコードを丸ごとコピーします（自分の ROM を読みます。「公開するとき」を参照） |
| `events` | イベント（下を参照） |
| `objective` | 省略可。マップメニューの「作戦目的」に出る勝利・敗北の文で、1 つ 30 文字まで。書いた場合、オープニングに `{"op": "3D65", "args": [127, 127]}` を書きます（エディターは自動で書きます）。書かなければ原作の文を使い、オープニングに `3D65 勝利番号, 敗北番号` を書きます |
| `battle_lines` | 省略可。このステージの戦闘での新しい台詞。書き方は[シナリオ MOD の戦闘セリフ](../mod-story/#戦闘セリフ)と同じで、`scene` は書きません |
| `setup` | 省略可：`route`（このステージの主人公のルート）、`story_vars`（ステージに入るときのシナリオ変数）、`last_choice`、`initial_resources` |
| `scene` | 省略可。借りるシナリオ番号を指定します。ふつうは書きません |
| `raw_events` | 省略可。原作のイベント形式のイベント（原作のイベントを丸ごとコピーするときに使います）。[ステージスクリプト命令リファレンス](../script-commands/)を参照 |

### ユニット（units.place）

1 レコードが 1 機です：

| 項目 | 説明 |
| --- | --- |
| `group` | グループ番号。オープニングで `{"deploy": グループ番号}` でそのグループを登場させます。増援も、そのときになったら `deploy` します |
| `x`・`y` | マスの座標。左上が 0 です |
| `pilot`・`unit` | 人物番号・機体番号。パッケージの新キャラクター・新ユニットは `"@名前"`（このパッケージのもの）か `"別のパッケージid@名前"`（`requires` に書く） |
| `faction` | 陣営：0 味方、1 敵、2 か 4 第三勢力 |
| `level` | このステージの基準レベルへの加算 |
| `upgrade` | 改造段数 |
| `ai` | 敵・第三勢力の行動：`{"mode": …, "wait": ターン, "target": 人物番号, "to": [x, y]}`。`mode` は `attack`（自由に攻撃。装甲と HP の低い相手から）、`accurate`（自由に攻撃。命中率で選び、命中 30% 未満の武器は使わない）、`hunt`（`target` だけを狙う）、`goto`（`to` へ向かう。途中で自分からは攻撃せず、攻撃されれば反撃する）、`flee`（`goto` と同じで、攻撃されても反撃しない）、`guard`（`target` を護衛し、射程内なら攻撃する）。`wait` はその場で動かないターン数で、31 はずっと動きません |
| `drop` | 撃墜されたときに落とす強化パーツの番号（0〜37）。ステージをクリアすると手に入ります。書かなければ落としません |
| `entry` | 登場時の残量：1 HP 10%・EN と弾数 0、2 HP と EN 10%、3／4／5 HP と EN 30／50／70%、6 HP 満タン・EN と弾数 0、7 HP 10%・EN 満タン。書かなければ満タンです |

`copy_from` を書かない場合、各陣営 30 機までです。味方ユニットは登場するとそのまま加入し、次のステージに引き継がれます。

### イベント（events）

`when` の書き方は 2 通りあります：

- 文字列 `"opening"`・`"setup"`・`"end"`：そのステージ自身のオープニング・初期配置・終了イベントで、それぞれ 1 つまで、必ず実行されます。`id` と `if` は書きません（判定したいときは `do` の中に `if` を書きます）。**どのステージにもオープニングが必要です**。終了イベントは勝利処理の後に実行されます。
- オブジェクト：[シナリオ MOD](../mod-story/) のイベントとまったく同じです（ターン、撃墜、HP、戦闘、敵の全滅、残り機数、エリアへの到達、説得……）。`id` が必要で、`scene` は書きません。`fired`・`not_fired` は同じステージのイベントを指します。

`do` にはシナリオ MOD の動作をすべて使えます（台詞、選択肢、登場、退場、加入、乗り換え、変数、音楽、カメラ、待ち……）。さらにキャンペーンだけで使える動作が 5 つあります：

| 動作 | 意味 |
| --- | --- |
| `{"win": true}` | ステージクリア。勝利処理に入り、そのあと終了イベントを実行します |
| `{"lose": true}` | GAME OVER。プレイヤーはそのステージをやり直せます。オープニングの途中では実行しないでください |
| `{"next": "ステージ名"}` | クリア後にどのステージへ進むか。終了イベントに書きます。分岐は、選択肢や `if` の枝ごとに違う `next` を書きます |
| `{"ending": true}` | エンディングに入り、終わるとタイトルに戻ります。最後のステージの終了イベントにだけ書きます |
| `{"to_map": true}` | オープニングでワールドマップから戦場に切り替えます |

オープニングのふつうの順番：ワールドマップで会話し、`to_map` で戦場に切り替え、作戦目的を設定し、`deploy` で各グループを登場させ、最後に `{"op": "3D48"}` で会話ウィンドウを閉じてプレイヤーに渡します（サンプルキャンペーンもこう書いています）。新しい台詞は `story/<言語>/*.txt` に書き、`text` を `"@名前"` にすることもできます。[シナリオ MOD](../mod-story/#セリフをテキストファイルに書く) と同じです。

原作の命令もそのまま書けます。たとえば `{"op": "3D5B", "args": [10]}` で資金が 1 万増え、`{"op": "3D3D", "args": [0, 0, 0, 最大機数, グループ番号]}` でプレイヤーが部隊から出撃するユニットを選び、そのグループの最初のレコードの位置に置きます（エディターの「Choose the sortie」（出撃選択）がこれです）。命令は[ステージスクリプト命令リファレンス](../script-commands/)を見てください。

## 自分で描いたマップ

`maps/<マップ名>/map.json` と下絵を同じフォルダーに置き、ステージで `"map": "マップ名"` と書きます：

```json
{"schema": "srw64.map.v1", "like": 20, "image": "base.png", "scale": 4,
 "terrain": [[99, 99, 99], [99, 5, 1]]}
```

- `image`：マップ全体の画像。大きさはマス数 × 16 × `scale` です（`scale` の既定は 4 で、1〜8）。28×32 マス、`scale` 4 なら 1792×2048 です。HD の画面ではこの画像を、原作の画面ではツールが減色して作ったものを描きます。
- `terrain`：マスごとに地形番号を 1 つ（63 は壁）。行数と列数は下絵のマス数と同じにします。外側の 2 周はマップの枠で、何を書いても枠として扱います。エディターの地形の選択肢に、各地形の名前・防御・命中・回復・移動コストが出ています。
- `like`：どの原作のマップの代わりに使うか。このステージの BGM、宇宙かどうか、戦闘背景、水面の色はそのマップに従うので、同じ種類の場所を選びます。選べるのはコロニーのアニメーションがないマップだけで、宇宙のマップは 66、74、112、137、157 だけです。
- 大きさは 20×15 から 128×128 マスまで。

エディターのマップページがしているのはこの作業です。手で書くときは `pack.py` が自動でマップツールを呼び出します。結果だけを確かめるには `python3 tools/mods/map_tool.py build maps/<マップ名> -o 出力フォルダー` を使うと、原作の画面での見え方の `preview.png` も作られます。

## 始まりの状態と避けること

- **最初は何もありません**：部隊は空で、主人公とパートナーには名前がありません。味方ユニットは、ステージに置いた味方のレコードで登場させる（登場するとそのまま加入します）か、シナリオの動作 `join` で加えます。
- **部隊・資金・改造・変数は次のステージに引き継がれ**、セーブにも残ります。
- **シナリオ変数**は 0〜3 の 4 値だけです。0〜54 は元のスクリプトが読み続け、ステージに入るときに 100〜114 と 128〜139 はリセットされます。キャンペーン独自の変数は 60〜99 を使います（エディターの「+ New variable」はここから選びます）。
- 原作の台詞のうち `{HeroName}`・`{PartnerName}` を含むものと、オリジナル主人公本人の台詞は、借りないほうが無難です。最初は主人公に名前がないためです。
- **落ちることが分かっている書き方**：キャラクターがマップにいないときの `3D49`、マップ上にまだいるユニットを `3D5A …, 4000` で消す（先に退場させる）。
- キャンペーン中はリンクメニューを使えません。

## コンパイルとパッケージ作成

```bash
python3 tools/mods/pack.py my-campaign -o build/mods
```

コンパイラーはサイトのステージエディターと同じもの（TypeScript）です。コマンドラインでは [Node.js](https://nodejs.org/) 23 以降が必要で、`python3` が自動で呼び出します。`pack.py` はキャンペーン全体をコンパイルして `build/mods/<id>-<バージョン>.srw64mod` を作り、ゲームと同じルールでチェックします。書き間違いは、どのステージのどのイベントのどの項目かが報告されます。各ステージが何にコンパイルされたかだけを見たいときは：

```bash
python3 tools/mods/stage.py compile my-campaign -o /tmp/out
```

## インストールと遊び方

1. `.srw64mod` をゲームのウィンドウにドラッグしてインストールします（MOD フォルダーに入れても可。[MOD パッケージ](../mods/#インストール)参照）。
2. タイトル画面で「MOD」を開き、「追加シナリオ」ページでキャンペーンの行の「プレイ」を押します。
3. タイトル画面の中央に「キャンペーン開始」とキャンペーン名が出るので、そこから始めます。以後タイトルでのロードはこのキャンペーンのセーブになります。
4. 本編に戻るには、同じページの「本編に戻る」。切り替えはタイトル画面でだけできます。

キャンペーンのセーブはユーザーディレクトリの `campaigns/<id>/saves/` にあり、本編とは別です。

## 公開するとき

エディターで作ったパッケージは番号と自分で書いたものだけでできているので、公開できます。手で書くときに `copy_from`・`template`・原作のイベントの `copy_from` を使うと、ROM の元データをパッケージにコピーします。そうして作ったパッケージは自分で遊ぶためだけのものです。テキスト・マップ・キャラクター・ユニットの番号はただの番号なので使えます。自分で描いたマップは、配布する権利のある画像にしてください。そのほかは [MOD パッケージの著作権](../mods/#著作権)のとおりです。
