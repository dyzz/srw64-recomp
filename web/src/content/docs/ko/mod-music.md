음악 MOD는 원작의 곡 하나를 오디오 파일로 바꿉니다. 게임에서 그 곡이 나오는 모든 곳, 즉 전투곡, 스테이지 음악, 스토리 장면, 타이틀, 사운드 셀렉트가 이를 따릅니다. 파일럿이나 기체가 싸울 때 흐를 곡을 고를 수도 있습니다.

패키지 설치와 관리는 [MOD 패키지: 설치와 제작](../mods/)을 참고하세요.

## 웹 도구로 만들기

[BGM MOD 제작 도구](/ko/mods/bgm/)는 모든 작업을 브라우저 안에서 처리합니다. **오디오는 어디에도 업로드되지 않습니다.**

1. 패키지 정보(ID, 버전, 이름, 제작자, 라이선스)를 입력합니다.
2. 49곡 목록에서 바꾸고 싶은 줄에 오디오 파일을 끌어다 놓습니다. mp3, wav, flac, m4a, ogg를 모두 쓸 수 있습니다. 도구가 게임 형식으로 변환하며, 이미 Ogg Vorbis인 파일은 그대로 사용합니다.
3. 줄을 눌러 곡을 설정합니다(▶를 누르면 바로 재생합니다).
   - **루프**: 곡 전체 루프, 곡 일부 구간 루프, 한 번만 재생 중에서 고릅니다. 파형 위의 파란 선(시작)과 금색 선(끝)을 끌어 구간을 정하며, 손을 떼면 가장 가까운 영점 교차 지점에 맞춰집니다. “이음매 미리 듣기”는 루프가 처음으로 돌아가는 순간을 재생합니다.
   - **음량(dB)**: 이 곡과 교체한 다른 곡들의 평균 음량이 옆에 표시되므로 서로 맞출 수 있습니다.
   - **곡명**: 사운드 셀렉트에 표시되는 이름입니다. 원한다면 언어별로 쓸 수 있습니다.
4. 원한다면 “전투곡”에서 파일럿이나 기체가 싸울 때 흐를 곡을 고릅니다.
5. “.srw64mod 내보내기”를 누르고, 그 파일을 게임 창에 끌어다 놓아 설치합니다.

나중에 패키지를 고치려면 “기존 .srw64mod 열기”로 다시 불러옵니다.

## 게임 안에서

- 사운드 셀렉트에서 교체된 곡에는 “MOD” 표시가 붙고, 패키지가 곡명을 지정했다면 그 곡명이 나옵니다.
- 설정의 일반 페이지에서 “MOD 음악”을 켜고 끄거나 음량(25–100%)을 조절할 수 있습니다. 변경은 다음에 시작하는 곡부터 적용됩니다.
- 노래방 모드는 가사가 원곡의 타이밍에 맞춰져 있으므로 원곡을 그대로 씁니다.

## 원작이 곡을 고르는 방식

- **전투곡**: 아군 기체가 전투에 참여하면 누가 공격하든 **아군 기체의 메인 파일럿**의 테마가 흐릅니다. 아군 기체가 참여하지 않으면 공격하는 기체의 테마가 흐릅니다.
- 다음 경우에는 원작이 항상 정해진 곡을 틀며, MOD의 전투곡으로 바꿀 수 없습니다: 갓 건담 H(명경지수 형태), 셔플 동맹의 슈퍼 모드 형태, V-MAX, 발=아, 아비=루, 제이=렌이 참여한 전투. 다만 그 정해진 곡 자체는 교체할 수 있습니다.
- 전투가 끝나도 스테이지 음악으로 돌아오지 않습니다. 다음 페이즈가 시작될 때까지 전투곡이 계속 흐릅니다. 루프를 설정할 때 참고하세요.
- 스테이지 음악은 페이즈가 시작될 때마다 처음부터 다시 재생됩니다.
- 적 증원 때 나오는 짧은 곡(38번)은 기본적으로 한 번만 재생되고, 그 뒤 게임이 알아서 스테이지 음악으로 돌아갑니다.

## 직접 만들기

웹 도구가 만드는 파일은 다음과 같습니다.

```text
yourname.bgm/
  mod.json
  audio/
    music/<song>.ogg
    music.json        선택
```

- 각 파일은 **곡 번호**(10진수, 앞에 0을 붙이지 않음)로 이름을 붙입니다. `7.ogg`는 7번 곡 “メインテーマ”를 교체합니다. [곡 표](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/songs.csv)에 49곡 전부의 번호, 곡명, 나오는 곳이 정리되어 있습니다.
- 형식은 반드시 **Ogg Vorbis**여야 하며, 샘플레이트는 무엇이든, 모노든 스테레오든 상관없습니다. 루프 지점을 샘플 단위까지 정확하게 지키는 것은 Vorbis뿐입니다. MP3는 앞뒤에 여백이 붙어 루프할 때 틈이 생깁니다. 다른 형식은 먼저 변환하세요. 예:

  ```bash
  ffmpeg -i in.wav -c:a libvorbis -q:a 6 out.ogg
  ```

`music.json`은 선택입니다. `.ogg` 파일만 있으면 각 곡은 곡 전체를 루프하고, 파일 그대로의 음량으로, 원래 곡명으로 표시됩니다. 세밀하게 조정하려면 다음처럼 씁니다.

```json
{
  "schema": "srw64.music.v1",
  "tracks": {
    "7":  { "loop": [441000, 5292000], "gain": -2.0,
            "title": { "zh-Hans": "…", "en": "…", "ja": "…" } },
    "38": { "loop": false }
  },
  "battle": {
    "pilot": { "36": 7 },
    "unit":  { "97": 12 }
  }
}
```

| 필드 | 의미 |
| --- | --- |
| `tracks.<song>.loop` | **샘플** 단위(초가 아님)의 `[시작, 끝]`. 끝에 이르면 시작으로 돌아갑니다. `false`는 한 번만 재생, `true`는 곡 전체를 루프합니다. 지정하지 않으면 파일의 `LOOPSTART`/`LOOPLENGTH` 태그를 쓰고, 그것도 없으면 곡 전체를 루프합니다 |
| `tracks.<song>.gain` | dB 단위의 음량 변경. 음수면 작아집니다 |
| `tracks.<song>.title` | 사운드 셀렉트에 표시되는 곡명, 언어별 |
| `battle.pilot.<pilot>` | 이 파일럿이 아군 기체의 메인 파일럿으로 싸울 때 흐를 곡(번호) |
| `battle.unit.<unit>` | 아군 기체가 참여하지 않을 때 이 기체가 공격 측으로 싸울 때 흐를 곡 |

파일럿과 기체 번호는 [파일럿 표](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/pilots.csv)와 [기체 표](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/units.csv)에 있으며, 각각의 원래 전투곡도 함께 나와 있습니다. 여러 패키지가 같은 곡이나 같은 파일럿을 지정하면 목록에서 위에 있는 패키지가 우선합니다.

### AI에게 맡기기

저장소의 [`docs/guide/audio-mods/`](https://github.com/dyzz/srw64-recomp/tree/main/docs/guide/audio-mods) 폴더에는 전체 형식 설명과 모든 표가 들어 있습니다(설명은 중국어입니다). 폴더 전체를 AI 어시스턴트에게 건네면 파일 이름을 바꾸고 변환한 뒤 `mod.json`과 `music.json`을 대신 써 줍니다.

## 전투음성

0.5.2부터 패키지로 전투 대사에 음성을 붙일 수도 있습니다. 전투 중 대사 창이 열리면 그 음성이 재생됩니다.

가장 쉬운 방법은 [전투음성 MOD 제작 도구](/ko/mods/voices/)이며, 이것도 모든 작업을 브라우저 안에서 처리합니다.

1. 패키지 정보를 입력합니다.
2. 캐릭터를 고르면 그 캐릭터의 전투 대사가 모두 나열되며, 각 대사에는 나오는 상황과 원문이 함께 표시됩니다. 녹음 파일을 해당 대사에 끌어다 놓거나 “파일 선택”을 누릅니다. 녹음은 Ogg Vorbis로 변환되며, ▶로 재생할 수 있습니다.
3. 녹음이 많다면 파일 이름을 레코드 번호로 시작하게 붙이고(예: `7018.wav`, `7018_attack.wav`) “한꺼번에 추가”에 모두 끌어다 놓습니다.
4. “.srw64mod 내보내기”를 누릅니다. 나중에 더 추가하려면 “기존 .srw64mod 열기”로 다시 불러옵니다.

직접 만들 때는 파일을 다음과 같이 둡니다.

```text
yourname.voices/
  mod.json
  audio/
    voice/battle/<record>.ogg
    voice.json        선택
```

- 파일 이름은 대사의 **레코드 번호**(5799–17346)입니다. [전투 대사 표](https://github.com/dyzz/srw64-recomp/blob/main/docs/guide/audio-mods/battle-voices.csv)에 11,548개 전부가 화자, 나오는 상황, 세 언어의 텍스트와 함께 정리되어 있습니다. 음악과 마찬가지로 Ogg Vorbis만 됩니다.
- 여러 페이지로 된 대사는 첫 페이지에서 재생됩니다. 재생 중인 음성은 다음 대사가 시작되거나, 전투가 끝나거나, 중간에 끊기면 멈춥니다.
- 대사 창은 원작의 속도를 그대로 유지하며 음성을 기다리지 않습니다. 대사 하나는 2~3초 안으로 맞추세요.
- 전투 애니메이션을 끄면 대사가 나오지 않으므로 음성도 나오지 않습니다. 음성은 읽기 언어와 상관없이 같습니다.
- 무작위로 고르는 대사는 모두 음성을 넣어야 항상 소리가 납니다. 예를 들어 “공격(일반, 3/14)”은 14개 중에서 무작위로 고르는 대사 가운데 하나입니다.
- `voice.json`은 선택입니다: `{"schema": "srw64.voice.v1", "gain": -3.0, "delay": 150}`. `gain`은 음량을 조절하고(dB, -30~12), `delay`는 대사 창이 열린 뒤 그만큼 밀리초를 기다립니다(0~2000).
- 설정의 일반 페이지에 MOD 전투음성 스위치와 음량이 있습니다.

## 저작권

사용하고 재배포할 권리가 있는 음악만 쓰세요. 원작 애니메이션 곡으로 만든 패키지는 개인적으로만 쓸 수 있으며, 공식 MOD 목록에 제출할 수 없습니다.
