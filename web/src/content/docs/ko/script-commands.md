스테이지의 각 이벤트는 16비트 워드의 나열입니다. 명령 오프코드 `3D31`–`3D79` 뒤에 그 오퍼랜드가 오고, 조건 `3E00`–`3E1D`가 if 블록을 이루며, 컨텍스트 마커 `3DD0`–`3DDB`가 현재 주인공의 루트나 선택지에 따라 실행할 구간을 고르고, `FFFF`로 이벤트가 끝납니다. [미니 스테이지](../mini-stage/)에서는 명령을 `{"op": "3D45", "args": [1]}`처럼 쓰며, 조건과 마커도 같은 방식으로 씁니다.

이 페이지는 [`config/data/original-jp-v1.json`](https://github.com/dyzz/srw64-recomp/blob/main/config/data/original-jp-v1.json)의 `stage_scripts` 테이블에서 생성됩니다. “코드 확인”은 게임의 핸들러에서 의미를 확인했다는 뜻이고, “구조 확인”은 무엇을 읽고 쓰는지는 알지만 무엇을 위한 것인지는 아직 완전히 알지 못한다는 뜻입니다.

구현 근거(각 항목이 어떤 게임 코드에 기반하는지)와 게임 내 확인 결과는 중국어로 기록되어 있습니다. 각 항목에서 [중국어 페이지](../../../zh/docs/script-commands/)의 해당 위치로 링크합니다.

## 이벤트 타입

이벤트의 타입에 따라 언제 검사되는지, 그리고 네 개의 발동 파라미터(`header`)를 어떻게 읽는지가 정해집니다.

| 타입 | 이름 | 검사 시점 | 발동 파라미터 |
|---|---|---|---|
| 0 | 턴 시작 | 페이즈 0 | 1. 턴 수: 현재 턴 ≥ 이 값<br>2. 페이즈: 현재 페이즈 8010F5E8과 같아야 함(1 아군 / 2 적)<br>3. 예약<br>4. 예약 |
| 1 | 지연 카운트(3D52로 시작) | 페이즈 0 | 1. 초기 상태: 실행 중에 3D52가 0xFD로 바꿔 씀<br>2. 페이즈: 실행 중에 3D52가 바꿔 씀; 4 = 제한 없음<br>3. 예약<br>4. 예약 |
| 2 | 기체 파괴 / 철수 | 항상 | 1. 게이트 변수: 100–115는 변수가 3인 동안 이벤트가 발동하지 않음(8009DE7C가 각 스테이지 시작 시 100–114를 3으로 설정하며, 스크립트가 0을 써서 활성화); 다른 번호는 검사하지 않음; 0은 게이트 없음<br>2. 캐릭터: 이 캐릭터가 탄 기체의 HP가 0%가 됨<br>3. 예약<br>4. 예약 |

| `3DD4` | 마나미 하밀 루트 | 현재 주인공 |
| `3DD5` | 리얼계 주인공(3DD1/3DD2) | 주인공 분류 |
| `3DD6` | 슈퍼계 주인공(3DD3/3DD4) | 주인공 분류 |

## 오퍼랜드 타입

오퍼랜드의 타입은 값의 범위를 나타냅니다. 여기에 없는 타입은 오퍼랜드 이름으로 설명합니다.

| 타입 | 의미 |
|---|---|
| `actor` | 캐릭터 번호(base:actors) |
| `text` | 테이블 0의 텍스트 번호 |
| `unit` | 기체 번호(base:units) |
| `flag` | 2비트 변수 0–199 |
| `scene` | 장면 |
| `group` | 출격 레코드 그룹 |
| `position` | 상위 바이트 x / 하위 바이트 y; 0x40–0x44는 3D54가 기억한 위치 기준 상대값 |
| `x` | 칸 x |
| `y` | 칸 y |
| `count` | 개수 |
| `frames` | 프레임 |
| `se` | 효과음 번호 |
| `bgm` | 곡 번호 |
| `event_slot_type1` | 이 장면에서 타입 1 이벤트의 등록 번호 |
| `event_slot_type8` | 이 장면에서 타입 8 이벤트의 등록 번호 |
| `actor_or_group` | 500 미만은 캐릭터 번호, 500부터는 그룹(값 − 500) |
| `bool` | 스위치 |
| `value` | 번호 |
| `side` | 페이즈 1 아군 / 2 적 / 3 제3세력(4 = 제한 없음) |
| `deploy_side` | 출격 소속 0/1/2(3 → 0, 4 → 2) |
| `raw` | 미해명 |
| `faction` | 소속 번호 0 아군 / 1 적 / 2 제3세력 |
| `map` | 맵 번호(base:map_assets; 8010F5EE에 씀) |

## 변수

2비트 변수(값 0–3)가 200개 있으며 `0x8015E818`에 저장됩니다. 조건으로 읽고 쓰며 스테이지가 바뀌어도 유지됩니다.

## 출격 레코드(28바이트)

| `+0` | 2 | 그룹 | `group` | 코드 확인 |
| `+2` | 2 | x | `x` | 코드 확인 |
| `+4` | 2 | y | `y` | 코드 확인 |
| `+6` | 2 | 파일럿 | `actor` | 코드 확인 |
| `+8` | 1 | 미해명 바이트 | `byte8` | 미해명 |
