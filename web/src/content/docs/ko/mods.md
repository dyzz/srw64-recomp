MOD 패키지는 폴더 하나, 또는 그 폴더를 `.srw64mod` 파일 하나로 압축한 것입니다. 데이터만 담으며 코드는 절대 담지 않습니다. 패키지를 활성화하면 게임은 원작에서 그에 해당하는 부분 대신 패키지의 내용을 사용합니다. 어떤 패키지도 바꾸지 않은 부분은 모두 원작 그대로입니다.

**음악과 전투음성, 능력치, 이름, 초상화, 맵 아이콘, 캠페인, 스토리 이벤트, 언어 패키지가 적용됩니다.** 곡 교체, 파일럿이나 기체가 싸울 때 흐를 곡 지정, 전투 대사 음성은 [음악 MOD](../mod-music/)에서, 기체·파일럿·무기의 능력치 변경은 [수치 MOD](../mod-data/)에서, 이름 변경과 새 초상화·맵 아이콘은 [이름·초상화·맵 아이콘 MOD](../mod-names/)에서, 원작 스테이지에 추가하는 이벤트, 캐릭터 합류, 스토리 분기 변경은 [스토리 MOD](../mod-story/)에서, 직접 배치한 스테이지를 이어 만드는 캠페인은 [캠페인 MOD](../mod-campaign/)에서, 읽기 언어 추가나 기존 언어의 텍스트 교체는 [언어 패키지 MOD](../mod-language/)에서 설명합니다. 다른 그래픽도 뒤따를 예정이며, 패키지 형식에는 이미 그 자리가 마련되어 있습니다.

MOD를 쓰려면 0.5.1 이상이 필요합니다. 음악과 지형 적응 외의 기능은 0.5.2, 스토리 MOD와 언어 패키지는 0.5.3이 필요합니다.

## 설치

1. MOD 관리 화면을 엽니다. 타이틀 화면 오른쪽 아래의 “MOD”를 누르거나, 설정을 열고 일반 페이지의 “MOD”를 누릅니다.
2. **`.srw64mod` 파일을 게임 창에 끌어다 놓습니다**(`.zip`이나 패키지 폴더도 됩니다). 게임이 백그라운드에서 설치하고, 화면 위쪽에 알림을 띄운 뒤 설치됨 페이지를 엽니다.
3. 또는 “폴더 열기”를 눌러 패키지 파일을 MOD 폴더에 직접 넣습니다. 다음에 MOD 관리 화면을 열 때 설치됩니다.

같은 패키지의 새 버전을 설치하면 이전 버전을 대체합니다. 이전 버전과 제거한 패키지는 삭제되지 않고 MOD 폴더 안의 `.trash`로 옮겨집니다.

Android에서는 패키지 파일을 문서(Documents) 폴더의 Marchwind64 폴더 안 `mods/`에 넣습니다(“파일” 앱). 게임을 시작하거나 MOD 페이지를 열 때 설치됩니다. 또는 MOD 페이지에서 파일에서 설치를 눌러 선택해도 됩니다.

## 관리

설치됨 페이지에는 각 패키지의 이름, 버전, 제작자, 내용, 상태가 나옵니다. 패키지를 켜거나 끄고, 제거할 수 있습니다(제거할 때는 확인을 묻습니다).

- **목록에서 위에 있는 패키지가 아래 패키지보다 우선합니다.** 두 패키지가 같은 곡을 교체하면 위쪽 패키지의 곡이 쓰입니다.
- 다른 패키지에 의존하는 패키지는 자동으로 그 패키지 위에 놓입니다. 의존하는 패키지가 없거나, 너무 오래되었거나, 꺼져 있으면 페이지에 그 사실이 표시되고 해당 패키지는 당분간 꺼진 상태로 남습니다.
- 패키지가 더 새로운 게임 버전을 요구할 때도 페이지에 표시됩니다.

## 패키지 만들기

음악 패키지를 가장 쉽게 만드는 방법은 웹사이트의 [BGM MOD 제작 도구](/ko/mods/bgm/)입니다. 아래 파일을 대신 만들어 줍니다. 직접 만들고 싶거나 안에 무엇이 들어 있는지 알고 싶다면 계속 읽어 주세요.

### 패키지에 들어가는 것

```text
mod.json        패키지 정보(필수)
audio/          음악과 음성
campaign/       추가 캠페인
art/            그래픽
dialogue/       대사와 언어
data/           능력치
```

사용하는 폴더만 넣으면 됩니다. 배포하려면 폴더 전체를 zip으로 압축하고 확장자를 `.srw64mod`로 바꿉니다. `mod.json`은 압축 파일의 최상위에 두거나, 최상위 폴더가 하나뿐이라면 그 안에 두어도 됩니다.

### mod.json

```json
{
  "schema": "srw64.mod.v1",
  "id": "yourname.bgm",
  "version": "1.0.0",
  "name": { "zh-Hans": "我的 BGM", "en": "My BGM", "ja": "マイ BGM" },
  "description": { "en": "New battle themes." },
  "authors": ["yourname"],
  "license": "CC-BY-4.0"
}
```

| 필드 | 의미 |
| --- | --- |
| `schema` | 항상 `srw64.mod.v1` |
| `id` | 패키지의 고유 이름. 영문자, 숫자, `.` `_` `-`로 64자 이내. “제작자.이름” 형식을 권장합니다. **배포한 뒤에는 바꾸지 마세요** |
| `version` | 버전. `1.0.0`처럼 씁니다 |
| `name` | 표시되는 이름. 문자열 하나, 또는 언어별 문자열(`zh-Hans`, `zh-Hant`, `en`, `ja`, 그리고 설치된 [언어 패키지](../mod-language/)의 언어). 번체 중국어는 간체로, 다른 언어는 각자의 대체 언어로, 그다음 일본어로 대체됩니다 |
| `description` | 선택. 설명이며 `name`과 같은 방식으로 씁니다 |
| `authors` | 선택. 제작자 목록 |
| `license` | 라이선스. 패키지 재배포를 허용해야 합니다: `CC-BY-4.0`, `CC-BY-SA-4.0`, `CC-BY-NC-4.0`, `CC-BY-NC-SA-4.0`, `CC0-1.0`, `MIT`, `GPL-3.0-or-later` |
| `game` | 선택. 필요한 게임 버전. 예: `">=0.5.1"` |
| `requires` | 선택. 이 패키지가 필요로 하는 패키지. 예: `{ "someone.base": ">=1.0" }` |
| `optional` | 선택. 있으면 함께 사용하는 패키지. `requires`와 같은 방식으로 씁니다 |
| `conflicts` | 선택. 동시에 켤 수 없는 패키지. 예: `{ "someone.old": "*" }` |

버전 조건은 `*`(모든 버전) 또는 공백으로 구분한 몇 개의 조건입니다. 예: `">=1.0 <2"`. 게임이 모르는 필드는 오류로 처리되므로 임의로 필드를 추가하지 마세요.

### 검사

[소스 저장소](https://github.com/dyzz/srw64-recomp)의 `tools/mods/validate.py`는 게임과 같은 규칙으로 패키지를 검사하고 문제를 모두 나열합니다.

```bash
python3 tools/mods/validate.py yourname.bgm-1.0.0.srw64mod
```

## 저작권

패키지에 들어가는 모든 것은 재배포할 권리가 있는 것이어야 합니다. 원작 애니메이션 곡 같은 자료로 만든 패키지는 개인적으로만 사용하세요. 배포하지 마시고, 저도 그런 패키지는 목록에 올리지 않습니다.
