추가 시나리오는 그 자체로 하나의 작은 캠페인입니다. 정한 순서대로 스테이지를 플레이하고, 그 사이에 평소와 같은 인터미션 (개조, 갈아타기, 저장)이 있으며, 스토리 선택지에 따라 엔딩이 달라질 수 있습니다. MOD 패키지로 배포되며, 타이틀의 MOD → 추가 시나리오에서 시작하고, **세이브는 본편과 완전히 분리되어 보관됩니다.**

각 스테이지는 네 층으로 이루어집니다: **맵** (원작 맵, 또는 직접 그린 맵 한 장), **유닛** (그룹별로 칸 위에 배치), **스토리** (오프닝, 전투 중, 클리어 후의 이벤트와 대사), **흐름** (클리어 후 어느 스테이지로 가는지, 엔딩, 또는 플레이어에게 고르게 하기).

이 페이지에서 설명하는 새 형식은 0.5.4 이상이 필요합니다. 0.5.1–0.5.3에서 만든 이전 형식의 캠페인도 그대로 플레이할 수 있습니다.

## 현재 가능한 것

| 가능 | 아직 불가 |
| --- | --- |
| 여러 스테이지 연속 진행, 분기 선택지, 여러 엔딩 | 본편 중간에 새 스테이지 끼워 넣기 |
| 원작 맵, 또는 직접 그린 맵 한 장 (칸마다 지형을 직접 정함) | 한 스테이지 안에서 두 번째 직접 그린 맵으로 바꾸기. 직접 그린 바다는 움직이지 않음 |
| 새 대사, 직접 쓴 선택지 문구와 작전 목표 문구 (언어별로 따로 씀), 원작의 「???」 실루엣 화자 | 콜로니 애니메이션이 있는 원작 맵을 직접 그린 맵의 틀로 쓰기 |
| 각 스테이지의 아군, 적, 제3세력 유닛, 증원, 적의 행동 방식, 떨어뜨리는 강화 파츠, 등장 시 남은 양 | 중간 스테이지부터 시험 플레이하기 |
| 승리·패배 조건: 전멸, 특정 인물 격추, 구역 도달, 턴 수, 남은 기체 수, HP, 설득… 조합 가능 | |
| 전투 중 인물의 새 대사, 출격 선택 | |
| 패키지의 새 기체, 새 인물 ([새 기체·새 인물·새 무기 MOD](../mod-units/)) | |
| 스테이지에서 스테이지로 이어지는 자금, 스토리 변수, 부대 | |

## 스테이지 편집기 사용하기

웹사이트의 [스테이지 편집기](/ko/mods/editor/)로 브라우저에서 캠페인을 한 스테이지씩 씁니다. **ROM이 필요 없고, 아무것도 업로드하지 않습니다.** 원작의 맵, 기체, 인물, 곡은 도감과 마찬가지로 웹사이트에서 읽어 옵니다. (편집기 화면은 지금은 중국어와 영어뿐이며, 아래 괄호 안은 영어 화면의 이름입니다.)

- **개요** (Overview): 스테이지 목록과 흐름도 (선은 클리어 후 가는 곳), 검사 결과, 패키지 정보와 주인공 루트.
- **맵** (Map): 원작 맵을 그대로 쓰거나, 자기 그림 (PNG, JPEG, WebP)을 가져와 칸으로 자르고 칸마다 지형을 고릅니다 (브러시, 사각형, 이어진 칸 채우기, 스포이트. 먼저 「색으로 추측」(Guess from the colours)으로 한 번 채운 뒤 고칠 수도 있습니다). 대신 자리를 차지할 원작 맵을 하나 고르고, 원작 이미지에서 어떻게 보이는지 확인합니다.
- **유닛** (Units): 그룹별로 유닛을 놓습니다. 그룹에는 진영과 등장 시점이 있습니다. 고른 유닛의 기체, 파일럿, 레벨 보정, 개조 단계를 바꿉니다. 적과 제3세력에는 행동 방식 (자유 공격, 특정 인물만 추격, 특정 칸으로 이동, 고정 방어, 특정 인물 호위 등), 제자리에서 움직이지 않는 턴 수, 격추될 때 떨어뜨리는 파츠, 등장할 때의 HP/EN을 정할 수 있습니다.
- **스토리** (Story): 출발 전, 전장 진입, 전투 중의 각 이벤트, 전투 후. 이벤트마다 시점과 조건을 고르고 동작 (대사, 등장, 이탈, 합류, 음악, 카메라, 선택지, 변수…)을 하나씩 추가합니다. 대사는 중국어/일본어/영어로 따로 쓰며, 옆에 게임에서 보이는 모습이 나옵니다. 따로 「전투 대사」(Battle lines) 칸이 있습니다.
- **승패와 증원** (Rules): 승리·패배 조건, 작전 목표 문구, 그룹별 등장 시점, 클리어 후 가는 곳 (엔딩, 다음 스테이지, 플레이어에게 고르게 하기), 전장 음악.

프로젝트는 브라우저에 자동으로 저장됩니다. 위쪽 막대의 「프로젝트 저장」(Save project)은 `.srw64edit` 파일로 저장하며, 다 만들지 않았어도 저장할 수 있고 「프로젝트 열기」(Open project)로 이어서 고칠 수 있습니다. 모든 편집은 실행 취소 (Ctrl/⌘+Z)할 수 있습니다. 「템플릿」(Template)은 두 스테이지짜리 완성된 캠페인을 불러오므로 거기서 시작해도 됩니다. 다 만들면 「.srw64mod 내보내기」를 누릅니다. 내보내기 전에 페이지가 먼저 검사합니다 (유닛이 맵 밖에 있음, 들어갈 수 없는 칸에 서 있음, 겹침, 진영마다 최대 30기, 아군과 적이 모두 있는지 등). 내보낸 패키지에는 원본 파일이 함께 들어 있어 「프로젝트 열기」로 다시 읽어 들일 수도 있습니다.

## AI에게 맡기기

파일을 읽고 쓸 수 있는 AI 에이전트 (Claude Code, Codex 등)는 이 페이지를 따라 캠페인 전체를 만들 수 있습니다. [소스 저장소](https://github.com/dyzz/srw64-recomp) 폴더에서 에이전트를 열고, 아래 요청을 복사한 뒤 “스토리” 부분을 여러분의 줄거리로 바꾸세요.

```text
Marchwind 64(『슈퍼로봇대전64』의 PC 리컴파일판)용 추가 시나리오 MOD(사용자 캠페인)를 만들어 주세요. 바로 설치할 수 있는 .srw64mod 파일로 묶어 주세요.

먼저 다음을 읽고 그 형식과 규칙을 정확히 따라 주세요:
- https://srw64.dreamquest.club/ko/docs/mod-campaign.md (캠페인과 스테이지의 형식, 맵, 패키지 묶기)
- https://srw64.dreamquest.club/ko/docs/mod-story.md (이벤트의 시점, 조건, 동작. 스테이지의 이벤트도 같은 방식으로 씁니다)
- 저장소의 예제 캠페인 config/recomp/campaigns/sample. 그 구조를 따라 주세요

요구 사항:
- 새 대사는 모두 ja와 ko를 쓰기. 일본어와 한국어 모두 「」를 쓰기
- 인물 번호, 기체 번호, 맵 번호는 저장소의 docs/guide/data-mods/ 표와 docs/guide/story-mods/scenes.csv에서 찾기
- 스토리 변수는 60–99만 쓰기

스토리:
(스테이지 수. 스테이지마다 어느 맵을 쓰는지, 누가 합류하는지, 적, 언제 증원이 오는지, 승리·패배 조건. 선택지는 어디에 있고 엔딩은 몇 개인지)

순서:
1. 먼저 스테이지 목록과 각 스테이지의 설계를 보여 주고, 제가 승인하면 파일을 쓰기
2. 다 쓰면 tools/mods/pack.py로 묶기(캠페인 전체를 컴파일하고 검사합니다). 오류가 있으면 고치기
3. 만들어진 파일이 어디 있는지와 설치 방법을 알려 주기
```

몇 가지 요령:

- **줄거리는 구체적일수록 좋습니다.** “2번째 스테이지는 원작 제5화의 맵을 쓰고, 아무로와 카미유가 출격하며, 적은 6기, 3턴에 증원, 적 전멸로 승리” 정도까지 적으세요. 번호를 AI가 알아서 고르게 하면 틀리기 쉽습니다.
- **먼저 스테이지 편집기에서 열어 보세요.** AI가 만든 패키지는 편집기의 「프로젝트 열기」로 읽어 들일 수 있어, 맵과 유닛 위치가 맞는지 한눈에 보입니다.
- **스테이지를 하나씩 플레이해 보세요.** 스테이지에 들어갈 수 있고, 이길 수 있고, 클리어 후 다음 스테이지로 이어지는지 확인한 다음, 전체를 이어서 플레이하세요.

이 아래는 전체 형식 설명입니다.

## 파일

```text
my-campaign/
  mod.json                      패키지 정보
  campaign.json                 캠페인: 이름, 시작 스테이지, 주인공 루트, 스테이지 순서
  stages/<스테이지>.json        스테이지 하나에 하나씩
  stages/<스테이지>.meta.json   선택: 스테이지 정보 화면의 내용
  status.json                   선택: 스테이지 정보 화면의 진행 규칙
  maps/<맵 이름>/               선택: 직접 그린 맵
```

`mod.json` 작성법은 [MOD 패키지](../mods/#modjson)에 있습니다. `game`은 `">=0.5.4"`로 설정하세요. 패키지를 묶을 때 이 원본 파일들은 패키지 안의 `campaign/`으로 컴파일되며, 원본 파일은 패키지에 들어가지 않습니다 (편집기가 내보낸 패키지에는 편집기가 다시 읽어 들일 수 있도록 원본 파일이 따로 한 벌 들어갑니다). 스테이지 정보용 선택 파일 두 개는 예제 캠페인의 것을 복사하세요.

## campaign.json

```json
{
  "schema": "srw64.campaign.v2",
  "id": "yourname.my-campaign",
  "name": {"zh-Hans": "我的战役", "en": "My Campaign", "ja": "マイキャンペーン"},
  "description": {"zh-Hans": "一句话简介。", "en": "One line about it.", "ja": "ひとことで紹介。"},
  "author": "yourname",
  "version": "1",
  "start": "valley",
  "route": 1,
  "stages": ["valley", "showdown"]
}
```

| 필드 | 의미 |
| --- | --- |
| `id` | `mod.json`의 `id`와 같아야 합니다. 캠페인 세이브 폴더의 이름이기도 하므로 **공개한 뒤에는 바꾸지 마세요** |
| `name`, `description` | 추가 시나리오 화면에 표시되는 이름과 설명: 문자열 하나, 또는 언어별로 하나씩 (`zh-Hans`, `zh-Hant`, `en`, `ja`, `ko`, 그리고 [언어 패키지의 언어](../mod-language/)) |
| `start` | 어느 스테이지가 처음인지 |
| `route` | 주인공 루트, 반드시 씁니다: 0 브래드, 1 마나미, 2 아크, 3 세레인. 원작의 일부 대사는 주인공 일행의 초상화를 그리는데, 루트가 없으면 크래시합니다. 스테이지마다 `setup`에서 따로 쓸 수도 있습니다 |
| `stages` | 스테이지 이름의 배열이며, `stages/<스테이지 이름>.json`에 대응합니다. 스테이지 이름에는 영문 소문자, 숫자, `-` `_`를 씁니다 |
| `status` | 선택. 스테이지 정보 화면의 진행 규칙 파일 |

게임은 「장면 번호」로 진행 상황을 기록합니다. 컴파일러가 `stages`의 순서대로 각 스테이지에 원작 장면 번호를 하나씩 배정하므로 (빌릴 수 없는 번호는 피합니다) 신경 쓸 필요는 없습니다. 다만 **세이브에 기록되는 것은 이 번호**이므로, 공개한 뒤에 스테이지를 추가할 때는 `stages`의 끝에 추가하고 중간에 끼워 넣지 마세요. 그러면 이전 세이브가 다른 스테이지를 가리키게 됩니다. 캠페인 하나는 최대 약 115개 스테이지입니다.

## 스테이지 파일

```json
{
  "schema": "srw64.stage.v1",
  "title": {"ja": "分かれ道", "zh-Hans": "岔路", "en": "Crossroads"},
  "map": 19,
  "units": {
    "place": [
      {"group": 0, "x": 14, "y": 14, "pilot": 36, "unit": 55, "faction": 0},
      {"group": 1, "x": 6, "y": 3, "pilot": 69, "unit": 317, "faction": 1, "level": 1,
       "ai": {"mode": "goto", "to": [14, 14]}, "drop": 3}
    ]
  },
  "objective": {"win": {"ja": "敵の全滅", "zh-Hans": "全灭敌人"}, "lose": {"ja": "アムロの撃墜", "zh-Hans": "阿姆罗被击破"}},
  "events": [
    {"when": "opening", "do": [
      {"bgm": 49}, {"fade": "in"},
      {"say": 36, "text": {"ja": "「行くぞ」", "zh-Hans": "“上了。”"}},
      {"fade": "out"}, {"to_map": true},
      {"op": "3D65", "args": [127, 127]},
      {"fade": "in"}, {"deploy": 0}, {"deploy": 1}, {"bgm": 27}, {"op": "3D48"}
    ]},
    {"id": "all-down", "when": {"enemies_gone": true}, "do": [{"win": true}]},
    {"id": "amuro-down", "when": {"defeated": 36}, "do": [{"lose": true}]},
    {"when": "end", "do": [
      {"say": 36, "text": {"ja": "「次はどうする？」", "zh-Hans": "“接下来怎么办？”"}},
      {"choose": {"text": {"ja": ["進む", "戻る"], "zh-Hans": ["前进", "回去"]},
                  "options": [[{"next": "onward"}], [{"next": "back"}]]}}
    ]}
  ]
}
```

| 필드 | 의미 |
| --- | --- |
| `title` | 타이틀 카드, 인터미션, 세이브 목록에 표시되는 제목. 스테이지 번호는 넣지 마세요. 인터미션과 세이브 목록이 클리어한 스테이지 수를 세어 “제N화”를 자동으로 붙입니다 |
| `map` | 원작 맵 번호, 또는 `maps/` 아래 직접 만든 맵의 이름 (아래 참고) |
| `units` | `place`는 이 스테이지의 유닛 (아래 참고). `copy_from`은 원작 한 스테이지의 출격 레코드를 통째로 복사합니다 (여러분의 ROM을 읽습니다. 「공유하기」 참고) |
| `events` | 이벤트 (아래 참고) |
| `objective` | 선택. 맵 메뉴의 「작전 목표」에 표시되는 승리·패배 문구이며, 한 줄은 30자 이내입니다. 이것을 쓰면 오프닝에 `{"op": "3D65", "args": [127, 127]}`를 써야 합니다 (편집기는 자동으로 씁니다). 쓰지 않으면 원작의 문구를 쓰며, 오프닝에는 `3D65 승리 번호, 패배 번호`를 씁니다 |
| `battle_lines` | 선택. 이 스테이지의 전투 중 새 대사. [스토리 MOD의 전투 대사](../mod-story/#전투-대사)와 같은 방식으로 쓰되, `scene`은 쓰지 않습니다 |
| `setup` | 선택: `route` (이 스테이지의 주인공 루트), `story_vars` (스테이지에 들어갈 때의 스토리 변수), `last_choice`, `initial_resources` |
| `scene` | 선택. 빌릴 장면 번호를 직접 지정합니다. 보통은 쓰지 않습니다 |
| `raw_events` | 선택. 원작 이벤트 형식의 이벤트 (원작 이벤트를 통째로 복사할 때 씀). [스테이지 스크립트 레퍼런스](../script-commands/) 참고 |

### 유닛 (units.place)

레코드 하나가 유닛 한 기입니다.

| 필드 | 의미 |
| --- | --- |
| `group` | 그룹 번호. 오프닝에서 `{"deploy": 그룹 번호}`로 이 그룹을 등장시키며, 증원도 때가 되면 `deploy`합니다 |
| `x`, `y` | 칸 좌표, 왼쪽 위가 0 |
| `pilot`, `unit` | 인물 번호, 기체 번호. 패키지의 새 인물과 새 기체는 `"@이름"` (이 패키지의 것) 또는 `"다른패키지id@이름"` (`requires`에 씀)으로 씁니다 |
| `faction` | 진영: 0 아군, 1 적, 2 또는 4 제3세력 |
| `level` | 이 스테이지의 기준 레벨에 더하는 값 |
| `upgrade` | 개조 단계 |
| `ai` | 적과 제3세력의 행동 방식: `{"mode": …, "wait": 턴, "target": 인물 번호, "to": [x, y]}`. `mode`는 `attack` (자유 공격, 장갑과 HP가 낮은 상대를 먼저 노림), `accurate` (자유 공격, 명중률로 상대를 고르며 명중 30% 미만인 무기는 쓰지 않음), `hunt` (`target`만 추격), `goto` (`to`로 이동하며 가는 길에 먼저 공격하지 않고, 공격받으면 반격), `flee` (`goto`와 같지만 공격받아도 반격하지 않음), `guard` (`target`을 호위하며 사거리 안이면 공격)입니다. `wait`는 제자리에서 움직이지 않는 턴 수이며, 31이면 계속 움직이지 않습니다 |
| `drop` | 격추될 때 떨어뜨리는 강화 파츠 번호 (0–37). 스테이지를 클리어해야 입수되며, 쓰지 않으면 떨어뜨리지 않습니다 |
| `entry` | 등장 시 남은 양: 1 HP 10%, EN과 탄수 0 / 2 HP와 EN 10% / 3·4·5 HP와 EN 30·50·70% / 6 HP 가득, EN과 탄수 0 / 7 HP 10%, EN 가득. 쓰지 않으면 가득 찬 상태입니다 |

`copy_from`을 쓰지 않을 때는 진영마다 최대 30기입니다. 아군 유닛은 등장하면 정식으로 합류해 다음 스테이지로 이어집니다.

### 이벤트 (events)

`when`은 두 가지 방식으로 씁니다.

- 문자열 `"opening"`, `"setup"`, `"end"`: 이 스테이지 자체의 오프닝, 배치, 종료 이벤트입니다. 각각 최대 하나이며 항상 실행되므로 `id`와 `if`는 쓰지 않습니다 (판정이 필요하면 `do` 안에 `if`를 씁니다). **모든 스테이지에는 오프닝이 있어야 합니다.** 종료 이벤트는 승리 처리 뒤에 실행됩니다.
- 객체: [스토리 MOD](../mod-story/)의 이벤트와 완전히 같습니다 (턴, 격추, HP, 전투, 적 전멸, 남은 기체 수, 구역 도달, 설득…). `id`가 있어야 하며 `scene`은 쓰지 않습니다. `fired`, `not_fired`는 같은 스테이지의 이벤트를 가리킵니다.

`do`에는 스토리 MOD의 모든 동작 (대사, 선택지, 등장, 이탈, 합류, 기체 교체, 변수, 음악, 카메라, 대기…)을 쓸 수 있고, 캠페인에서만 쓰는 동작이 다섯 가지 더 있습니다.

| 동작 | 의미 |
| --- | --- |
| `{"win": true}` | 스테이지 클리어. 승리 처리를 한 뒤 종료 이벤트를 실행합니다 |
| `{"lose": true}` | GAME OVER. 플레이어는 이 스테이지를 재도전할 수 있습니다. 오프닝 도중에는 실행하지 마세요 |
| `{"next": "스테이지 이름"}` | 클리어 후 어느 스테이지로 갈지. 종료 이벤트에 씁니다. 분기는 선택지나 `if`의 각 갈래에 다른 `next`를 쓰면 됩니다 |
| `{"ending": true}` | 엔딩을 재생하고, 끝나면 타이틀로 돌아갑니다. 마지막 스테이지의 종료 이벤트에만 씁니다 |
| `{"to_map": true}` | 오프닝에서 월드맵에서 전장으로 전환합니다 |

오프닝의 일반적인 순서: 월드맵에서 대사를 넣고, `to_map`으로 전장으로 전환하고, 작전 목표를 정하고, `deploy`로 각 그룹을 등장시키고, 마지막으로 `{"op": "3D48"}`로 대화창을 닫고 플레이어에게 넘깁니다 (예제 캠페인이 이렇게 씁니다). 새 대사는 `story/<언어>/*.txt`에 쓰고 `text`를 `"@이름"`으로 쓸 수도 있습니다. [스토리 MOD](../mod-story/#대사를-텍스트-파일에-쓰기)와 같습니다.

원작 명령도 그대로 쓸 수 있습니다. 예를 들어 `{"op": "3D5B", "args": [10]}`은 자금 1만을 더하고, `{"op": "3D3D", "args": [0, 0, 0, 최대 기체 수, 그룹 번호]}`는 플레이어가 부대에서 출격할 인원을 고르게 해 그 그룹의 첫 번째 레코드 위치에 놓습니다 (편집기의 「출격 선택」(Choose the sortie)이 바로 이 명령입니다). 명령은 [스테이지 스크립트 레퍼런스](../script-commands/)에 있습니다.

## 직접 그린 맵

`maps/<맵 이름>/map.json`을 바탕 그림 한 장과 함께 두고, 스테이지에 `"map": "맵 이름"`을 씁니다.

```json
{"schema": "srw64.map.v1", "like": 20, "image": "base.png", "scale": 4,
 "terrain": [[99, 99, 99], [99, 5, 1]]}
```

- `image`: 맵 전체 그림이며, 크기는 칸 수 × 16 × `scale`입니다 (`scale`은 기본 4, 1–8). 28×32칸에 `scale` 4라면 1792×2048입니다. HD 이미지에서는 이 그림을 그리고, 원작 이미지에서는 도구가 품질을 낮춰 만든 그림을 그립니다.
- `terrain`: 칸마다 지형 번호 하나 (63은 벽). 행 수와 열 수는 바탕 그림의 칸 수와 같아야 합니다. 가장 바깥 두 줄은 맵 테두리이며, 무엇을 써도 테두리로 처리됩니다. 편집기의 지형 목록에 지형마다 이름, 방어, 명중, 회복, 이동 비용이 나와 있습니다.
- `like`: 어느 원작 맵의 자리를 대신 차지할지. 이 스테이지의 BGM, 우주인지 아닌지, 전투 배경, 수면 색은 그 맵을 따르므로 같은 종류의 장소를 고르세요. 콜로니 애니메이션이 없는 맵만 고를 수 있으며, 우주 맵은 66, 74, 112, 137, 157만 고를 수 있습니다.
- 크기는 20×15칸부터 128×128칸까지입니다.

편집기의 맵 페이지가 하는 일이 바로 이것입니다. 직접 쓸 때는 `pack.py`가 맵 도구를 자동으로 호출합니다. 따로 결과를 보려면 `python3 tools/mods/map_tool.py build maps/<맵 이름> -o 출력 폴더`를 실행하세요. 원작 이미지에서의 모습인 `preview.png`가 함께 만들어집니다.

## 시작 상태와 피해야 할 것

- **캠페인은 아무것도 없는 상태로 시작합니다.** 부대 명단은 비어 있고, 주인공과 파트너는 이름이 없습니다. 아군은 스테이지에 놓은 아군 레코드로 등장하거나 (등장하면 정식으로 합류합니다) 스토리 동작 `join`으로 합류합니다.
- **부대, 자금, 개조, 변수는 다음 스테이지로 이어지며**, 세이브에도 보존됩니다.
- **스토리 변수**는 0–3의 값만 가집니다. 원작 스크립트는 0–54를 계속 읽고, 스테이지에 들어갈 때 100–114와 128–139는 초기화됩니다. 캠페인 자체의 변수는 60–99를 쓰세요 (편집기의 「＋ 새 변수」(+ New variable)도 여기서 고릅니다).
- 원작 대사 중 `{HeroName}`, `{PartnerName}`이 들어간 것과 원작 주인공 자신이 말하는 것은 빌려 쓰지 않는 편이 좋습니다. 시작할 때 주인공에게 이름이 없기 때문입니다.
- **알려진 크래시**: 캐릭터가 맵에 없을 때의 `3D49`, 아직 맵에 있는 기체를 `3D5A …, 4000`으로 지우기 (먼저 이탈시키세요).
- 캠페인 안에서는 링크 메뉴가 비활성화됩니다.

## 컴파일과 묶기

```bash
python3 tools/mods/pack.py my-campaign -o build/mods
```

컴파일러는 웹사이트의 스테이지 편집기와 같은 것 (TypeScript)이며, 명령줄에서는 [Node.js](https://nodejs.org/) 23 이상이 필요하고 `python3`가 자동으로 호출합니다. `pack.py`는 캠페인 전체를 컴파일해 `build/mods/<id>-<version>.srw64mod`를 만들고, 게임과 같은 규칙으로 검사합니다. 잘못 쓴 곳이 있으면 어느 스테이지, 어느 이벤트의 어느 항목인지 알려 줍니다. 각 스테이지가 무엇으로 컴파일되는지만 보고 싶다면:

```bash
python3 tools/mods/stage.py compile my-campaign -o /tmp/out
```

## 설치와 플레이

1. `.srw64mod`를 게임 창에 끌어다 놓아 설치합니다 (또는 MOD 폴더에 넣습니다. [MOD 패키지](../mods/#설치) 참고).
2. 타이틀 화면에서 “MOD”를 열고 “추가 시나리오” 화면으로 가서, 캠페인 줄의 “플레이”를 누릅니다.
3. 타이틀 화면 가운데에 “캠페인 시작”과 캠페인 이름이 나타납니다. 거기서 시작하세요. 이제 타이틀에서 불러오기를 하면 이 캠페인의 세이브를 불러옵니다.
4. 본편으로 돌아가려면: 같은 화면의 “본편으로 돌아가기”를 누릅니다. 전환은 타이틀 화면에서만 할 수 있습니다.

캠페인의 세이브는 본편과 별도로 사용자 폴더의 `campaigns/<id>/saves/`에 있습니다.

## 공유하기

편집기로 만든 패키지는 번호와 여러분이 직접 쓴 것만 쓰므로 공개적으로 공유할 수 있습니다. 직접 쓸 때 `copy_from`, `template`, 원작 이벤트의 `copy_from`을 쓰면 여러분의 ROM에 있는 원작 데이터가 패키지에 복사되며, 이렇게 만든 패키지는 자신이 플레이하는 용도로만 써야 합니다. 텍스트, 맵, 캐릭터, 기체 번호는 번호일 뿐이므로 괜찮습니다. 직접 그린 맵은 배포할 권리가 있는 그림이어야 합니다. 그 밖에는 [MOD 패키지 저작권 규칙](../mods/#저작권)을 따릅니다.
