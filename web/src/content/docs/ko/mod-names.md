이 MOD는 게임이 **표시하는** 이름과 초상화만 바꿉니다. 대사, 화자 이름, 상태 화면, 전투 확인 화면, 도감, 맵 이름표가 이를 따릅니다. 세이브에는 원래 이름이 그대로 남으므로 패키지를 끄면 모두 원래대로 돌아오고, 세이브는 원작 게임을 포함해 어디서든 불러올 수 있습니다.

직접 작성하지 않아도 웹 도구가 .srw64mod를 만들어 줍니다. [이름·초상화 MOD 제작 도구](/ko/mods/names/)는 이름과 초상화를 받아 그림을 알아서 자르고 크기를 맞춰 줍니다. [맵 아이콘 MOD 제작 도구](/ko/mods/icons/)는 원작 아이콘과 HD 아이콘을 사용자의 아이콘 옆에 보여 주며, 아군, 적, 행동 완료 상태로 미리 볼 수 있습니다.

패키지 설치와 관리: [MOD 패키지](../mods/). 0.5.2 이상이 필요합니다.

## 패키지에 들어가는 것

```text
yourname.heroes/
  mod.json
  dialogue/names.json          이름
  art/portraits/133.png        초상화, 파일럿 번호로 이름을 붙임
  art/icons/184.png            맵 아이콘, 기체 번호로 이름을 붙임
  art/icons.json               선택: 그림의 방향이 원작과 다를 때
```

이 중 하나만 있어도 됩니다.

## 이름(dialogue/names.json)

```json
{
  "schema": "srw64.mod-names.v1",
  "heroes": {
    "super-male": {
      "hero":    { "en": { "name": "Takuma", "surname": "Amano", "nickname": "Takuma" } },
      "partner": { "en": { "name": "Minato", "surname": "Hojo" } }
    }
  },
  "unit": { "en": "Daybreak" },
  "pilots":  { "133": { "en": { "name": "Shingo", "full": "Shingo Hojo" } } },
  "units":   { "184": { "en": "GoShogun Kai" } },
  "weapons": { "731": { "en": "Super Bazooka" } }
}
```

모든 항목은 언어별로 씁니다: `zh-Hans`(간체 중국어), `zh-Hant`(번체 중국어. 없으면 간체를 사용), `en`, `ja`, 그리고 설치된 [언어 패키지](../mod-language/)의 언어. 빠진 언어는 평소 이름을 표시합니다. 여러 패키지가 같은 대상의 이름을 바꾸면 MOD 목록에서 위에 있는 패키지가 우선합니다.

### 원작 주인공, 파트너, 부대(heroes, unit)

- `heroes`는 네 루트 `super-male`, `super-female`, `real-male`, `real-female`로 나뉘며, 각각 `hero`와 `partner`를 가집니다.
- 각 언어에는 `name`(필수), `surname`, `nickname`(없으면 이름을 사용)을 씁니다. 풀네임은 언어별로 이어 붙입니다. 영어는 공백, 중국어는 「·」, 일본어는 「・」로 잇습니다.
- 원작은 대사에 주인공 이름을 채워 넣으므로 대사도 이를 따릅니다.
- 부대 이름을 지정하면 이름을 정하는 장면이 “마음에 안 든다” 분기로 진행합니다. 주인공이 마치 윈드를 거절하고 패키지의 이름을 제안합니다. 이미 지나간 장면은 다시 재생되지 않습니다.

### 그 밖의 파일럿, 기체, 무기(pilots, units, weapons)

- [ID 표](/ko/mods/ids/)의 번호로 지정합니다. 파일럿에는 `name`(짧은 이름, 필수)과 `full`(없으면 짧은 이름을 사용)을 쓰고, 기체와 무기에는 이름만 씁니다.
- 무기 메뉴의 격투/사격 표시와 P, B, MAP 표시는 자동으로 붙습니다.
- 이름 자체가 바뀌므로 화자 이름, 상태 화면, 맵은 이를 따르지만, **그 이름을 언급하는 대사 본문은 바뀌지 않습니다**.

### 길이

이름은 세이브에 기록되지 않으므로 원작의 칸 수에 묶이지 않지만, 공간이 좁은 곳이 있습니다. 맵 이름표와 전투 이름 바는 폭이 고정되어 있습니다.

- 주인공의 이름, 성, 닉네임이 원작의 칸 수(이름과 성은 7칸, 닉네임은 5칸)를 넘거나 제가 번역한 이름 중 가장 넓은 것보다 넓을 때, 그리고 부대 이름이 10칸을 넘을 때는 로그에 `SRW64_MOD_NAMES_WARNING` 줄이 남습니다. 이름은 그래도 사용됩니다. 가장 자주 표시되는 것은 닉네임이므로 5칸 정도로 맞추세요.
- 절대 한도: 주인공의 이름, 성, 닉네임은 16자, 부대와 그 밖의 모든 이름은 24자입니다. 이를 넘거나 모르는 필드나 언어가 있으면 **파일 전체가 제외되고** 로그에 `SRW64_MOD_NAMES_PROBLEM`이 남습니다.
- 이름에 줄바꿈, 전각 공백, `< > { }`를 넣을 수 없으며, 앞뒤에 공백을 둘 수 없습니다.

일본어로 원작 이미지를 쓰는 경우, 원작 화면은 게임 자체의 글리프로 그려지는데 이 글리프로는 패키지의 이름을 그릴 수 없습니다. 그런 곳에서는 이름만 이 포트의 자체 글꼴로 그리고, 주변 텍스트는 원작 글리프로 그립니다.

## 초상화(art/portraits)

- 파일 이름은 **파일럿 번호**에 `.png`를 붙입니다. 예: `art/portraits/133.png`.
- 정사각형, 96~2048픽셀이며 96의 배수(96, 192, 384, 768…)여야 합니다. 투명도를 써도 되며, 뒤에 있는 그림이 비쳐 보입니다.
- 대사, 전투, 상태 화면, 전투 확인 화면, 도감, 세이브 슬롯 모두 이 초상화를 사용하며, 이미지를 원작으로 설정했든 HD로 설정했든 똑같습니다.
- 같은 원작 초상화를 쓰는 파일럿(예: 한 캐릭터의 다른 번호들)은 모두 함께 바뀝니다.
- 초상화가 있는 파일럿의 번호가 아닌 이름이거나 크기가 틀린 파일은 건너뛰고, 로그에 `SRW64_MOD_PORTRAITS_PROBLEM`이 남습니다.

## 맵 아이콘(art/icons)

- 파일 이름은 **기체 번호**에 `.png`를 붙입니다. 예: `art/icons/184.png`.
- 정사각형, 16, 32, 64, 128픽셀 중 하나이며 픽셀 아트로 그립니다. 게임이 흐리게 하지 않고 픽셀 단위로 128까지 확대합니다. 투명도를 써도 됩니다.
- 기체 본래의 색으로 한 번만 그리면 됩니다. 적과 제3세력에는 각 진영의 색(빨강, 노랑) 테두리가 붙고, 행동을 마친 기체는 알아서 회색이 됩니다.
- **방향**: 게임은 진영마다 아이콘을 뒤집어, 아군은 왼쪽, 적은 오른쪽을 보게 합니다. 정면을 보는 아이콘은 뒤집지 않습니다. 사용자의 그림은 원작 아이콘과 같은 방향을 보고 있다고 간주합니다(원작 아이콘은 [ID 표](/ko/mods/ids/units/)에서 볼 수 있습니다). 그렇지 않다면 `art/icons.json`에 적어 주세요. 예:

  ```json
  { "schema": "srw64.icons.v1", "facing": { "55": "left", "184": "front" } }
  ```

  값은 `left`, `right`, `front`입니다. 원작이 정면을 보더라도 옆모습으로 그려서 표시해 두면 진영마다 뒤집힙니다.
- 같은 원작 아이콘을 쓰는 기체(예: 한 기체의 다른 번호들)는 모두 함께 바뀝니다. 한 패키지에서는 그중 하나에만 그림을 넣으세요.
- 이미지를 원작으로 설정했든 HD로 설정했든 표시됩니다. 기체 번호가 아닌 이름이거나 크기가 틀린 파일은 건너뛰고, 로그에 `SRW64_MOD_ICONS_PROBLEM`이 남습니다.

## 예시

예시 패키지 “이름 변경 예시”(Renaming Example)는 [`config/recomp/mods/hero-names`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/hero-names)에 있습니다. 슈퍼로봇 루트 남자 주인공, 그의 파트너, 부대의 이름을 바꿉니다.
