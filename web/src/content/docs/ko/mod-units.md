이 MOD는 게임에 **원작에 없는** 기체, 무기, 인물을 추가합니다. 자체 번호를 가지고 원작의 모든 인물과 기체 옆에 나란히 놓이며, 누구도 대체하지 않습니다. 원작 기체나 원작 인물 하나를 복사해 출발점으로 삼고, 이름, 수치, 무기, 그림, 대사를 바꿉니다.

패키지 하나로 추가할 수 있는 것:

- **변형하는 기체**. 형태마다 무기와 맵 아이콘이 따로 있습니다.
- **맵에서 합체하는 기체**: 패키지에 쓴 조합대로 합체하고, 다시 분리할 수 있으며, 합체한 상태로 출격할 수도 있습니다. 합체 기체를 개조해도 각 파츠의 개조는 지워지지 않습니다.
- **새 무기**. **합체 공격**도 만들 수 있습니다. 파트너, EN, 기력은 원작과 같은 규칙으로 판정하며, 무기 화면, 도감, 전투 뷰어에 파트너가 표시됩니다.
- **새 인물**. 자체 초상화, **전투 대사와 음성**(일반 전투 상황, 또는 특정 무기를 쓰거나 특정 상대를 만났을 때), 자체 **전투곡**을 가집니다.
- **적 쪽의 새 기체와 새 인물**. 스토리에서 등장시킵니다.
- **자체 서 있는 모습, 전투 그림, 컷인**: 서 있는 모습과 기술 연출 속의 장면을 HD 이미지용과 원작 이미지용으로 한 장씩 넣습니다.

새 기체와 새 인물은 도감과 전투 뷰어에 자기 그림과 작품명으로 나옵니다.

0.5.4 이상이 필요합니다. 패키지 설치와 관리는 [MOD 패키지: 설치와 제작](../mods/)을 참고하세요.

## 기체 MOD 제작 도구로 만들기

웹사이트의 [기체 MOD 제작](/ko/mods/units/) 도구로 이런 패키지를 브라우저에서 만들 수 있습니다. **그림과 녹음은 어디에도 업로드되지 않습니다.**

1. 원작 인물, 기체, 무기 중 하나를 복사하고, 네 언어의 이름, 수치, 무기, 형태, 탑승자, 합체 공격을 바꿉니다.
2. 자기 그림에서 초상화를 잘라냅니다. 기체에 서 있는 모습, 컷인이 있는 전투 그림, 맵 아이콘을 넣으면 브라우저가 게임에서 쓰는 색 수로 줄여 줍니다.
3. 네 언어의 전투 대사를 씁니다. 대사마다 음성을 넣고 파형 위에서 잘라낼 수 있으며, 전투곡도 넣을 수 있습니다.
4. 게임에 들어 있는 효과로 무기 연출을 조합합니다. 배우를 하나씩 또는 발사 위치째로 움직이고, 원작의 어떤 무기에서든 배우를 빌려 오고, 컷인을 넣고, 원작 효과의 색을 바꿉니다. 내 ROM을 고르면 무대에 원작 효과가 그려집니다(ROM은 브라우저 안에서만 읽고 업로드하지 않습니다).
5. 이 기체가 언제 합류하는지와 패키지 자체의 증원을 씁니다. `.srw64mod`로 내보내며, Thunderstore 패키지로도 내보낼 수 있습니다.

바로 고쳐 쓸 수 있는 템플릿이 들어 있습니다. 게임의 「정보」 페이지에 있는 스위치(기본은 꺼짐)를 켜면 제작 도구가 실행 중인 게임에 패키지를 바로 보내 전투 뷰어에서 시험할 수 있습니다. 게임은 받기 전에 먼저 묻습니다.

지금 제작 도구에서 복사하거나 연출을 빌리거나 기체에 달 수 있는 것은 흔한 범용 무기(빔 라이플, 빔 사벨, 발칸, 머신건, 미사일, 바주카, 빔 캐논, 캐논, 격투, 몸통 박치기, 도끼, 사벨)와, 기체가 복사한 원래 기체의 무기뿐입니다. 다른 무기는 나중에 열립니다. 더 복잡한 패키지는 아래 형식대로 직접 쓰거나 AI 어시스턴트에게 맡기세요.

## 패키지에 들어가는 것

```text
yourname.rival/
  mod.json
  data/new_units.json            새 기체, 새 무기, 새 인물, 새 전투 그림(필수)
  data/units.json、pilots.json、weapons.json
                                 선택: 복사해 온 뒤의 수치 변경(수치 MOD 방식)
  dialogue/names.json            이름(이름 MOD 방식)
  dialogue/battle_quotes.json    선택: 새 인물의 전용 전투 대사
  art/…                          서 있는 모습, 전투 그림, 초상화, 맵 아이콘
  audio/…                        선택: 음성, 전투곡
  story/…                        선택: 합류 시점, 적 쪽 등장(스토리 MOD)
```

## new_units.json

```json
{
  "schema": "srw64.new-units.v2",
  "scenes":  { "cannon-pose": [2560, 1716, 2118] },
  "weapons": { "cannon": { "copy": 875, "inherits_from": 875,
                           "animation": { "camera": 1, "hit": 59, "action": 84, "defender": 125, "sounds": [219],
                                          "actors": [ { "scene": "@cannon-pose", "h4": 1, "h5": 255, "behavior": 359 } ] } } },
  "units":   { "final": { "copy": 224, "pose": [2324, 1724, 2016], "icon": 978,
                          "weapons": [870, 871, "@cannon"], "inherits_from": 224,
                          "crew": [171, 168, 170, 169, 166] } }
}
```

새 기체, 새 무기, 새 인물, 새 전투 장면은 모두 **이름으로 쓰고**, 번호는 게임이 정합니다. 기체는 400–998, 무기는 1400–2399, 인물은 400–511, 장면은 원작 장면 다음부터입니다. 원작의 번호는 하나도 차지하지 않습니다.

- 이름에는 영문 소문자, 숫자, `-` `_` `.`만 씁니다. 패키지의 다른 파일에서는 `@이름`으로 이 패키지의 새 항목을 가리킵니다. `data/units.json`에는 `"@final": {"hp": 8000}`, `dialogue/names.json`의 `units`에는 `"@final"`, 맵 아이콘은 `art/icons/@final.png`, 스토리 MOD에서는 `"with": "@final"`, `"unlock": "@cannon"`처럼 씁니다. 다른 패키지의 항목은 `패키지id@이름`으로 쓰고, 그 패키지를 `mod.json`의 `requires`에 넣습니다.
- 번호는 「패키지 id@이름」으로 계산되므로, 같은 패키지라면 어느 기기에서 어떤 순서로 설치해도 같습니다. 두 이름이 같은 번호로 계산될 때만 한쪽이 한 칸 뒤로 밀립니다. 세이브 옆에는 각 번호가 어느 패키지의 어느 이름인지 기록됩니다. 나중에 설치한 패키지 때문에 번호가 밀렸다면 불러올 때 지금 번호로 자동으로 고치고, 패키지를 끈 상태로 이런 세이브를 불러오면 어느 패키지가 필요한지 알려 주며 타이틀 화면으로 돌아갑니다.

### 기체(units)

| 필드 | 의미 |
| --- | --- |
| `copy` | 복사할 기체(자체 전투 레코드가 있는 원작 기체 번호, 또는 다른 새 기체). 수치, 무기, 그림이 먼저 여기서 옵니다. 복사할 때 변형, 분리, 합체는 빠집니다 |
| `pose` | 서 있는 모습: 원작의 `[장면, 아틀라스, 팔레트]` 세 리소스 번호, 또는 패키지의 `"@그림 이름"`([직접 만든 전투 그림](#직접-만든-전투-그림) 참고) |
| `icon` | 맵 아이콘: 원작 아이콘 번호. 패키지에 `art/icons/@이름.png`가 있으면 그것을 씁니다 |
| `weapons` | 무기 목록: 원작 무기 번호와 `@새 무기` |
| `inherits_from` | 스토리에서 이 기체로 교체할 때(스토리 MOD의 `replace`) 개조 단계를 이 이전 기체에서 옮겨 옵니다 |
| `crew` | 인물 번호 1–5개. 첫 번째가 메인 파일럿입니다. 이 기체가 메인 파일럿에게 등록되면 나머지 인물이 탑승자가 됩니다 |
| `combine` | 파츠의 합체로 만들어짐. 아래 참고 |
| `forms` | 변형. 아래 참고 |
| `work` | 도감 상세에 나오는 원작품. 원작 작품 번호 0–24이며, 쓰지 않으면 복사한 기체를 따릅니다. 도감의 형식 번호 줄은 `dialogue/names.json`의 `models`에 씁니다(최대 48자) |

패키지가 추가한 기체와 인물은 도감 맨 끝의 「MOD」 그룹에 나옵니다. 새 기체 수에는 제한이 없습니다.

**합체**: `"combine": {"parts": [파츠 2–5기], "over": [원작 합체 기체]}`. 파츠의 순서가 곧 탑승자의 순서(각 파츠의 메인 파일럿)입니다. 맵에서 원작 합체 기체(`over`)의 「합체」가 성립하고 나머지 파츠(예: 블랙 윙)도 옆에 있으며 아직 행동하지 않았다면, 합체 결과가 이 새 기체가 됩니다. 「분리」하면 모든 파츠로 돌아갑니다. 이 기체는 스토리 MOD의 `build`로 만들어지며([스토리 MOD](../mod-story/)), 스스로 스테이지 시작 때 출격하지는 않습니다.

**변형**: 기본 형태에 `"forms": ["@wr"]`로 다른 형태 1–2개(같은 파일의 새 기체)를 나열합니다. 각 형태는 평소처럼 자기 `weapons`, `pose`, `icon`을 씁니다. 모든 형태의 무기는 하나의 공용 목록으로 합쳐지고, 각 무기는 그 무기를 나열한 형태에서만 쓸 수 있습니다. 개조 단계, 무기 개조 단계, 탑승자는 원작처럼 형태 전체가 공유합니다. 맵 메뉴에 「변형」이 나오며(형태가 셋이면 선택 메뉴가 열립니다), 스테이지 시작 때 출격하는 것은 기본 형태입니다. 기체 하나는 변형 계열 하나에만 속할 수 있으며, 원작 기체는 넣을 수 없습니다.

### 무기(weapons)

- `copy`는 원작 무기 하나를 복사합니다. `inherits_from`은 이 새 무기의 개조 단계를 이전 기체의 어느 무기에서 가져올지 정합니다(이전 기체에 원래 있던 무기는 그대로 옮겨집니다).
- `animation`은 전투 연출입니다: 카메라, 명중 효과, 동작, 방어 측의 반응, 효과음, 배우(배우의 `scene`에는 패키지의 `@장면`을 쓸 수 있습니다). 이 부분은 기체 MOD 제작 도구로 조합하는 것이 가장 편합니다.
- 복사한 무기의 격투/사격, 이동 후 사용, 빔을 `data/weapons.json`에서 바꾸면 메뉴 이름 앞뒤의 「格／射」「P」「B」가 따라 바뀝니다.

**합체 공격**: `"combination": {"units": ["@z", 228], "parts": [196, 899], "multiplier": 1.5}`. `units`는 참가하는 기체 2–5기(원작 번호 또는 `@이름`)이고, `parts`는 같은 순서로 각 기체가 내는 무기를 씁니다. 공격력은 그 무기들의 현재 공격력의 평균에 `multiplier`를 곱한 값입니다. 선택으로 `pilots: [[인물, 인물], …]`를 쓰면 메인 파일럿들이 그중 한 조를 갖춰야 합니다. 무기 목록에 이 무기가 있는 참가 기체는 누구든 앞장설 수 있습니다. 참가 기체는 모두 맵에 있고 하나로 이어져 있어야 하며(8방향 인접), 각자 EN과 기력이 충분해야 합니다. 공격하면 모든 기체에서 이 무기의 EN이 줄고 탄수는 줄지 않으므로, 탄수를 쓰는 무기를 복사했다면 `data/weapons.json`에서 `en`과 `"ammo": -1`을 지정하세요. 파트너가 없으면 맵의 무기 화면에서 회색으로 표시되고 누가 없는지 알려 줍니다. 합체 공격은 원작처럼 개조할 수 없습니다. `dialogue/names.json`의 `weapons`에서 이름을 붙이는 것을 잊지 마세요. 그러지 않으면 복사한 무기의 이름이 나옵니다.

### 인물(pilots)

```json
"pilots": { "kai": { "copy": 166, "voice": 166,
                     "portrait": { "image": "art/kai.png", "hd": "art/kai-hd.png" } } }
```

| 필드 | 의미 |
| --- | --- |
| `copy` | 복사할 원작 인물(능력 레코드가 있어야 함). 능력치, 특수기능, 정신기, 초상화, 전투곡이 여기서 옵니다 |
| `voice` | 전투에서 누구의 대사를 빌려 쓸지. 쓰지 않으면 `copy`입니다. 패키지에 이 인물의 전용 전투 대사가 있어도, 쓰지 않은 상황에서는 이 인물의 대사를 말합니다 |
| `portrait` | 패키지의 초상화: `image`는 96×96, 최대 63색의 픽셀 그림이고, `hd`는 한 변이 96의 정수배인 정사각형 고해상도 그림입니다(생략 가능). 원작 리소스 번호 두 개 `[그림, 팔레트]`로 써도 되고, 쓰지 않으면 복사한 인물의 초상화를 씁니다 |
| `love` | 선택. 연애/우정 보정: `[{"with": 166, "mutual": true}]`. 2칸 이내에 있으면 공격 +30%, 받는 피해 −30%이며, `mutual`이면 상대도 같은 보정을 받습니다 |
| `combo_as` | 선택. 합체 공격의 파일럿 조건에서 어느 원작 인물로 칠지 |

모든 패키지를 합쳐 새 인물은 최대 112명입니다. 수치, 특수기능, 정신기는 `data/pilots.json`의 `"@kai"`로, 이름은 `dialogue/names.json`의 `pilots."@kai"`로 바꾸고, 합류는 스토리 MOD의 `{"join": {"pilot": "@kai", "unit": 9}}`로 합니다.

`image`는 저장소의 도구로 큰 그림에서 줄여 만들 수 있습니다.

```bash
python3 tools/mods/sprite_pixels.py 大图.png kai.png --size 96 96 --colors 63
```

## 새 인물의 전용 전투 대사

```json
{
  "schema": "srw64.battle-quotes.v1",
  "pilots": {
    "@kai": {
      "attack":  [{"ja": "「カイ、行くぞ!」", "zh-Hans": "“凯，上了！”", "en": "\"Kai, here I come!\"", "voice": "kai-attack.ogg"},
                  {"ja": "「これでも食らえ!」", "zh-Hans": "“吃我这招！”"}],
      "evade":   [{"ja": "「見切った!」", "zh-Hans": "“看穿了！”"}],
      "special": [
        {"weapon": 49, "lines": [{"ja": "「全力の一撃だ!」", "zh-Hans": "“全力一击！”"}]},
        {"opponent": 298, "situation": "evade", "lines": [{"ja": "「そんな攻撃が当たるか!」", "zh-Hans": "“这种攻击打不中我！”"}]}
      ]
    }
  }
}
```

`dialogue/battle_quotes.json`에 둡니다. 패키지의 새 인물(`@이름`, 또는 다른 패키지의 `패키지id@이름`)에게만 쓸 수 있으며, 원작 인물의 대사는 바꿀 수 없습니다.

- 상황은 아홉 가지이며, 원작처럼 매번 그 묶음에서 무작위로 한 줄을 말합니다: `attack` 공격, `shot_down` 격추당함, `heavy` 큰 피해(남은 HP 30% 미만), `medium` 중간 피해(30–90%), `light` 작은 피해(90% 이상), `evade` 회피, `no_damage` 공격 무효(배리어, 장갑), `no_ammo` 탄약이나 EN이 부족해 반격할 수 없음, `out_of_range` 사거리 밖이라 반격할 수 없음. **쓰지 않은 상황에서는 `voice` 인물의 대사를 말하며**, 대사 창에도 그 인물의 이름과 초상화가 나옵니다.
- 대사 하나는 객체 하나입니다: 언어별 대사(`ja`는 반드시 있어야 하며 최대 42자로 딱 한 페이지 세 줄, 다른 언어는 최대 200자이며 리더가 대사 창 폭에 맞춰 배치합니다). 선택으로 `voice`에 `audio/voice/battle/` 안의 `.ogg` 파일 이름을 쓰면 그 대사가 나올 때 재생됩니다(Ogg Vorbis만 됩니다. [음악 MOD](../mod-music/#전투음성) 참고).
- `special`은 조건이 있는 대사이며, 조건이 충족되면 반드시 그 대사를 말합니다.
  - `"weapon": 무기`: 이 무기로 공격할 때(원작 무기 번호 또는 `@새 무기`). 이름이 같은 무기는 같은 무기로 치고, 새 무기는 복사한 원래 무기로 칩니다. `"sometimes": true`를 붙이면 원작의 일부 무기 대사처럼 일반 공격 대사에 자주 밀립니다.
  - `"opponent": 원작 인물`: 상대가 이 인물일 때. `situation`에는 아홉 상황 중 하나를 씁니다(기본 `attack`).
  - 조건 대사는 인물 한 명당 합계 최대 119줄입니다. 여러 조건이 동시에 충족되면 그중 하나를 무작위로 고릅니다.
- 대사 번호는 게임이 정하며(모든 패키지 합계 최대 2048줄), 세이브에는 기록되지 않습니다. 패키지를 끄면 빌려 쓰던 대사로 그대로 돌아갑니다.

새 인물의 전투곡은 패키지의 `audio/music.json`에 씁니다: `"battle": {"pilot": {"@kai": "@kai-theme"}}`. 곡은 `audio/music/kai-theme.ogg`에 둡니다. [음악 MOD](../mod-music/)를 참고하세요.

## 직접 만든 전투 그림

새 기체의 서 있는 모습, 기술 연출 속의 장면, 컷인에는 모두 패키지의 PNG를 쓸 수 있습니다. `new_units.json`에 `sprites`를 씁니다.

```json
"sprites": {
  "stand":  { "image": "art/battle/stand.png", "origin": [59, 90], "hd": "art/battle/stand-hd.png" },
  "cutin":  { "image": "art/battle/cutin.png", "origin": [56, 48], "mirror": false, "ticks": [22], "hd": "art/battle/cutin-hd.png" }
},
"scenes": { "cutin": "@cutin" },
"units":  { "final": { "pose": "@stand" } }
```

- `image`는 게임 안의 실제 크기 픽셀 그림입니다(서 있는 모습은 약 128×96). 최대 127색이며, 반투명 이하는 투명으로 처리합니다. `python3 tools/mods/sprite_pixels.py 大图.png 小图.png --size 128 96`으로 큰 그림을 줄이고 색을 줄여 만들 수 있습니다.
- `hd`는 프레임마다 한 장씩 넣는 고해상도 그림입니다. HD 이미지에서는 이것을, 원작 이미지에서는 `image`를 그립니다. 개조나 능력 같은 화면과 도감도 이 두 장을 씁니다.
- `origin`은 그림에서 장면 원점에 해당하는 픽셀입니다. 서 있는 모습은 발밑 가운데로 씁니다.
- `mirror`는 기본이 `true`입니다: 기체와 기술 연출 속의 그림이 진영에 따라 좌우 반전됩니다. 컷인처럼 반전하면 안 되는 것은 `false`로 씁니다.
- 여러 프레임은 `"frames": [...]`로 쓰고, `"ticks"`(프레임마다 몇 박)와 `"loop"`(끝나면 몇 번째 프레임으로 돌아갈지)를 함께 씁니다.
- `"around": [앞, 뒤]`: 어떤 무기 효과는 「다음 장면」으로 바뀝니다(예: 빔은 빔 몸통, 빔 꼬리로 차례로 바뀝니다). 이런 배우에 자기 그림을 넣을 때는 이것을 써야 합니다. 기체 MOD 제작 도구의 「그림 바꾸기」가 자동으로 써 줍니다. 일부 무기(약 95개, 예를 들어 여럿이 함께 쓰는 필살기)의 연출은 장면 번호로 서로를 계산하므로, 이런 무기의 배우는 그림을 바꿀 수 없습니다(컷인은 넣을 수 있습니다). 제작 도구는 「그림 바꾸기」를 잠그며, 게임도 이런 패키지를 불러오지 않습니다.
- 서 있는 모습 `pose`와 장면 총표 `scenes`에는 `@그림 이름`을 쓰며, 원작의 세 리소스 번호를 그대로 써도 됩니다.
- 색 바꾸기: `scenes`에 `{"recolor": 56, "colors": {"2": "#20e060"}}`라고 쓰면 원작 전투 장면 56(빔)의 그림과 동작은 그대로 두고 팔레트에서 적은 칸만 새 색으로 바꿉니다(칸 번호 0–255, 투명한 칸은 투명 그대로). 원작 화면과 HD 화면 모두 따라 바뀝니다. **0.5.4.1 이상의 게임이 필요**하며 `mod.json`의 `game`은 `">=0.5.4.1"`로 씁니다. 기체 제작기에서는 「전투 연출 → 색」에서 눌러 바꾸고, 내보낼 때 자동으로 적어 넣습니다.

원작 그림을 빌려 쓰고 HD 팩으로 그림을 바꾸는 패키지는 `mod.json`에 `"requires": {"srw64.hd": ">=1.3"}`을 씁니다. HD 팩이 없거나 이미지가 원작으로 설정되어 있으면 패키지 전체가 불러와지지 않고, MOD 페이지에 「HD 이미지가 필요합니다」라고 표시됩니다. 게임 안에서 이미지 설정을 바꾸면 다시 시작해야 반영됩니다.

## 합류시키기, 적에게 쓰게 하기

새 기체와 새 인물은 설치해도 저절로 나타나지 않습니다. 언제 합류하는지를 스토리로 써야 합니다([스토리 MOD](../mod-story/)).

- `{"join": {"pilot": "@kai", "unit": "@rz"}}`: 인물과 기체가 아군에 합류합니다.
- `{"replace": {"pilot": 171, "unit": 224, "with": "@final"}}`: 명단의 이전 기체를 새 기체로 바꾸고, 개조 단계는 `inherits_from`대로 옮깁니다.
- `{"build": "@final"}`: 아군에 합체 기체(`combine`을 쓴 새 기체)를 한 대 만듭니다.
- `{"unlock": "@cannon"}`: 스토리에서 해금되는 새 무기를 해금합니다.
- 스토리 파일의 `deployments`: 적과 제3세력도 패키지의 새 기체와 새 인물을 쓸 수 있습니다.

[캠페인](../mod-campaign/)의 출격 레코드에도 `@이름`을 쓸 수 있습니다.

## 예시

- “파이널 단쿠가”: [`config/recomp/mods/final-dancouga`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/final-dancouga). 원작 파이널 단쿠가를 복사한 새 기체로, 탑승자가 다섯 명이고 자체 서 있는 모습, 컷인, 맵 아이콘이 있습니다. 맵에서 단쿠가와 블랙 윙이 합체하며, 분리했다가 다시 합체할 수 있고, 합체한 상태로 출격할 수도 있습니다. [MOD 다운로드](/ko/mods/#srw64.final-dancouga) 페이지에서 받을 수 있습니다.
- “카츠와 슈퍼 어스게인”: [`config/recomp/mods/super-earthgain`](https://github.com/dyzz/srw64-recomp/tree/main/config/recomp/mods/super-earthgain). 브래드 편의 「결착의 때」를 클리어하면 카츠가 합류하고, 어스게인과 바이로즈가 합체해 슈퍼 어스게인이 됩니다(브래드가 메인, 카츠가 서브 파일럿). 개조는 어스게인에서 계승됩니다. 합체한 상태로 출격하고, 맵에서 분리하면 두 기체가 합체 공격 「초뢰·천룡마멸진」을 쓸 수 있으며, 서로 붙어 있으면 다시 합체할 수 있습니다. [MOD 다운로드](/ko/mods/#srw64.super-earthgain) 페이지에서 받을 수 있습니다.
