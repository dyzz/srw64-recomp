## 왜 ROM을 직접 준비해야 하나요?

게임 콘텐츠는 실행할 때 사용자의 ROM에서 읽어 옵니다. 이 프로젝트에는 ROM이 들어 있지 않습니다. 프로젝트가 제공하는 것은 리컴파일 도구와 런타임, 번역, 인터페이스입니다. 원작 게임의 코드, 텍스트, 그래픽, 음악의 권리는 각 권리자에게 있습니다.

지원하는 ROM은 『슈퍼로봇대전64』 일본판 Rev 0뿐입니다. 바이트 순서는 상관없습니다(`.z64`, `.v64`, `.n64`). 게임이 알아서 인식하고 변환합니다. `.z64` 형식의 SHA-256은
`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`입니다. 다른 리비전은 지원하지 않습니다.

<span id="rom-location"></span>

## ROM은 어디에 두나요?

- **Windows**: ROM 이름을 `rom.z64`로 바꿔 압축을 푼 `Marchwind64-windows-x64` 폴더에 넣은 뒤, `Marchwind64.cmd`를 더블클릭합니다(`Marchwind64.exe`가 아닙니다). `%LOCALAPPDATA%\SRW64Recomp\rom.z64`에 두어도 됩니다. Windows는 기본적으로 파일 확장명을 숨기므로 파일이 `rom.z64.z64`가 될 수 있습니다. 먼저 파일 탐색기의 보기 메뉴에서 “파일 확장명”을 켜 주세요.
- **Linux와 Steam Deck**: 이름을 `rom.z64`로 바꿔 `marchwind64.sh`와 같은 위치에 두거나, `~/.local/share/srw64-recomp/rom.z64`에 둡니다.
- **macOS와 Android**: 이름을 바꿀 필요가 없습니다. 처음 실행할 때 열리는 창에서 ROM을 선택합니다.
- **Nintendo Switch**: 이름을 `rom.z64`로 바꿔 SD 카드의 `/switch/Marchwind64/`에 넣습니다. 처음 실행할 때 본체에서 30초 정도 걸려 가져옵니다.

ROM이 압축 파일 안에 있다면 먼저 압축을 풀어 주세요. `.n64`나 `.v64` 덤프는 `rom.n64`나 `rom.v64`라는 이름이어도 됩니다. 자세한 순서는 [설치](/ko/install/)를 참고하세요.

## 에뮬레이터인가요?

정적 리컴파일로 만든 네이티브 포트입니다. N64의 MIPS 프로그램을 C로 옮긴 다음 Windows, macOS, Linux, Android, Switch용 네이티브 애플리케이션으로 컴파일하며, 그래픽은 [RT64](https://github.com/rt64/rt64)가 렌더링합니다(Switch에서는 자체 OpenGL 렌더러를 씁니다). BIOS, 플러그인, 에뮬레이터 설정은 필요 없습니다. 이 방식 덕분에 인터페이스를 바꾸고 기능을 추가할 수도 있습니다.

## 어떤 플랫폼과 컨트롤러를 지원하나요?

| 플랫폼 | 요구 사항 |
| --- | --- |
| Windows(실험적) | 64비트 Windows |
| macOS | Apple silicon, macOS 14 이상 |
| Linux | x86-64, glibc 2.35 이상, Vulkan 드라이버 |
| Steam Deck(실험적) | Linux 패키지를 사용하며, Deck은 자동으로 인식됩니다 |
| Android(실험적) | arm64, Android 9 이상, Vulkan 1.1. 테스트한 휴대폰: [Android 호환성](/ko/android/) |
| Nintendo Switch(실험적) | Atmosphère 커스텀 펌웨어와 hbmenu, 애플리케이션 모드. NRO만 있고 NSP는 없습니다 |

각 플랫폼에 필요한 CPU, 그래픽 카드, 드라이버는 설치 페이지의 [시스템 요구 사항](/ko/install/#requirements)에 정리되어 있습니다.

키보드와 일반적인 컨트롤러를 지원하며, 화면의 버튼 표시는 마지막으로 사용한 장치에 맞춰 바뀝니다. Android에서는 컨트롤러가 연결되지 않았을 때 터치 조작을 쓸 수 있습니다. 화면을 터치하면 현재 화면에 필요한 버튼이 “확인”, “빨리 넘기기”, “다음 아군”처럼 기능 이름과 함께 나타납니다. 키보드와 컨트롤러 입력은 설정의 조작 페이지에서 바꿀 수 있습니다.

<span id="saves"></span>

## 세이브는 어디에 있나요? 에뮬레이터와 호환되나요?

세이브는 사용자 폴더의 `saves` 폴더에 있습니다.

- **Windows**: `%LOCALAPPDATA%\SRW64Recomp\saves`. 파일 탐색기의 주소 표시줄에 입력하고 Enter를 누르세요. 포터블 모드(`Marchwind64.exe` 옆에 `user-data` 폴더가 있는 경우)에서는 게임 폴더의 `user-data\saves`입니다.
- **macOS**: `~/Library/Application Support/SRW64Recomp/saves`. Finder에서 ⇧⌘G를 누르고 붙여 넣으세요.
- **Linux와 Steam Deck**: `~/.local/share/srw64-recomp/saves`.
- **Android**: 시스템의 “파일” 앱에서 “Marchwind64”를 연 다음 `saves`로 들어갑니다.
- **Nintendo Switch**: SD 카드의 `/switch/Marchwind64/saves`. 카드 리더나 ftpd로 복사해 옵니다.

`cartridge.sram`은 카트리지 세이브(슬롯 1, 2)이고, `slots/`에는 슬롯 3 이후가, `auto/`에는 자동 저장이 들어 있습니다. 백업하려면 `saves` 폴더를 통째로 복사하고, 복원하려면 게임을 종료한 뒤 다시 넣으면 됩니다. 같은 방법으로 세이브를 다른 컴퓨터나 플랫폼으로 옮길 수 있습니다.

카트리지 세이브 `saves/cartridge.sram`은 ares의 `.ram` 파일과 바이트 단위로 호환되므로 둘 사이에서 세이브를 그대로 복사할 수 있습니다. 다른 에뮬레이터라면 설정의 저장 페이지를 사용하세요. “세이브 내보내기”는 슬롯 1, 2를 ares, Project64, mupen64plus, RetroArch에서 쓰는 형식으로 변환합니다. “세이브 가져오기”는 `import` 폴더에 넣은 세이브를 읽어 새 슬롯으로 추가하며, 기존 세이브는 그대로 둡니다.

## 아무 때나 상태 저장을 할 수 있나요?

아니요. 이 게임은 에뮬레이터에서 돌아가는 것이 아니므로, 아무 때나 저장하고 불러오는 에뮬레이터식 상태 저장이 없습니다. 원작과 같은 방식으로 저장하며, 여기에 자동 저장을 추가했습니다.

- 기본으로 켜져 있으며, 각 맵을 마친 뒤, 출격 직전, 아군 턴이 시작할 때마다 저장합니다.
- 기본적으로 인터미션 자동 저장 3개와 턴 자동 저장 5개를 보관하고, 그보다 많아지면 가장 오래된 것부터 지웁니다. 보관 개수를 바꾸거나 자동 저장을 끄려면 설정의 저장 페이지를 사용하세요.
- 자동 저장은 타이틀 화면의 불러오기에서 불러옵니다. 턴 자동 저장을 불러오면 그 턴을 처음부터 다시 시작합니다.

## HD 팩이란 무엇인가요?

HD 팩은 게임 그래픽을 교체하는 별도의 선택 다운로드입니다. 없으면 원작 그래픽을 사용합니다. 설치하면 게임 중 언제든지 원작 그래픽과 HD 그래픽을 전환할 수 있습니다. Android에서는 앱 안에서 가져옵니다. 앱 아이콘을 길게 눌러 “HD 팩 가져오기”를 선택하거나, 다운로드한 zip을 SRW64로 여세요. Switch는 전용 Switch HD 팩을 SD 카드 최상위에 압축을 풀어 사용하며, 컴퓨터용 팩은 Switch에서 동작하지 않습니다.

이미지는 주로 두 가지 방법으로 만들었으며, 출처는 팩과 릴리스 노트에 적혀 있습니다.

- **AI 생성**: 초상화, 인터미션 배경, 우주 오브젝트, 타이틀 이미지는 원작 그래픽을 참고 이미지로 삼아 Alibaba Cloud의 Qwen 이미지 모델로 생성했습니다. 스토리 세계 지도와 전술맵 바탕 이미지도 원작 그래픽을 참고로 OpenAI의 이미지 모델이 그렸습니다.
- **원작 업스케일**: 기체 그림과 맵 기체 아이콘은 로컬 업스케일 모델로 원작 픽셀 아트를 다시 그렸습니다. 전술맵의 팔레트 인덱스 맵은 원작 맵 픽셀을 업스케일한 것입니다.

테두리는 코드로 그립니다. BANPRESTO 로고, GAME OVER, 창 테두리는 실행할 때 사용자의 ROM에서 생성하며 팩에는 들어 있지 않습니다.

## 언어는 어떻게 바꾸나요?

설정의 언어에서 중국어, 영어, 일본어, 한국어 중 하나를 선택합니다(한국어는 커뮤니티 번역자 테오(jung5441)가 번역했습니다). 게임 중에 쓸 수 있는 단축키도 있으며, 버튼은 플랫폼마다 다르고 설정의 조작 페이지에 나와 있습니다. 대사, 메뉴, 데이터 텍스트가 함께 바뀌고, 선택한 언어는 다음 실행에도 유지됩니다.

## 원작과 무엇이 다른가요?

스토리는 그대로이며, 능력치, 적의 행동, 전투 계산은 원작을 따릅니다. 설정의 게임 규칙 페이지에는 끌 수 있는 보정 항목이 있습니다. 켜면 해당 계산과 규칙이 조정됩니다.

추가 기능은 대부분 인터페이스, 읽기, 조작에 관한 것입니다. 네이티브로 렌더링하는 설정과 인터미션 화면, 대사 기록과 자동 읽기, 빨리 넘기기와 건너뛰기, 와이드 화면, 추가 세이브 슬롯, 자동 저장, 키 설정 변경 등이 있습니다.

## 게임이 한 화면에서 멈추거나 창이 “응답 없음”이 됩니다

대부분 그래픽 드라이버가 너무 오래된 경우입니다. 최소한 다음 버전 이상으로 업데이트하세요.

- **NVIDIA**: 475.14보다 새로운 버전.
- **AMD**: 2019년 이후에 나온 드라이버.
- **Intel**: 최신 드라이버.
- **Linux**: 배포판의 최신 Mesa 또는 NVIDIA 드라이버. **Steam Deck**에서는 SteamOS를 최신으로 유지하세요.

드라이버는 GPU 제조사 웹사이트에서 받으세요. Windows 업데이트가 설치하는 드라이버는 오래된 경우가 많습니다. GPU가 두 개인 노트북은 둘 다 업데이트해야 합니다. 그래도 멈춘다면 게임을 다시 실행해 옵션 → 피드백에서 문제 보고서를 내보낸 뒤 [GitHub 이슈](https://github.com/dyzz/srw64-recomp/issues)에 첨부해 주세요.

## 문제는 어떻게 신고하나요?

[GitHub](https://github.com/dyzz/srw64-recomp/issues)에서 양식을 사용해 이슈를 열고, 재현할 수 있도록 버전, 플랫폼, 문제가 생기기까지의 과정을 적어 주세요. 게임의 옵션 → 피드백에서 플랫폼 정보를 복사하고 문제 보고서(버전, 시스템, 그래픽, 설정, 최근 몇 번 실행한 로그. 세이브와 ROM은 들어가지 않습니다)를 내보낼 수 있습니다. 보고서를 첨부하고, 스크린숏이 있다면 함께 올려 주세요. 스토리 대사와 도감 이름은 사이트의 [스토리](/ko/story/)와 [도감](/ko/library/) 페이지에서 해당 대사 옆에 수정 의견을 남겨 주세요.
