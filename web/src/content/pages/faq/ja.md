## なぜ ROM を自分で用意する必要があるのですか？

ゲームのプログラム・テキスト・画像・音楽は原作の権利者のもので、私たちが配布することはできません。このプロジェクトが公開するのは自作の部分だけです。N64 のプログラムをネイティブコードに変換するツールとランタイム、翻訳テキスト、インターフェースです。ゲーム本体は起動時にお手持ちの ROM から読み込みます。

対応する ROM は 1 種類だけです。『スーパーロボット大戦64』日本版 Rev 0、`.z64` バイトオーダー、SHA-256 は
`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`。ほかのリビジョンには対応していません。`.n64`・`.v64` 形式は一般的な N64 ROM ツールで `.z64` に変換してください。

## エミュレーターですか？

いいえ。N64 の MIPS プログラムを静的リコンパイルで C に変換し、Windows・macOS・Linux・Android のネイティブプログラムとしてビルドしています。描画は [RT64](https://github.com/rt64/rt64) です。BIOS やプラグイン、エミュレーターの設定は不要で、原作を超えてインターフェースや機能を変えることもできます。

## 対応プラットフォームとコントローラーは？

| プラットフォーム | 動作環境 |
| --- | --- |
| Windows（試験的） | 64 ビット版 Windows |
| macOS | Apple シリコン、macOS 14 以降 |
| Linux | x86-64、glibc 2.35 以降、Vulkan ドライバー |
| Steam Deck（試験的） | Linux 版と同じパッケージ。Deck を自動認識 |
| Android（試験的） | arm64、Android 9 以降、Vulkan 1.1 |

キーボードと一般的なコントローラーが使え、画面のボタン表示は最後に使った機器に合わせて変わります。Android でコントローラーがないときはタッチ操作です。画面に触れるとボタンが現れ、いまの画面で使うものだけが「決定」「早送り」「次の味方」のような機能名つきで並びます。設定ウィンドウの「操作」ページでキー割り当てを変更できます。

## セーブデータはどこにありますか？エミュレーターと共有できますか？

セーブデータはユーザーディレクトリの `saves` フォルダーにあります。

- macOS：`~/Library/Application Support/SRW64Recomp/`
- Linux／Steam Deck：`~/.local/share/srw64-recomp/`
- Windows：`%LOCALAPPDATA%\SRW64Recomp\`

カートリッジのセーブ `saves/cartridge.sram` は ares の `.ram` と同じバイト列なので、そのままコピーし合えます。ほかのエミュレーターとは設定ウィンドウの「セーブ」ページを使います。「エミュレーター用に書き出す」でセーブ 1・2 を ares・Project64・mupen64plus・RetroArch 用に書き出し、「エミュレーターから取り込む」で `import` フォルダーに置いたセーブを新しい番号で取り込みます。既存のセーブは上書きされません。

## HD パックとは？

別配布の任意の画像パックです。ゲームの内容は変えず、絵だけを差し替えます。入れなければオリジナルの画面、入れれば <kbd>F6</kbd> でいつでも切り替えられます。

画像の出どころは 2 種類で、どちらもパック内の説明とリリースノートに明記しています。

- **AI 生成**：顔グラフィック・インターミッション背景・宇宙のオブジェクト・タイトル画像は、Alibaba Cloud の Qwen 画像モデルがオリジナル画面を参考に生成。シナリオのワールドマップと戦術マップの下絵は、OpenAI の画像モデルがオリジナル画面を参考に描いたものです。
- **オリジナルからの拡大**：ユニット絵とマップ上のユニットアイコンは、ローカルの拡大モデルでオリジナルのドット絵から描き直し。戦術マップのカラー番号マップはオリジナルのマップの画素を拡大したものです。

枠はコードで描画しています。BANPRESTO ロゴ・GAME OVER・ウィンドウ枠は実行時にお手持ちの ROM から生成するため、パックには含まれません。

## 言語の切り替え方は？

<kbd>F7</kbd>（Steam Deck は左スティック押し込み）で中国語・英語・日本語を順に切り替えるか、設定ウィンドウの「言語」で選びます。会話・メニュー・データがまとめて切り替わり、次回の起動にも引き継がれます。

## 原作との違いは？

シナリオ・数値・敵の行動・戦闘結果は原作どおりに動きます。違いはインターフェース・会話・便利機能です。ネイティブ描画の設定画面とインターミッション画面、会話の履歴とオート、早送りとスキップ、ワイド画面、追加のセーブ枠と自動セーブ、キー割り当てなど。わずかなルール修正は設定ウィンドウの「ルール」ページにあり、オフにできます。

戦闘中の Z+START は原作のソフトリセットで、タイトル画面に戻り、セーブしていない進行は失われます。

## 不具合の報告は？

[GitHub の Issues](https://github.com/dyzz/srw64-recomp/issues) に、バージョン・プラットフォーム・問題が起きる前の操作を書いて報告してください。スクリーンショットがあると助かります。ゲーム内からの報告機能は開発中です。
