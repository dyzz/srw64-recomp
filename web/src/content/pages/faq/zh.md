## 为什么需要自备 ROM？

游戏内容在启动时从你自己的 ROM 读取，本项目不提供 ROM。项目提供重编译工具与运行时、翻译文本和界面；原作的程序、文字、图像和音乐归各自的版权方所有。

目前只支持《超级机器人大战64》日版 Rev 0。`.z64`、`.v64`、`.n64` 三种字节序都可以，游戏会自动识别并转换；按 `.z64` 计算的 SHA-256 为
`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`。其他版本不受支持。

## 这是模拟器吗？

本项目是通过静态重编译制作的原生移植：先将 N64 的 MIPS 程序翻译成 C，再编译成 Windows、macOS、Linux、Android 的本机程序，图形由 [RT64](https://github.com/rt64/rt64) 渲染。运行时无需配置 BIOS、插件或模拟器，也可以在原版的基础上调整界面、增加功能。

## 支持哪些平台和手柄？

| 平台 | 要求 |
| --- | --- |
| Windows（实验性） | 64 位 Windows |
| macOS | Apple 芯片，macOS 14 起 |
| Linux | x86-64，glibc 2.35 起，需要 Vulkan 驱动 |
| Steam Deck（实验性） | 与 Linux 同一个包，自动识别 Deck |
| Android（实验性） | arm64，Android 9 起，需要 Vulkan 1.1 |

支持键盘和常见手柄，画面上的按键提示会随最后使用的设备切换。Android 未连接手柄时可以触屏操作：触碰屏幕后会出现当前画面需要的按键，并标出「确定」「快进」「下个单位」等功能名。键盘和手柄的按键分配可以在设置窗口的「操作」页修改。

## 存档在哪里？能和模拟器互通吗？

存档位于以下用户目录中的 `saves` 文件夹：

- macOS：`~/Library/Application Support/SRW64Recomp/`
- Linux／Steam Deck：`~/.local/share/srw64-recomp/`
- Windows：`%LOCALAPPDATA%\SRW64Recomp\`

卡带存档 `saves/cartridge.sram` 与 ares 的 `.ram` 格式相同，可以直接互拷。其他模拟器的存档可以通过设置窗口的「存档」页导入或导出：「导出给模拟器」将存档栏 1、2 转为 ares、Project64、mupen64plus、RetroArch 的格式；「从模拟器导入」读取放在 `import` 文件夹中的存档，存入新的存档栏，保留原有存档。

## HD 包是什么？

HD 包是单独下载、可选安装的图片包，只替换游戏画面。未安装时使用原版画面；安装后，可以在游戏中随时切换原版与 HD。Android 上在应用里导入：长按应用图标选「导入 HD 包」，或用 SRW64 打开下载的 zip。

包内图片主要通过以下两种方式制作，来源列在包内说明和发布说明中：

- **AI 生成**：头像、场间背景、宇宙物件和标题图由阿里云百炼的通义千问图像模型以原版画面为参考生成；剧情世界地图和战术地图的底图由 OpenAI 的图像模型以原版画面为参考绘制。
- **由原版放大**：机体立绘和地图上的机体图标用本地放大模型从原版像素图放大重绘；战术地图的色号图由原版地图像素放大而来。

边框由代码绘制；BANPRESTO 标志、GAME OVER 和窗口边框在游戏运行时从你的 ROM 生成，不包含在包内。

## 怎么切换语言？

在设置窗口的「语言」中选择中文、英文或日文，游戏中也有切换语言的快捷键（各平台按键不同，见设置的「操作」页）。对白、菜单和数据文本会一起切换，所选语言会保留到下次启动。

## 和原版有哪些不同？

游戏保留原版剧情，数值、敌人行动和战斗结算以原版为基础。设置窗口的「规则」页提供可关闭的修正选项；启用后，对应的计算和规则会有所调整。

新增功能主要围绕界面、阅读和操作：原生绘制的设置与场间画面、对白回看与自动阅读、快进与跳过、宽屏、多存档栏与自动存档，以及改键等。

原版自带软复位：战斗中同时按 N64 手柄的 Z 和 START（对应到你的键盘或手柄上的按键见设置的「操作」页）会回到标题画面，未存档的进度会丢失。

## 遇到问题怎么反馈？

请到 [GitHub Issues](https://github.com/dyzz/srw64-recomp/issues) 提交，注明版本、平台和问题发生前的操作，方便复现；有截图也可以一并附上。游戏内的一键反馈功能仍在开发中。
