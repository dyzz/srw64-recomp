## 开始之前

### 这是模拟器吗？

本项目是通过静态重编译制作的原生移植：先将 N64 的 MIPS 程序翻译成 C，再编译成 Windows、macOS、Linux、Android、Switch 的本机程序，图形由 [RT64](https://github.com/rt64/rt64) 渲染（Switch 上用自己的 OpenGL 渲染器）。运行时无需配置 BIOS、插件或模拟器，也可以在原版的基础上调整界面、增加功能。

<span id="rom"></span>

### 为什么需要自备 ROM？

游戏内容在启动时从你自己的 ROM 读取，本项目不提供 ROM。项目提供重编译工具与运行时、翻译文本和界面；原作的程序、文字、图像和音乐归各自的版权方所有。

目前只支持《超级机器人大战64》日版 Rev 0。`.z64`、`.v64`、`.n64` 三种字节序都可以，游戏会自动识别并转换；按 `.z64` 计算的 SHA-256 为
`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`。其他版本不受支持。

### 支持哪些平台和手柄？

| 平台 | 要求 |
| --- | --- |
| Windows（实验性） | 64 位 Windows |
| macOS | Apple 芯片，macOS 14 起 |
| Linux | x86-64，glibc 2.35 起，需要 Vulkan 驱动 |
| Steam Deck（实验性） | 与 Linux 同一个包，自动识别 Deck |
| Android（实验性） | arm64，Android 9 起，需要 Vulkan 1.1；实测机型见[安卓兼容列表](/zh/android/) |
| Nintendo Switch（实验性） | Atmosphère 自制系统与 hbmenu，应用模式；只提供 NRO，不提供 NSP |

各平台对 CPU、显卡和驱动的具体要求见安装页的[系统要求](/zh/install/#requirements)。

支持键盘和常见手柄，画面上的按键提示会随最后使用的设备切换。Android 未连接手柄时可以触屏操作：触碰屏幕后会出现当前画面需要的按键，并标出「确定」「快进」「下个单位」等功能名。键盘和手柄的按键分配可以在设置窗口的「操作」页修改。

### 和原版有哪些不同？

游戏保留原版剧情，数值、敌人行动和战斗结算以原版为基础。设置窗口的「规则」页提供可关闭的修正选项；启用后，对应的计算和规则会有所调整。

新增功能主要围绕界面、阅读和操作：原生绘制的设置与场间画面、对白回看与自动阅读、快进与跳过、宽屏、多存档栏与自动存档，以及改键等。

## 安装

<span id="rom-location"></span>

### ROM 放在哪里？

- **Windows**：把 ROM 改名为 `rom.z64`，放进解压出的 `Marchwind64-windows-x64` 文件夹，然后双击 `Marchwind64.exe` 启动。也可以放在 `%LOCALAPPDATA%\SRW64Recomp\rom.z64`。Windows 默认隐藏扩展名，改名时容易变成 `rom.z64.z64`，先在资源管理器的「查看」里勾选「文件扩展名」。
- **Linux／Steam Deck**：改名为 `rom.z64`，放在 `marchwind64.sh` 旁边，或 `~/.local/share/srw64-recomp/rom.z64`。
- **macOS、Android**：不用改名，首次启动时在弹出的窗口里选择 ROM。
- **Nintendo Switch**：改名为 `rom.z64`，放进 SD 卡上的 `/switch/Marchwind64/`。首次启动会在主机上导入，约半分钟。

ROM 是压缩包的话先解压。`.n64`、`.v64` 格式改名为 `rom.n64`、`rom.v64` 即可。详见[安装](/zh/install/)。

### Windows 弹出安全提示怎么办？

选择「更多信息」→「仍要运行」。

### Windows 怎么用便携模式？

在 `Marchwind64.exe` 旁边新建一个空文件夹 `user-data`，存档和设置就放在里面（第一次会从 `%LOCALAPPDATA%\SRW64Recomp` 补入已有的设置和存档，正常退出后同步回去）。整个游戏文件夹连同 ROM 可以放在 U 盘或移动硬盘上，换盘符、换电脑都能接着玩。

### Switch 为什么要按住 R 启动？

从相簿打开的 hbmenu 内存不够，游戏会提示改用按住 R 的方式。

### Switch 怎么更新？

删掉旧的 `fonts`、`dialogue`、`stages`、`splash` 四个文件夹，再解压新版；存档、设置和 `game` 文件夹保留，新版第一次启动会自动重新导入一次。HD 包出新版时整体替换 `hd` 文件夹。

Switch 版没有游戏内的更新提示，新版本请留意[安装页](/zh/install/)或 GitHub。

### Switch 版有点卡正常吗？

Switch 版目前性能还有待优化，运行时会有一定卡顿。

## 存档

<span id="saves"></span>

### 存档在哪里？能和模拟器互通吗？

存档都在用户目录的 `saves` 文件夹里：

- **Windows**：`%LOCALAPPDATA%\SRW64Recomp\saves`，在资源管理器地址栏输入这个路径回车即可打开。便携模式（`Marchwind64.exe` 旁边有 `user-data` 文件夹）下是游戏文件夹里的 `user-data\saves`。
- **macOS**：`~/Library/Application Support/SRW64Recomp/saves`，在访达里按 ⇧⌘G 输入路径。
- **Linux／Steam Deck**：`~/.local/share/srw64-recomp/saves`。
- **Android**：在系统「文件」应用里找到「Marchwind64」，打开里面的 `saves`。
- **Nintendo Switch**：SD 卡上的 `/switch/Marchwind64/saves`，可以用读卡器或 ftpd 拷出来。

里面的 `cartridge.sram` 是卡带存档（存档栏 1、2），`slots/` 是存档栏 3 起，`auto/` 是自动存档。备份时复制整个 `saves` 文件夹；恢复时先退出游戏，再放回原处。换电脑或换平台时也是这样搬存档。

卡带存档 `saves/cartridge.sram` 与 ares 的 `.ram` 格式相同，可以直接互拷。其他模拟器的存档可以通过设置窗口的「存档」页导入或导出：「导出给模拟器」将存档栏 1、2 转为 ares、Project64、mupen64plus、RetroArch 的格式；「从模拟器导入」读取放在 `import` 文件夹中的存档，存入新的存档栏，保留原有存档。

### 能随时即时存档吗？

不能。游戏不是在模拟器里运行的，没有模拟器那种任意时刻保存、读取的即时存档。存档仍按原版的方式进行，另外加了自动存档：

- 默认开启，在过关进入场间、出击前和每回合开始时自动保存。
- 默认保留 3 份场间存档、5 份回合存档，超出的旧存档会删除。份数可以在设置窗口的「存档」页修改，也可以在那里关闭自动存档。
- 在标题画面的读取画面里读取自动存档。读取回合存档会从那一回合开始重来。

## HD 包

### HD 包是什么？

HD 包是单独下载、可选安装的图片包，只替换游戏画面。未安装时使用原版画面；安装后，可以在游戏中随时切换原版与 HD。

包内图片主要通过以下两种方式制作，来源列在包内说明和发布说明中：

- **AI 生成**：头像、场间背景、宇宙物件和标题图由阿里云百炼的通义千问图像模型以原版画面为参考生成；剧情世界地图和战术地图的底图由 OpenAI 的图像模型以原版画面为参考绘制。
- **由原版放大**：机体立绘和地图上的机体图标用本地放大模型从原版像素图放大重绘；战术地图的色号图由原版地图像素放大而来。

边框由代码绘制；BANPRESTO 标志、GAME OVER 和窗口边框在游戏运行时从你的 ROM 生成，不包含在包内。

### Android 和 Switch 怎么装 HD 包？

Android 上在应用里导入：长按应用图标选「导入 HD 包」，或用 Marchwind64 打开下载的 zip。Switch 用单独的 Switch 版 HD 包，解压到 SD 卡根目录即可，电脑版的包在 Switch 上不能用。

### HD 包可以放在游戏旁边吗？

可以，放在 `Marchwind64.app`、`marchwind64.sh` 或 `Marchwind64.exe` 旁边都行。游戏文件夹和用户数据目录都有 HD 包时，用用户数据目录里的。

macOS 上，放在应用旁边之前，应用要先在访达里移动过一次（例如拖进「应用程序」）。

### 怎么切换原版和 HD？

随时切换：设置窗口「通用」页的「画面」，或按快捷键（默认键盘 4 或 F6、手柄按下右摇杆）；Windows 和 macOS 的菜单栏里也有「HD 画面」。切换立即生效，不影响存档。这个选择不会保存，每次启动都从 HD 开始。

HD 画面下，地图上的单位图标可以单独换回原版：设置「通用」页的「地图单位图标」，这一项会记住。

### HD 包怎么更新？

HD 包有自己的版本号，内容变了才发新版，不必每次更新应用都重新下载。有新版时游戏的更新检查会提示，更新时整体替换旧的 `hd` 文件夹。

## 语言与操作

### 怎么切换语言？

在设置窗口的「语言」中选择中文、英文、日文或韩文（韩文由社区译者 [테오（jung5441）](https://github.com/jung5441) 翻译），游戏中也有切换语言的快捷键（各平台按键不同，见设置的「操作」页）。对白、菜单和数据文本会一起切换，所选语言会保留到下次启动。

### Steam Deck 怎么改键和退出？

游戏会识别 Deck 并使用适合 Deck 的默认键位，设置里可以改键。

从 Steam 菜单选择「退出游戏」可保存并退出。

## 遇到问题

<span id="gpu"></span>

### 游戏卡在某个画面不动，或窗口「未响应」？

多半是显卡驱动太旧，请先更新到下面的版本或更新：

- **NVIDIA**：高于 475.14。
- **AMD**：2019 年以后发布的驱动。
- **Intel**：最新驱动。
- **Linux**：发行版提供的最新 Mesa 或 NVIDIA 驱动。**Steam Deck** 保持 SteamOS 为最新即可。

驱动最好从显卡厂商官网下载，Windows 更新自带的往往偏旧；笔记本如果有两块显卡，两块都要更新。更新后仍然卡住，请重新打开游戏，在「选项 → 反馈」里导出问题报告，附在 [GitHub Issue](https://github.com/dyzz/srw64-recomp/issues) 里。

### 遇到问题怎么反馈？

请到 [GitHub Issues](https://github.com/dyzz/srw64-recomp/issues) 按表单提交，注明版本、平台和问题发生前的操作，方便复现。游戏里「选项 → 反馈」可以一键复制平台信息、导出问题报告（版本、系统、显卡、设置和最近几次运行的日志，不含存档和 ROM），请一并附上；有截图更好。剧情台词和图鉴译名的意见，请在官网[剧情](/zh/story/)和[图鉴](/zh/library/)页面对应的句子旁直接提交。
