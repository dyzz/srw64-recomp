SRW64 Recompiled — HD 图片包 / HD image pack

安装：把这个 hd 文件夹放进用户目录，
  macOS：~/Library/Application Support/SRW64Recomp/hd
打开游戏即为 HD。F6 或设置窗口的“图片”可以随时切回原版。
这个包只能配同一版本的应用使用；换版本时整个替换。

来源说明
- 头像、场间背景、剧情世界地图、宇宙物件和标题 Logo 与火焰，
  由阿里云百炼的通义千问图像模型（qwen-image-3.0 / qwen-image-3.0-pro）
  以原版画面为参考生成，属于 AI 生成内容。
- BANPRESTO 标志与 GAME OVER 由原图按算法放大；对话框和战斗界面边框由代码绘制；
  世界地图的舰船、地标与 5600 标记是自制模型。
- 包内不含 ROM 数据。

Install: put this hd folder in the user directory
  (macOS: ~/Library/Application Support/SRW64Recomp/hd). The game then starts in HD;
F6 or Images in the settings window switches back to the original. Use the pack with
the app of the same version, and replace it as a whole when you update.

The portraits, intermission backgrounds, story world map, space objects and the title
logo and flames are AI-generated with Alibaba Cloud Model Studio (Qwen image models
qwen-image-3.0 / qwen-image-3.0-pro), using the original graphics as reference. The
BANPRESTO logo and GAME OVER are algorithmic upscales of the originals; the dialogue
and battle frames are drawn by code; the world-map ships, landmarks and the 5600 marker
are models made for this project. The pack contains no ROM data.
