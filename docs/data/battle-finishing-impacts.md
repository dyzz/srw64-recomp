# 战斗动画的收招与受击语音

受击台词沿用游戏选出的驾驶员和台词。游戏请求播放时，宿主检查本回合实际运行的动画。如果收招还没发生，就让动画继续，在收招事件发生的游戏步打开原台词框并播放配音。反击使用当回合的守方。无伤回避走原来的回避台词流程。

## ROM 清点

武器动画表有 1,329 个槽，按完整解析内容去重后有 963 种脚本。它们引用了 59 种普通命中时的守方动作。命中特效表有 159 个槽，反应表有 28 个槽。检查同时覆盖攻方主动作、攻方子对象、守方动作、命中特效、伤害模式及 89 项按武器和机体选取替代动画的映射。同名武器、机体变体和无显示名的动画都计入槽数。

## 复查

在仓库根目录运行以下命令可得到逐槽清单。每行列出机体、替代映射、攻守动作、子对象行为及例程地址、关联命中特效、伤害模式和命中的规则。

```sh
.venv/bin/python tools/recomp/analysis/battle_finishing_impacts.py > weapons.csv
.venv/bin/python tools/recomp/analysis/battle_finishing_impacts.py --bank hit > hits.csv
.venv/bin/python tools/recomp/analysis/battle_finishing_impacts.py --bank reaction > reactions.csv
```

实跑使用重编译版的战斗查看器，回放游戏本身的战斗循环。每类抽取代表招式，同时记录首次命中、动作切换、守方台词出现的游戏步和成片音轨。将实际台词音频与录影音轨做互相关定位，可区分游戏触发时刻与录制、混音造成的偏差。击坠样本同时检查预留伤害被消费的时刻与稍后发出的击坠台词。完整 ROM 扫描和逐类实跑各有独立记录。
