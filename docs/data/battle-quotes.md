# 战斗台词的选择表：哪句话在什么时候说

日期：2026-09-27。战斗 overlay（ROM `0x121560`，代码 `0x801C2600` 起）为每个交战方准备两条台词槽（记录 `+0x2C` 攻击时说，`+0x848` 挨打／回避时说），由 `func_80222050` 填入。填法分两层，先查**条件台词表**，再按情境从**通用台词段**里抽。解码实现在 `src/srw64_native/battle_quotes.py`，导出（`tools/content/export_text.py`）把结果写进 `assets/text-export/records.jsonl` 每条战斗台词的 `context.triggers`，并按声部汇总到 `assets/text-export/battle/triggers.json`；出货文件 `content/dialogue/<locale>/battle/` 每条上方的 `# 触发：` 注释也来自这里。

## 声部

驾驶员不是按人物号而是按**声部号**查表：`D_800CA9C4[人物号] = 声部号`（-1 表示没有台词）。绝大多数人物独占一个声部；剧情里的复制人物（ドモン 273/274、シャッフル同盟四人的副本）与本尊共用声部，ウォン 与 コンピュータ 共用 9 号。257 个声部，160 个带条件台词。

## 通用台词段（记录 5813–14226）

表 `ROM 0x1161C0`，每声部 36 字节：九对（起始偏移，条数），记录号 = 5813 + 偏移。九个情境按调用方传入的编号：

| 编号 | 情境 | 判定（`func_80222050`） |
| --- | --- | --- |
| 0 | 攻击 | 本方出手 |
| 1 | 被击坠 | 命中后剩余 HP 为 0 |
| 2 | 重伤 | 剩余 HP 不足 30% |
| 3 | 中伤 | 剩余 HP 30–90% |
| 4 | 轻伤 | 剩余 HP 90% 以上 |
| 5 | 回避 | 结果码 21、22；分身等特殊回避（结果码 6–12）另有条件码基数 27500，通用段仍用此情境 |
| 6 | 攻击无效 | 结果码 2–5（护罩、装甲吸收） |
| 7 | 弹药／EN 不足 | 武器号 -2：无法反击 |
| 8 | 射程外 | 武器号 -3：无法反击 |

`func_80222B14` 在段内随机取一条。条数为 0 时若槽还空着就填 5813（コウ 的第一句）作兜底。

## 条件台词表（记录 14227–17346）

索引 `ROM 0x121150`（每声部一个 u32 偏移），数据 `ROM 0x20F250 + 偏移`，每项两个 u16：条件码、文本偏移（记录号 = 14227 + 偏移），`0xFFFF` 结束。条件码 40000／40001 表示"接上一条件"，一组连续的项构成一次触发依次显示的多人对话（每句的说话人由文本头前三位决定）。`func_8022245C` 把命中的项分进三个优先组，只从最高的一组里随机取一项：

| 组 | 来源 |
| --- | --- |
| 0（最高） | 合体技对话（8000 系） |
| 1 | 2600 系武器台词、10000 系情境台词里带对手／副驾驶条件的、条件表里带剧情标志或副驾驶条件的 |
| 2（最低） | 900 系武器台词、乘坐特定机体的情境台词、对手为女性、条件表里按对手机体／驾驶员的 |

取到第 2 组的台词后，通用台词仍会再抽一次，并以三分之二的概率把它顶掉（`func_80222B14`：已有台词时在 1.5 倍条数里掷骰，掷进条数内才替换）。所以 900 系的武器台词（バルカン、ゴッドフィールドダッシュ 之类）只是"有时会说"。

条件码的含义：

| 条件码 | 含义 |
| --- | --- |
| 0–90 | 条件表 `D_80222F20` 的一行 (c, w)：c 见下表，w 是武器（-1 无、900+武器号、2600+武器号）。c 在 700–879 时下一行是剧情标志检查 (标志号, 值)，例如 ドモン 的 シャイニングフィンガーソード 分"标志 45 = 0"和"= 3"两组 |
| 900 + 武器号 | 使用该武器（第 2 组） |
| 2600 + 武器号 | 使用该武器（第 1 组） |
| 5000 | 对手驾驶员为女性（驾驶员记录 +4 的第 1 位） |
| 8000 + n | 合体技。武器记录第 0 字段 1222–1229 对应基数 8000–8700（ダブルバーニングファイヤー、ダブルライトニングバスター、ツインビーム、マジンガートルネード、ファイナルダイナミックスペシャル、トリプルマジンガーパンチ、ダブルマジンガーブレード、ツインオーラアタック），n 由搭档表 `[主驾驶][搭档]` 查出（`func_80221CF8`／`func_80221ACC`），只在战斗模式 3 下生效 |
| 10000 + 2500·s + k | 情境 s（基数 10000 被击坠、12500 重伤、15000 中伤、17500 轻伤、20000 攻击、22500 攻击无效、25000 回避、27500 分身回避、30000 弹尽、32500 射程外）加条件 k：k < 400 乘坐机体 k；400–999 同下表的 c |

c 的含义（`func_80221F5C`）：

| c | 含义 |
| --- | --- |
| 0–399 | 对手机体号 |
| 400–699 | 对手声部号 + 400 |
| 700–879 | 剧情标志（c − 700）的值（`func_800A496C`，每标志 2 位） |
| 880–889 | 副驾驶（`func_801C4A08`）：880 チャム、881 シルキー、882 ローレンス、883 アイシャ、884 甲児、885 ひかる、886 マリア、887 鉄也、888 ジュン、889 ナイーダ |

武器按武器记录（`ROM 0x119970`，每条 14 字节）第 0 字段比较，所以不同机体上的同名武器（各种 バルカン砲、ロケットパンチ）视为同一件；`triggers.json` 的 `desc` 会列出同组的全部名字。

## 原版读不到的台词

- 条件表每声部只读 `0x1E0` 字节（120 项）。デューク（声部 90，448 项）、ボス（164，274 项）、甲児（165，298 项）的表超过上限，后面的 150 句（记录 15420–15523、15925–15953、16242–16258）原版永远不会显示；导出里标 `unreachable`，注释写"超出原版读取上限"。
- 39 句没有任何表引用：7343、8105、10481–10483、10702–10731、14527–14530。出货文件放在 `battle/other.txt`。
- 5799–5812（`battle.special`）不在这两张表里：主程序 `800A2890` 在旗舰被击坠时按 `D_800C9A08` 的舰长顺序（ブライト、シーラ、エレ、葉月博士、エマリー、ヘンケン、ハワード）各二选一。
