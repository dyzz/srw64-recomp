# 音乐替换与战斗语音 MOD

2026-10-20。规划两类音频 MOD：**替换战斗与其他 BGM**、**给人物加战斗语音**。属于 [MOD 包](mod-packages.md) 的 `audio/` 一类（§4 已定：音乐按曲目号、战斗语音按战斗台词号）。音乐按歌号替换已在 `mods` 分支实现（§8），其余仍是设计。原版事实来自静态分析（[战斗鉴赏 §6.7](battle-viewer.md)、[战斗台词选择表](../data/battle-quotes.md)），未实机的地方单独标出。

## 1. 目标与范围

- **BGM 替换**：一个 OGG 顶替原版一个歌号，所有放这首歌的地方（战斗曲、关卡曲、剧情曲、标题、音乐鉴赏、卡拉OK）都跟着换。新曲也这样做：顶替音乐鉴赏里的某一首，可以带自己的曲名。
- **改战斗曲**：可以按人物或机体指定战斗时放哪个歌号。
- **战斗语音**：战斗演出里每显示一句战斗台词，就放对应的语音。
- 不改原版逻辑和节奏：
  - 原版的选曲、换曲时机、播放状态都照常运行，只是换掉听到的声音。
  - 战斗台词照原版的时钟翻页，不为等语音而延长。
- **我们不分发任何音频**：程序只提供机制；歌曲和配音由 MOD 作者自己准备，版权由作者负责。官方包和内置 HD 包不带音频。
- 不在本文范围：剧情语音（按台词记录号，键已在 MOD 包 §4 预留）、音效替换、精神指令和 cut-in 的独立语音（§6）。

## 2. 原版事实

### 2.1 放歌

- `8007E810(歌号)`：
  - 歌号等于当前曲 `D_800FFA6C` 时什么也不做，同一首不会重开。
  - 负数 → `80077B38` 停止。
  - 否则 → `80077868` 开始播放，并记入 `D_800FFA6C`。
- `8007E87C(n)` 淡出，内部调 `80077BD8`。`80077AD0()` 查询是否还在播放（敌增援 jingle 放完后，`801E076C` 靠它换回关卡曲）。
- 开始 `80077868` 和停止 `80077B38` 都**只从 `8007E810` 调用**，所以放歌只有这一个入口。`80077AD0` 除了原版音乐模块内部，还被标题、结局和战术地图（`801E076C`，敌增援 jingle）调用；`8007E87C` 有十来处调用者。
- 音乐是序列（类似 MIDI），由序列播放器 `D_800D1344` 合成，和音效在 RSP 里混成一路。宿主在 `srw64_queue_audio`（`src/host/audio.cpp`）拿到的是混好的立体声，44.1 kHz。
- 歌号共 49 首：标题 overlay 的 `D_801CB290`（ROM `0x1147E0`，49 × {文本号, 歌号}）就是音乐鉴赏的曲目表，曲名是文本 232 起。

### 2.2 战斗选曲

- 由地图 overlay 在交战结算之后、进演出之前选好（`801E085C(句柄A, 句柄B, 单方)`），所以**关掉战斗动画也会换曲**。
- 规则：
  1. 任一方是ヴァル＝ア三人 → `0x22`。
  2. 否则只要有一方是我方，就按**我方主驾驶员的人物曲表**（ROM `0x7D6A0`，361 项）；超级模式、明鏡止水、V-MAX 状态改用硬编码的 `0xB`／`0xA`／`0xD`。
  3. 都不是我方 → 按攻方**机体曲表**（ROM `0x7DF30`，363 项）。
- 没有按剧情变量、关卡、Boss 的分支。
- 关卡曲是地图资源记录 `+0xB`，每个阶段开始重放；战斗结束后不换回关卡曲，战斗曲一直放到下一阶段或下一场战斗。

### 2.3 战斗台词

- 战斗 overlay 为每个交战方准备两条台词：攻击时说、挨打／回避时说（`func_80222050`）。台词按**声部**（`D_800CA9C4[人物号]`，257 个）先查条件台词，再从九种情境（攻击、被击坠、重伤……射程外）的通用段里随机抽。
- 每句都有**台词记录号**：通用段 5813–14226，条件台词 14227–17346。多人对话（合体技等）是连续几条，各自有记录号和说话人。
- 宿主的对白层已经在台词开始显示时拿到记录号（`native_dialogue.cpp`，日志里的 `battle_quote` 事件带 `text_id`）。台词照原版时钟自动翻页，不能手动翻。

## 3. 包格式

放在 MOD 包的 `audio/` 下：

```text
audio/
  music/<歌号>.ogg       顶替原版第 N 首（歌号十进制，如 7.ogg = メインテーマ）
  music.json            可选：循环点、音量、曲名、改战斗曲
  voice/battle/<记录号>.ogg   某句战斗台词的语音
  voice.json            可选：语音设置
```

格式用 **Ogg Vorbis**（体积小、无专利；宿主用单头文件解码库，许可证与 GPL 兼容）。采样率任意，宿主重采样到输出采样率。

### 3.1 `music.json`（可选）

只放 OGG 也能用：整首循环、原音量、曲名不变。要细调时才写：

```json
{
  "schema": "srw64.music.v1",
  "tracks": {
    "7": { "loop": [123456, 2345678], "gain": -2.0,
           "title": { "ja": "…", "zh-Hans": "…", "en": "…" } }
  },
  "battle": {
    "pilot": { "36": 7 },
    "unit":  { "50": 12 }
  }
}
```

- `tracks`：按歌号设循环点（采样数，`[起点, 终点]`）、音量修正（dB）、音乐鉴赏里显示的曲名。也接受文件里的 `LOOPSTART`／`LOOPLENGTH` 标签，这是很多游戏音乐包的惯例。
- 新曲就是顶替某个歌号：放进 `music/<歌号>.ogg`、写上曲名，音乐鉴赏里那一行就变成新曲。
- `battle`：改「谁打仗放哪首」，值是歌号。`pilot` 按人物号，`unit` 按机体号。先按原版规则选出歌号，再查这张表覆盖（§4.2），所以ヴァル＝ア三人、超级模式这些原版规则仍然有效，除非作者明确改。

### 3.2 语音

- 文件名就是战斗台词记录号，和台词文本文件的 `@记录号` 一致；台词文件每条上方的 `# 触发：` 注释说明了这句什么时候出现（[台词文本文件](../guide/dialogue-text.md)），方便配音者对照。
- `voice.json`（可选）：整体音量；台词显示时语音的起始延迟；某个人物在战斗中是否闭嘴（只显示文字）。
- 同一记录号多个包都提供时，按 MOD 包 §3 的顺序后面的赢。
- 不分语言：语音一般只有一种（日语），换阅读语言不影响。

### 3.3 工具

- 导出清单：列出 49 首的歌号、曲名、出现在哪些关卡曲／战斗曲；列出每个人物的全部战斗台词记录号、文本和触发条件（现有的 `export_text.py` 已有这些数据），生成配音用的表格。
- 校验：文件名能不能对上歌号／记录号、循环点是否在文件长度内、`music.json` 字段是否合法。宿主与 Python 共用规则，坏包不启用（MOD 包 §3）。

## 4. 宿主实现

### 4.1 混音器

- 在 `srw64_queue_audio` 里，原版这一段音频送进 SDL 之前，把替换音乐和语音按同样的样本数混进去。
  - 时间轴跟游戏自己的音频走，不跟墙钟，所以不会漂。
  - 2 倍速、卡顿、暂停时，和原版声音的表现一致。
- 解码放在工作线程：音乐流式解码、按循环点循环；语音整段解码后缓存（短）。
- 两个独立音量：音乐、语音，在设置窗口「声音」一栏；另有「使用 MOD 音乐／语音」的总开关。单声道选项照原版设置一起生效。

### 4.2 音乐替换

直接拿 OGG 混：有替换的歌号，原版停掉不放，宿主放 OGG。具体包三个函数：

- **`8007E810(歌号)`**（放歌的唯一入口）：
  - 歌号有替换：先调原函数停掉原版音乐（`8007E810(-1)`），再把 `D_800FFA6C` 写成这个歌号，宿主开始放 OGG。原版「同一首不重开」照常有效。
  - 没有替换：宿主停掉 OGG，调原函数照常放。
- **`8007E87C`（淡出）**：照常调原函数，宿主同时淡出 OGG。
- **`80077AD0`（是否还在放）**：宿主在放 OGG 时，返回 OGG 是否还在放（循环曲永远是「在放」）；否则照原函数。这样敌增援 jingle（`0x26`）按替换文件的长度放完再切回关卡曲。原版音乐模块内部也调它，但那只发生在宿主没在放 OGG 的时候。

改战斗曲：包装 `801E085C`，在它选出歌号之后查 `music.json` 的 `battle` 表，换成表里的歌号再放。

音乐鉴赏、卡拉OK、战斗鉴赏也走 `8007E810`，自动用替换；音乐鉴赏的曲名按 `tracks` 里的 `title` 显示，没写就用原名。

### 4.3 战斗语音

- 在对白层识别到新的战斗台词时（`battle_quote` 事件、第一页），查 `voice/battle/<记录号>`，有就开始放。
- 同一侧下一句台词开始时，停掉上一句的语音；战斗结束、中止演出（手柄 X）时全部停止。
- 原版台词不等语音：语音比台词框显示得久，就会接着放到下一句开始或战斗结束。v1 不为语音延长台词框，因为那样会改动战斗演出的节奏。
- 关掉战斗动画时没有台词，也就没有语音。

### 4.4 调试与测试

- 调试接口状态加：当前歌号、是否被替换、来自哪个包；正在放的语音记录号。
- 单元测试：重采样、循环点、混音不爆音（饱和截断）、包合并顺序。
- 实机（Windows 台式机与 Mac）：
  - 标题音乐鉴赏放一首替换曲。
  - 迷你关打一场：战斗曲替换、按人物覆盖战斗曲、台词语音按记录号播放。
  - 敌增援 jingle 后能切回关卡曲。
  - 2 倍速与中止演出时声音正常。

## 5. 风险与注意

- **同一首不重开**：原版放同一首时直接返回，宿主也照此处理（`D_800FFA6C` 写成替换的歌号），否则两场战斗之间会从头重放。
- **卡拉OK 的歌词同步**：卡拉OK 按原曲的节奏走字幕，替换后对不上。可以在卡拉OK 模式里不用替换，或者随它（待定）。
- **战斗曲在地图上延续**：替换曲在战后会一直放到下一阶段，和原版一致，作者做循环时要考虑。
- **台词随机性**：通用段是随机抽的，配音者要按记录号配全，否则只有部分台词有声音。导出表格时标明每个人物的台词总数。
- **版权**：只提供机制和格式说明，不收录、不链接任何音频资源。

- 剧情语音：按剧情台词记录号，键已预留；剧情对白可手动翻页，可以选择「语音放完再翻」。

## 8. 实现进度（2026-10-20，`mods` 分支）

按歌号替换音乐与音乐鉴赏显示已经写好；改战斗曲、语音、音量设置还没做。

- **代码**：`src/host/music.{hpp,cpp}`。
  - 替换表：启用的包里 `audio/music/<1–255>.ogg`，按载入顺序上面的包赢；`audio/music.json` 读 `tracks` 的 `loop`（`[起点, 终点]`，或 `false`＝只放一次）、`gain`、`title`，类型不对的字段忽略。包有变化（安装、启停、删除）时重新读。
  - 解码用 RT64 自带的 `stb_vorbis`（公有领域），在 `music.cpp` 里编译一次。和 §4.1 写的流式解码不同，现在是在工作线程**整首解码**，最近两首留在内存里，关卡曲和战斗曲来回切不用重解；解完之前是静音，从解完开始放。`music.json` 没写循环时用文件里的 `LOOPSTART`／`LOOPLENGTH` 标签。
  - 混音：`audio.cpp` 在原版音频送 SDL 之前调 `srw64_audio_mixer`（`srw64-frame-host` 不带 MOD，指针为空），线性插值重采样到输出采样率，按原版设置的单声道位混成单声道，饱和截断。录像音轨在混音之后，所以录像里听得到替换曲。
  - 三个包装（`generate_cpu.py` 的 NATIVE_HOOKS，原函数改名 `srw64_original_play_song`／`_fade_song`／`_song_playing`）照 §4.2。淡出按游戏 60 Hz 帧数换算成输出样本数。敌增援 jingle（`0x26`）默认只放一次，`music.json` 写了循环才循环。
  - 卡拉OK（模式 `0x1A`）保留原曲。
  - 音乐鉴赏：被替换的行右侧标 `MOD`，包写了 `title` 就按当前语言显示包里的曲名（原版曲名照旧保持日语）。
  - 调试接口状态 `music`：是否在放替换曲、歌号、是否解完、位置、循环区间、是否只放一次。日志 `SRW64_MUSIC_REPLACE song=… file=… package=…`、`SRW64_MUSIC_DECODE_FAILED`。
- **测试**：`tests/native_music.cpp`（`make recomp-music-test`）覆盖 `music.json` 解析、多包覆盖与过滤（非歌号文件名、非 OGG、停用的包）、原速与重采样混音、整首循环与循环区间、只放一次、淡出、增益、单声道、截断、解码中静音。
- **实机（2026-10-20，Mac，分支构建）**：拖入含两首正弦测试音的包（歌号 4 为 440 Hz 并带中文曲名，歌号 3 为 660 Hz 并带 `LOOPSTART`／`LOOPLENGTH`），在音乐鉴赏里依次放 4、3、2（未替换）、4，再按 Esc 停止，同时录像，按半秒分析音轨：
  - 曲目表第 3、4 行标 `MOD`，第 4 行显示「测试替换曲」。
  - 放替换曲时音轨几乎只有测试音（测试音以外的成分约 0.5%），原曲没有声音；第 3 首按标签循环（循环区间 44100–132300，位置已经绕回）。
  - 换到未替换的第 2 首，原曲照常响起、替换曲停止；Esc 后静音，状态显示没有替换曲在放。
- **实机，迷你关（2026-10-20，Mac）**：
  - 地图 20 的关卡曲（44）、タケル 的战斗曲（23）都换成了替换曲；我方攻击、阶段开始、敌方攻击、第 2 回合开始时来回切换，宿主每次都接管，原版的当前曲号与替换曲一致。
  - 敌增援 jingle：第 1 回合事件里用 `3D3A 38` 直接放 0x26（3 秒的测试文件），放完后 `801E076C` 自己换回关卡曲。录音里 1000 Hz 之后直接接 500 Hz，中间没有空档。
- **还没验证**：淡出（场景切换）、2 倍速、Windows。
- **还没做**：`battle` 改战斗曲（包装 `801E085C`）、战斗语音、音乐／语音音量和总开关、§3.3 的导出与校验工具。
