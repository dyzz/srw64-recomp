# Android 触控 UI 复盘与回看入口修复

2026-10-10。用户反馈：最近改动后安卓回看入口消失；当前整体布局认可，希望离线比较各版后讨论设计。先做源码复盘、离线渲染和方案记录；随后用户确认复用返回位置，已按下述方案 C 实现。

## 结论

回看功能仍在，是触屏映射遗漏。`dialogue_model.hpp` 的 `Reader::update` 用 L（`0x20`）切换回看；`8fab028` 把 `FixedDialogue` 的圆形 L1 从 L 改成宿主 L2（自动），但没有迁移原 L 的入口。`by_scene=false`，因此保留在 `SceneId::Dialogue` 场景表里的“回看”不会出现在当前固定布局中。

同一改动保留了上排 L2/R2，当前对白布局有两个自动入口、两个按住快进入口、零个回看入口。此前实机复核验证了自动、快进、跳过和三语标签，没有验证被替换按键的原功能仍然可达；这是验收遗漏。

## 已采用：C，复用返回位置

用户确认（2026-10-10）：正常对白显示回看（L）；回看中显示返回（B）；跳过中显示停止跳过（B）。不新增按钮，正常对白上排和其他圆键不变。自动仍由自动键开关，快进保持按住生效、松开停止。

`touch_pad::scene` 接收阅读状态，界面从阅读器读取小型同步快照，所有显示和命中使用同一份状态布局。状态切换后，改变用途或消失的按钮不会重解释已经按住的手指，而是保持触摸所有权并阻断到松手。回看中收起自动/快进/跳过及重复触发键。阅读器另阻断回看期间的快进、跳过组合，关闭后仍按住也不会重新推进。没有可用阅读器的序章页保留 B。

离线页顶端新增三种已采用状态，直接编译当前工作区映射。历史和 A/B 草案继续保留供复盘。

## 早期候选方案

### A：自动上方新增回看（早期候选，未采用）

保留上排、十字键、确定、返回、自动、Hold + ▶▶ 和跳过的位置与功能。在自动上方新增与跳过同尺寸的回看圆键，直接发送 L。使用现有词条：回看 / ログ / Log，无须新增翻译。

草案尺寸：直径 9.2 mm；相对自动中心向上 13.2 mm、向左 1 mm。原本直接照搬跳过的 12.2 mm 偏移量，会使回看与跳过的扩展触摸圆略有重叠；调整后新增按钮与邻近圆键的扩展触摸区分开。现有自动与快进之间仍继承约 0.34 mm 的触摸范围重叠，不把这个既有问题误称为本方案新增，也不在本轮顺带移动已认可的按钮。

优点是符合“上方不变”和当前操作习惯，回看也明确可见；代价是按钮从 9 个增加至 10 个，仍保留上排自动/快进的重复入口。双框及较窄屏幕需要重点验证新增按钮与原生内容的关系。

### B：重复的上排 L2 改回看（备选）

对白时将上排 L2 改为“回看”，发送 L；圆形自动继续发送宿主 L2。按钮数量保持 9 个，回收一个重复入口，不多占画面。

这是数量更克制的方案，但改变了先前确定的上排语义，因此本轮只列作备选。仅给 L2 改标签而仍发送 L2 不算修复，必须验证实际输入位。R2 重复暂保留，避免讨论扩成整排重新设计。

不建议用自动长按、双击或隐藏手势兼任回看：入口难发现，还会使自动开关与长按判定冲突。也不建议为这一个遗漏恢复所有场景精简方案，10/08 恢复固定按钮的原因仍成立。

## 回看打开后的状态

补入口还应覆盖打开/关闭和滚动，而不只检查按钮存在：

1. 点回看打开面板，当前对白计时暂停；同一入口在回看中显示“返回”，再次点按返回原对白。
2. 十字键上下逐行、左右翻页；返回和确定只关闭面板，不能顺带推进对白。
3. 回看中不应继续显示可操作的自动、快进、跳过。现有阅读器会忽略自动切换，但 R2 含 A、跳过含 START，会先关闭面板；继续按住 R2 还可能在随后恢复快进。应显式屏蔽这些输入并在退出时处理仍按住的手指，不能只把按钮画成灰色。
4. 自动在回看中暂停计时，退出后恢复此前状态；快进不应从回看前的按住状态意外延续。正文滚动区应避开触控区域，并给触屏用户显示滚动/关闭提示。

上述状态约束已随方案 C 接入，A/B 离线图仍只展示早期入口草案。序章文字页与剧情对白也应区分：目前两者都落到 `FixedDialogue`，新回看入口应以阅读器可用为条件，不能给没有历史的序章页面放一个无效按钮。

## 验证范围

本次成功编译五份历史 C++20 头文件，导出四种物理尺寸布局。离线浏览器检查了当前与 A/B 的三语 × 四种屏幕配置，共 12 组：没有标签盒溢出或按钮越出画布；另保存双框、回看背景和三语截图供目视比较。几何审计使用源码中的 1.5 mm 触摸扩展，不把视觉间距当成触摸间距。

回归验收关注：

- 固定布局正在使用的分支必须实际包含 L、自动、按住快进和单键跳过，不能只测未启用的场景表。
- 手动/自动/快进 → 打开回看 → 上下左右滚动 → 关闭回看，各条路径都不丢当前句、不误翻页；按住快进时打开/关闭回看也要测。
- 剧情、世界地图对白、序章、选择肢、普通地图分别核对可用动作；单框/双框、三语及手机实际 DPI 下核对内容遮挡。

- `history-verification.json`：普通对白的回看打开/返回、长按入口不误关闭、确定关闭不推进、上下滚动/左右翻页、自动阅读在回看中暂停并在关闭后恢复、真实长按快进松手后停止，均通过。对白覆盖世界地图和战术地图开场。
