# 数据文本汉化：词条表与译名规范

日期：2026-09-23。本文说明名称、标签与系统提示这类“数据文本”怎样翻译、怎样进入语言目录，以及中文（`zh-Hans`）和英文（`en`）的统一译名规范。台词不走这里：战斗台词（约 5799–17346）与剧情对白、选择肢（17347 起）放在独立的纯文本文件里，玩家可以逐条修改，见[台词文本文件](../guide/dialogue-text.md)；它们的机翻草稿另有流程，译名以本文的词条表为准。

## 为什么用词条表

文本表 `base:t00` 前约 5,650 条是名称与界面文字：地形、作品名、关卡标题、机体、驾驶员、武器、精神指令、特殊能力与技能、強化パーツ、场间画面标签与提示，以及姓名输入提示、角色列表、反击命令说明、胜败条件和损伤程度。同一个日文原文会在很多记录里重复（同名武器每台机体一条，同一驾驶员每种形态一条），而武器列表文字（`格ビームサーベルP`）又是“标记＋武器名＋标记”的组合。逐条翻译既重复又容易前后不一致。

所以每种语言有一份词条表 `content/locales/terms/<locale>.json`：按分区列出“日文原文 → 译文”，每个不同的原文只译一次。`content/locales/terms/sections.json` 规定各分区对应的记录范围。`tools/content/apply_terms.py` 把词条表展开成语言目录里带 `source_sha256` 的普通条目（标 `"origin": "terms"`），运行时和 C++ 首次导入器读到的仍然只是条目，不需要认识词条表。

- 武器列表（`weapon_menus` 分区）不单独翻译：由 `weapons` 分区的译文按原版语法拼出——`格`／`射` 前缀、译名、`P`／`B`／`MAP` 后缀保持不变。这些字母只是占位：原版画的是字库里专门的图标字形（241–244、575），原生武器表也画这些原版图标，与语言无关。原名以 `MAP` 结尾的武器（`ファンネルMAP`），译文也必须以 `MAP` 结尾。
- 标记为 `complete` 的分区要求每个含日文的原文都有译文；`models`（机体型号）只翻译 `飛行試作型MA` 这类非型号文字。
- 词条表里的原文找不到对应记录（原文拼错或分区放错）时，工具报告“unused”。
- 词条与手写条目不能覆盖同一记录；数据区原有的 73 条手写译文已迁入词条表，第一话的 93 条手写对白移到了台词文本文件，语言目录里现在只剩词条条目。

```sh
PYTHONPATH=src .venv/bin/python tools/content/apply_terms.py            # 改完词条表后重写语言目录
PYTHONPATH=src .venv/bin/python tools/content/apply_terms.py --check    # 只检查，目录过期时失败
PYTHONPATH=src .venv/bin/python tools/content/apply_terms.py --missing  # 列出 complete 分区还缺的原文
```

`tests/test_terms.py` 检查中英词条表的分区与原文集合一致、译文不改 `<G:...>` 参数、词条条目都是草稿；有 ROM 时还确认语言目录与词条表展开结果一致。

## 显示位置与边界

- 原生页面（战前确认页、场间各画面）通过语言目录取这些文字，切到中文或英文即显示译文；缺译回退日文。
- 设置里把界面切回原版时，原版画面用 ROM 字模绘制，仍显示日文；这是有意保留的原版模式。
- 原版战术地图菜单、战斗动画内的标签与烘焙在图片里的文字暂未接入语言目录；它们的记录已经有译文，等接入时直接可用。
- 不翻译：调试标签（战斗动画编辑用的平假名条目 1179–1369、4307–4381，战斗与剧情标志编辑器 5644–5798）、音乐名（232–280）、改造刻度条（4145–4267）、地图图标字模（5104–5149）、姓名输入字盘（5220–5239、5247–5449）。

## 通用规范

**中文（简体）**：采用大陆玩家的通行译名（高达、魔神Z、盖塔），不用港台译名（钢弹、无敌铁金刚、盖特）。人名中间用间隔号 `·`（U+00B7）；感叹号、问号、括号用全角。机体型号、`HP`、`EN`、`MAP`、`L1`–`L9`、`S`／`M`／`L` 尺寸等保留原样。通行叫法优先于官方写法：现译就是大陆通行叫法的保留（卡缪·比丹、希罗·唯、扎古、东方不败）；没有通行叫法时用官方简中；两者都没有的按音译，尽量用人名常用字。**不用台湾、香港的译名**（2026-09-24 用户决定）：官方繁中、台配、台版谐音名、港版都不作为依据，只作参考。雷霆王是用户确认的例外：大陆 1994–95 年播出的就是台配版，没有 B 站正版；只保留作品名和机体名，台配的人名和招式另行复查。

**英文**：优先使用官方写法：Bandai Namco 官方英文版（超级机器人大战 V／X／T／30）、高达官方英文站、官方英文发行（Discotek 等）与官方卡牌；没有的按通行罗马字与英文圈惯例（Hepburn，长音不加符号：`Koji Kabuto`）。标签尽量短：原生页面列宽按日文设计，超长文字会被裁掉。

**两种语言都**：保持原文的信息，不加解释；保留原文里的数字、`+`、`%`；原文里连续两个以上的空格是填数字的占位（`第  話`、`(最大で  段階まで)`、`あと  機`、`命中率    %`），原生页面把第一处双空格换成数字，译文必须原样保留这些空格（`第  话`、`(最多  段)`、`Stage  `）；多行提示里 `<BR>` 的位置可以调整。

## 首批译文（2026-09-23）

31 个分区的 2,433 个原文全部有中英译文，展开为每种语言 4,674 条记录；`--missing` 与 `unused` 均为 0。

首批定下、上表之外的译法：

- **精神指令英文**按 T／30 英文版的叫法：必中 Bullseye、ひらめき Flash、根性 Vigor、ド根性 Guts、鉄壁 Wall、熱血 Valor、魂 Soul、友情 Faith、激励 Rouse、脱力 Daunt。中文用直觉、毅力、大毅力、铁壁、热血、魂等社区通行叫法。单字缩写（1149–1178）中文取译名首字，“大毅力”取“大”；英文取三个字母，自爆为 `SD`。
- **状态与技能**：気力 英文统一为 Will，战前页原来的 Morale 已改。聖戦士 英文统一为 Holy Warrior，规则开关原来的 Aura Warrior 已改。切り払い 中文为“切落”，強化 为“强化人”，S防御 保持“S防御”。战前页手写标签已按词条统一：奥拉屏障、I力场、行星防御器、马赫特技、神之影。
- **硬件与专名**：コントローラパック 为“手柄记忆卡”，64GBパック 为“64GB传输卡”，シャッフル 统一为“洗牌同盟”。マスターアジア 中文用大陆通行的“东方不败”，对应机体为“尊者高达”。
- **英文 MAP 武器**写成 `Buster Rifle MAP`。拼出的列表文字在标记前会多一个空格，但运行时按原版语法拆分必须保留它，显示上看不出。
- **ROM 笔误**不照抄：モンド・アガケ 与 モンド・アカゲ 都译作 Mondo Agake（蒙多·阿伽克）。官方写法是 Agake，ROM 里的 アカゲ 是笔误（首批曾按 アカゲ 译作 Akage，2026-09-24 改正）。ゲーツ・キャバ 与 ゲーツ・キャパ 同译为盖茨·卡帕／Gates Capa。
- **胜败条件**里的「・」中文改为顿号、英文改为分号。“〜の撃破”写成中性的“〜被击破／〜 destroyed”，因为同一句会出现在胜利和败北两种列表里。
