## 2. 接管方式

源码：[`ability_page.cpp`](../../src/host/ability_page.cpp)（游戏线程适配器）、[`frontend.cpp`](../../src/native/ui/frontend.cpp) 的 `ability_sync`（页面）、[`game_hooks.cpp`](../../src/host/game_hooks.cpp) 的包装（`ability_build`／`ability_step`／`ability_frame`，十个钩子在 `generate_cpu.py` 的 `NATIVE_HOOKS`）。武器行与武器列标签复用 `upgrade_page::weapon_row_json`／`weapon_labels_json`。设置页「场间画面」选原版时五个构建入口都交回原画面；`SRW64_NATIVE_ABILITY=0` 或不加载 profile 时整次运行保留原画面。

| 原函数 | 包装 |
| --- | --- |
| `801D14BC`／`801D22E0` 列表初始化 | 不调原函数。保留背景调用（含随机数）与列表生成、行副本、`D_801DEC5C` 写入；不建布局、文字、光标精灵 |
| `801D1554`／`801D2378` 列表每帧 | 移动／翻页：适配器写页、行、副本与 `D_801DEC5C`（每页 9 行）；确认／返回注入 A／B |
| `801D16D8`／`801D2480` 能力页初始化 | 不调原函数。保留背景调用；页面从记录直接取字段 |
| `801D2030`／`801D24C8` 能力页每帧 | 上一台／下一台注入 L／R（原版移动列表光标并重进画面，页面随之重建）；A（机体页）／B 注入 |
| `801D2144` 武器一览初始化 | 不调原函数。保留背景、`801C7254`；页写 1 |
| `801D21F8` 武器一览每帧 | 移动／翻页适配器自己写；返回注入 B |

**快照**：`status.ability_page`：`screen`（`units`／`pilots`／`unit`／`weapons`／`pilot`）、`serial`、`labels`、`weapon_labels`；列表有 `page`、`pages`、`cursor`、`rows[]`（机体：`slot`、`number`、`name`、`pilot`、`hp`、`art`；驾驶员：`index`、`number`、`name`、`unit`、`level`）、`sub{name,level}`；机体页有 `unit`、`size`、`repair`、`parts[]`、`hp`／`hp_max`、`en`／`en_max`、`types[]`、`shield`、`abilities[]`、`move`、`mobility`、`armor`、`limit`、`terrain`、`index`、`count`；武器一览有 `unit{…,en,morale}`、`page`、`pages`、`cursor`、`rows[]`（同武器改造）；驾驶员页有 `pilot{index,number,name,full_name,level,hidden,art}`、`unit`、`morale`、`next`、`sp`／`sp_max`、`stats{melee,ranged,hit,evade,skill,reaction}`、`over{hit,evade}`、`mobility`、`spirits[]`、`skills[]`、`terrain`、`index`、`count`。事件日志 `ability-page-events.jsonl`。

**调试**：稳定 ID `ability:N`（列表行；点光标行即进入，武器一览点光标行返回）；键盘 ↑↓、←→（翻页）、Enter／Z、Esc／X，能力页 Q／E（或 ←→）前后切换；等待条件 `ability_page`。
