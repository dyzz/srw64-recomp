# 2 倍速

设置「通用」页的「游戏速度」：原速／2 倍速，默认原速，存进 presentation.json 的 `game_speed`（1 或 2）。一键切换的是改键表里的「2 倍速开关」：键盘默认 Tab，手柄默认 R4 背键（SDL 的第一个 paddle），安卓触屏在左上角「开始」右边有一个 2× 按钮，开启时显示琥珀色。切换后左上角出现一个小标签（「2 倍速：开／关」）约 1.5 秒；安卓上不显示，按钮颜色本身就是状态。

代码：`src/host/game_speed.hpp`（判定与写入）、`src/host/host.cpp` 的 `frame_start`（每个 VI 调用）、`src/host/game_hooks.cpp`（战前画面的步进记号）、`src/native/ui/frontend.cpp` 的 `toggle_speed`。

## 原理

原版每隔 `D_8010F0C8` 个 VI 跑一帧逻辑。`8008163C` 在 `D_80172D0C`（距上一帧的 VI 数）小于它时直接返回；`8007FC48` 开机时写成 2，之后再没人写（[60fps.md §2.1](../design/60fps.md)）。游戏里所有等待、步进、滚动都按帧计数，所以改成 1 就是整体 2 倍速。VI 频率和音频线程不变：音乐速度不变，音效触发会密一倍。

宿主每个 VI 按场景决定写 1 还是 2。值还不是 1 或 2 时不写，开机流程照原样走。

## 哪些场景加速

| 场景 | 判定 | 速度 |
| --- | --- | --- |
| 战斗演出 | 模式 2、0x1A、0x1C | 2 倍 |
| 世界地图（剧情） | 模式 12、13 | 2 倍 |
| 战术地图·事件脚本 | 模式 3／0xB／0x11／0x16／0x22，且 `engine+0x97C` 不是 0x80（同 `script_inject.hpp` 的 `idle_reason`） | 2 倍；当前指令是选择肢（3D44）或出击选择（3D3D）时原速 |
| 战术地图·敌方与第三方阶段 | `0x8010F5E8` 不是 1 | 2 倍 |
| 战术地图·我方阶段 | 主状态 `0x80172EB0` 是等玩家操作的状态：5、6、8、0xC、0xD、0x16、0x17、0x19、0x1B、0x22、0x3A、0x3C、0x2E–0x37 | 原速 |
| 战术地图·我方阶段的其他状态 | 单位移动、阶段切换（0x39）等 | 2 倍 |
| 战前确认、敌方攻击时的应对选择 | `801D5064`／`801D5294` 在最近 4 个 VI 内步进过（无论哪个阶段） | 原速 |
| 其他（标志、标题、场间、姓名页、读档、结局、出售等） | 其余模式 | 原速 |

菜单保持原速，是因为原版的按键连发（按住 12 帧后每 3 帧一次）也按帧计数，2 倍速下光标会快一倍。

## 热键与原生页面

Tab 在战前确认页、场间画面里原本就用来换选项，所以只在没有原生页面、设置窗口、图鉴、MOD 管理和战斗查看器时才切换速度；这些画面本来就是原速。

Steam Deck 在 Steam Input 模板下不一定把背键交给游戏。SDL 看不到 R4 时，可以在 Steam 的控制器设置里把一个背键映射成键盘 Tab。

## 调试与验证

- 调试状态 `game_speed`：`double` 是设置值，`running` 表示这一帧是否在 2 倍速。
- 虚拟手柄键名 `r4` 按的是速度开关（`srw64_pad`）。
- 单元测试 `tests/native_game_speed.cpp`（`make recomp-game-speed-test`）覆盖场景判定和写入时机。

还没实机看过的点：每个 VI 一份显示列表时 RT64 的缓冲是否够用；背键在 Deck 的 Steam Input 下能否被 SDL 看到。
