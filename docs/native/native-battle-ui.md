# 战前确认 UI

日期：2026-09-20。原生 profile 运行默认在选定武器与目标后显示 SDL/RmlUi 战前确认页。敌方攻击时也用同一页面选择反击、回避或防御。场景是自制 `battle-ui` 迷你关卡，不是独立网页原型。

攻击／反击实机图、设计目标与功能需求见[战前 UI 设计说明](battle-ui-design-brief.md)。

## 页面与操作

双方卡片沿原版深蓝底、青色直角边框布局，保留战场地图。参考用户提供的机战 Y 截图调整为等宽、等高、左右镜像；敌方在左、我方在右，机体大图相向，驾驶员头像不镜像。HP／EN 余量绿色、损失部分红色，右侧资源条反向填充。显示等级、气力、SP、精神状态格、武器及消耗、命中率、暴击率、预计伤害，以及双方切落／盾防／分身几率。**武器的命中补正和暴击补正单独列出；最终概率已经包括这些补正。** 没有反击武器时不显示该方攻击数值，保留相同的布局高度。

- 我方主动攻击：开始战斗、选择武器、精神、返回选目标、战斗动画开关。选择武器直接打开原攻击武器列表；原版 B 只返回选目标，因此适配器顺序执行原确认返回和原目标返回两个入口。
- 敌方进攻：选择反击武器、精神、回避、防御、战斗动画开关、开始战斗。切换应对后重新发布双方快照，选择武器进入原游戏武器列表，再回到新页面。
- 鼠标、↑↓ 或 Tab 选择按钮，Enter／Z 执行；我方主动攻击时 Esc／X 返回。模态期间拦截底层游戏输入，关闭后等待按键释放，避免确认键穿透。
- 文案使用现有中／日／英目录，未翻译的机体、驾驶员和武器名沿用日文回退；动态主角名走既有名称展开。
- `SRW64_NATIVE_BATTLE_UI=0` 保留原确认界面；不加载 profile 的旧入口也保留原界面。脚本强制战斗和 AI 对 AI 交战不弹出此页。

## 战前精神使用

攻击和反击均提供我方参战机体的精神选择页，包括同乘驾驶员各自已经习得的指令和独立 SP。状态格汇总本机已习得及当前生效的精神：灰色表示未生效，橙色／绿色高亮表示实际效果位已开启；根性等即时恢复指令不伪装成持续 buff。

习得数量及指令读取驾驶员 `+0x0A`、`+0x0B`，当前／最大 SP 为 `+0x16/+0x18`，消耗读取 ROM 运行表 `80217F70`。是否可用调用原 `801F18A0(handle,id)`，列表检查在 RAM 副本执行，选定后再次验证。已生效、SP 不足和需在地图使用分别标注；需要地图目标的指令、自爆及复活仍保留地图入口，不自动替用户指定对象。

选择可用指令后调用原 `801D6A68`，由原效果与演出流程负责精神、HP、气力、行动次数及 SP 扣除（`801E195C`）。仅在这一段战前施放期间拦截正常返回地图的 `801C8AB4`：恢复保存的菜单／光标／参战表，重新调用原命中计算及战斗显示缓存，再打开战前精神页。不会恢复单位、驾驶员、物品、阶段或 RNG 数据，因此实际消耗与效果不会因返回而撤销。

Esc 关闭精神页回到当前交战；随后再次 Esc 才是原有的主动攻击取消。回避／防御选择及当前武器在施放期间保留；SP 不足的选项不能通过旧 serial 或重复点击绕过。精神页打开时背景战斗按钮禁用，方向键与 Tab 在可用指令及返回按钮之间选择。

## 数据口径

| 项目 | 来源与处理 |
| --- | --- |
| 命中率 | 原游戏已计算的参战表 `8018B6E8 + slot*0x5C + 0x12`，限制在 0–100；包含应对指令的回避减半及精神效果。与原游戏显示口径一致，未重新解释其随机数端点。 |
| 武器命中补正 | 运行时武器记录 `+0x0A`，有符号字节；ROM 表行内 `+4`。 |
| 武器暴击补正 | 运行时武器记录 `+0x14`，有符号字节；ROM 表行内 `+13`。 |
| 暴击率 | 纯函数复算 `801F47B0` 的阈值。己方为技量差＋武器补正＋底力；敌方／第三方为（技量差＋武器补正）÷4。下限 1，再按整数随机数 0–99 的成功个数显示：`clamp(ceil(threshold),0,100)`。热血／魂生效时为 0。 |
| 预计伤害 | 在完整 RDRAM／上下文副本调用 `801F5628`，分别选非暴击／暴击分支；纳入精神、防御指令、护罩，最后经过 `801F5B78` 的手加减／生存限制。随机数仅在隔离副本中固定，不消耗真实战斗 RNG。显示命中且没有特殊回避时的伤害，不是概率加权均值。 |
| 切落／盾防 | 驾驶员技能、等级与机体装备均须满足。切落还检查对方当前武器 `+4 & 8`；不是按武器名称猜测。我方几率为 `ceil(level*100/16)`，敌方／第三方为 `ceil(level*100/32)`，上限 100%。 |
| 分身类 | 机体对应能力、主驾驶员气力 ≥130 时 50%；对方必中使切落与分身失效。各几率是到达该防御判定时的条件概率，不可相加。 |
| 精神与图像 | 精神读取主驾驶员状态位，名称走语言目录；机体首个非空姿势与驾驶员头像由本地 ROM 导入，365 个姿势绑定中的 363 个有效绑定、361 个头像绑定均有 Python／C++ 像素一致性检查。 |

暴击是**命中后的条件概率**。例如敌方阈值 `21/4 = 5.25`，整数 0～5 都成功，显示 **6%**。不可直接截断成 5%。武器命中 `+20` 也不必然让最终命中多 20 个百分点，因为之后还要乘地形／尺寸倍率。

本页没有展示预先掷出的暴击标志或命中结果，也没有把各项特殊防御合并成“实际造成伤害概率”。假身次数在能力区显示，二次攻击仍未单独展示。公式研究见[战斗计算](../gameplay/battle-formulas.md)。

## 护罩口径

当前普通战斗的 `801F7204` 在护罩分支入口检查攻击武器 `+4 & 2`，并保留所选反击武器的 EN 后要求至少 5 EN。本作四类护罩经过此入口；名称含“ビーム”不等于该武器设置了此位，例如迷你关卡的ベガトロンビーム（678）原始属性为 `0x40`，不会触发此分支。

- I 力场 2000、行星防御 2000、光束涂层 1000，可累加；伤害不超过强度则无效化，超过时减去强度、残余最低 10。
- 灵气屏障为 3000＋圣战士等级表加成；不超过阈值则无效化，超过则全额贯穿，不做减法。
- 防御指令（参战表 `+0x10 == 2`）会把护罩强度翻倍。这不是“地形 2”。
- 成功无效化／减伤消耗 5 EN；灵气屏障被贯穿不消耗这 5 EN。发生护罩反应后不再判盾防，包含灵气屏障贯穿分支。
- 盾防成功时，伤害 ≥20 才按原版整十取整减半；界面另列对方盾防时伤害。

以上由 616 组原结算函数对照覆盖四类及组合、光束标记有／无、EN 4／5 边界、反击武器 EN 预留、防御指令和伤害阈值。范围是本作普通交战；不泛指其他作品所有称为“护罩”的能力。

## 接入方式

`battle_page.cpp` 在游戏线程读取参战双方并发布 JSON 快照；`frontend.cpp` 只读快照、向适配层发送带 serial 的语义动作，不读取 RDRAM。预览副本中的原估算函数写入不会进入真实战局。

`801D5064`（主确认）、`801D5294`（敌方应对）的包装停留在原输入状态。用户确认时仅向原函数提供一次 A／B 边沿与原菜单选项，原函数继续负责武器合法性、战前事件和战斗流程。动画开关沿用 `8015DDA8 & 4`（置位表示关闭）。

切换语言只更新快照名称；打开设置不会把新规则混入已经准备好的战斗快照。下一次原游戏重新计算战斗时使用当前规则。

源码：

- [`battle_page.cpp`](../../src/host/battle_page.cpp)：状态适配、原流程调用和输入所有权。
- [`combat_preview.hpp`](../../src/host/combat_preview.hpp)、[`critical_probability.hpp`](../../src/host/critical_probability.hpp)：预览与离散暴击概率。
- [`frontend.cpp`](../../src/native/ui/frontend.cpp)：共享 RmlUi 布局、操作和多语言。
- [`battle_ui_probe.hpp`](../../src/host/battle_ui_probe.hpp)：可选运行探针，仅 `SRW64_BATTLE_UI_PROBE=1` 时执行；随机数固定值只作用于本线程的隔离副本调用。

## 双方能力效果与底力（2026-09-21）

双方卡片新增可滚动的“能力效果”区，读取实际驾驶员技能、技能等级、当前 HP 和机体能力。补正数值是已纳入命中／暴击预估的公式项，不会再叠加一次；必中、必闪等最终覆盖仍优先。技能存在但本次不满足条件时保留条目并解释原因。

| 能力 | 展示口径 |
| --- | --- |
| 新人类／强化人间 | 技能等级，命中与回避补正。原计算按同一技能标志组处理，不重复叠加。 |
| 底力 | 等级、是否生效、当前命中／回避／暴击补正，以及该等级的 HP 发动阈值。**本作不增加装甲**。敌方／第三方不加底力暴击；我方热血／魂期间另提示不能暴击。 |
| 圣战士 | 回避补正；原命中计算没有攻击方圣战士加命中的调用。等级还影响灵气屏障强度。 |
| 超能力 | 命中与回避补正。 |
| 切落／盾防 | 各自技能等级、本次几率，以及无装备、等级不足、不可切落武器、必中或护罩优先等原因。 |
| 分身类机体能力 | 分身、马赫特殊、真马赫特殊、神之分身、盖塔幻影、瞬幻足、超级干扰器，显示各自名称及本次几率／未发动原因。 |
| 护罩 | 灵气屏障、I 力场、光束涂层、行星防御，分别列基础强度与本次状态。最终组合强度、防御指令与 EN 消耗仍由上文护罩计算处理。 |
| 其他特殊防御 | 假身剩余次数；特定机体的固定伤害装甲。假身没有折算为概率，也不把条件伤害变为概率加权伤害。 |

当前默认修正规则下，底力 L4 在 **HP < 40%** 时开始生效。1050/3000（35%）对应 ROM 表基础值 10：命中 +5、回避 +5、我方暴击 +10；恰好 40% 不生效。HP 越低，按后续档位提高。关闭档位修正时，原版整体提前一档；关闭减半修正时，命中／回避使用完整基础值，暴击不变。界面遵循打开该次战斗时的规则设置。

机制依据为本地原函数与 ROM 表：`801F45C4` 周围的命中调用链、底力 `801E1D64`／`80217F90`、新人类 `801E1EDC`、圣战士 `801E1F08`、超能力 `801E1F10`，以及暴击 `801F47B0`。原版圣战士／超能力的空函数保留调用方的技能掩码，实际得到回避 +32、命中／回避 +64；启用等级修正后才按等级表取值。没有把空函数误解成零加成。
