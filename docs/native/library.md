# Library（图鉴）

日期：2026-10-02。原版没有的资料页：标题画面右下角 MOD 左边的「Library」，也可从设置「通用」页的「Library · 图鉴」进入（给够不到标题按钮的手柄）。窗口沿用设置窗口的框体，左边列表、右边详情，分「机体」「人物」两页。

## 作品分组

原版标题 overlay（`load_0010DA50`，ROM `0x10DA50` 载于 `801C4500`）里有两个玩家进不去的画面「キャラクターリスト」「ロボットリスト」（初始化 `801C8F1C`／`801C96FC` 无调用者，见[标题菜单](native-title-menus.md)），数据和显示代码完整，图鉴的分组就用它们：

| 表 | 位置 | 格式 | 原版用法 |
| --- | --- | --- | --- |
| 人物表 | `D_801CB3A0`，ROM `0x1148F0`，246 条 | `u16 人物, s16 作品, u16 标志` | `801C8AF8` 建表，`801C8D74` 详情显示全名与作品名 |
| 机体表 | `D_801CB964`，ROM `0x114EB4`，316 条 | `u16 机体, s16 作品, s16 型号` | `801C930C` 建表，`801C9578` 详情显示型号（文本 `110+型号`，−1 无）与作品名 |
| 作品名 | 文本 `60+作品`（带换行的版本 `85+作品`），25 部 | | 中英文译名在词条表 `series` 段 |
| 重复记录别名 | 人物 `D_800C6A08`（ROM `0x513F8`，33 对），机体 `D_800C6A8C`（ROM `0x5147C`，22 对） | `u16 重复编号, u16 主编号` | 原版「见过」判定 `80091574`／`80091670` 用它把重复记录归到主记录；同一编号多次出现时最后一对生效，照搬 |

原版没有介绍文字：两个详情画面只显示上面这些，ROM 文本里也没有成段的人物／机体介绍。原版的列表还按「见过」位图（`D_8010F4D0`／`D_8010F520`）决定显示哪些，图鉴不做解锁，全部显示。

归组顺序：在表里 → 按别名找到主记录 → 表里同名的记录 → `library.cpp` 的补充表（徒步的ドモン 等、ハイパー系オーラバトラー、盖塔战机、ビッグゴールド、ドラゴノザウルス，以及能从兵种名确定作品的杂兵）→ 都不行的归「其他」（AI、ゲリラ 等）。**真・ゲッター1/2/3 原版表归在オリジナル，图鉴改归ゲッターロボ**（用户决定）。组的顺序是作品在原版表里第一次出现的顺序（UC 高达各作 → G → W → 超级系 → 原创），组内按原版表顺序，表外的排在后面按 ROM 顺序；机体详情加型号，两页详情都显示作品名。

## 页面

版式以 Steam Deck「特大」界面（1280×800 像素、1.48 像素／dp，约 865×540dp）为基准设计：面板几乎占满窗口（96%×94%，上限 1180×760dp），标题与页签同一行，列表固定 210dp；图框取详情区宽度的 30%（150–220dp，Deck 约 164），地形放在图下；金色标签（改造上限／二回行动）在名字右边，人物的阵营等短标签跟在全名后；机体数值每行 3 格，人物 7 项加一个「Lv1 → Lv99」图例格每行 4 格，恋爱补正单独一行；武器名后的标签放不下时换行，列表长名字自动缩字。改界面大小或窗口时整页重建。Mac「标准」大小下同一版式更宽松。

两页同一版式：左边方形大图（机体战斗立绘、人物头像），右边作品（机体加型号）、名字（人物加全名）、标签行、数值条、地形；下面是各自的小节。

- **机体**：金色标签是改造上限（+0x20，6–15 段，武器共用），其后移动类型、尺寸、特殊能力、盾、强化部件槽（+0x19）、修理费。六项数值条满格取全体前 10% 左右（HP 22000、EN 300、移动力 10、运动性 130、装甲 2300、限界 380）。武器表加「满改」（改到上限的攻击力）与「型」（改造类型 Ⅰ–Ⅳ，武器 +0xE；每段增量是常驻表 `D_800CA590` 的一行，费用是改造画面 overlay 的四张 u32 表），表下按本机出现的型列出改满共加多少攻击力、花多少资金。满改解锁的武器（`D_801DC87C` 18 条，已在机体武器表里，+0xF 带未解锁位 0x04）标「满改解锁」，+0xF 0x02 标「合体技」。
- **人物**：金色标签是二回行动等级，其后阵营（原版人物表第三字段，1＝以敌方登场）、副驾驶员／妖精（能力记录 +0 的 0x80／0x40；这两类六项能力与二回行动照原版能力页显示「–」，精神点数照常）。恋爱补正（表 ROM `0x1012B4`）每位搭档带小头像，标「双向」或「单向」：搭档也有一行指回本人才算双向，原版有 7 条单向（阿莲比→多蒙、利修→塞蕾茵、艾玛丽→布莱特、比查→艾露、艾露→捷度、波士→纯、波士→沙也加）。数值条白色到 1 级、青色延伸到 99 级。精神指令为卡片（习得等级、消耗），特殊技能画在 1–99 级的刻度轴上。
- 没展示的原版数据：换乘类别（机体 +0x12、驾驶员 +0xB）、出售基础价（只有 9 种量产机可卖，表 ROM `0x109030`），按用户决定不显示。

## 收录规则

- 按作品分组，见上。
- 名字为空、`???` 或纯数字的占位人物不收。
- 同名且记录完全相同的后续条目去掉（机体比较 36 字节记录和武器编号；人物比较能力、阈值、精神记录）；同名但数值不同的保留，同一作品内从第二个起加「(2)」「(3)」（不同作品的同名人物如两个「大作」不编号）。当前 ROM：机体 353 条、人物 293 条。
- 没有能力记录的人物（映射为 −1）只显示头像和名字，注明「不上场战斗的人物」。
- 数值是基础值：不含改造、强化部件、精神和气力效果。人物 284（我方クェス）的阈值按游戏的实际读法越界读进精神表，页面照游戏显示。

## 操作

| 输入 | 作用 |
| --- | --- |
| ↑↓ ／ 十字键上下（按住连发） | 选条目；在第一条再按上回到页签 |
| ←→ ／ 十字键左右 | 滚动详情；在页签上则切页 |
| Q／E ／ L1／R1 | 机体 ↔ 人物 |
| 鼠标 | 点条目、点页签，滚轮滚列表和详情 |
| Esc／X ／ B | 关闭 |

两页各记住自己选到的位置；切语言、切 Original／HD 会重建页面。详情跟随选择用 `SetInnerRML` 局部更新，不重建整个窗口。调试接口：`ui.click --id library-open`、`lib-tab:0|1`、`lib-item:N`。

## 代码

- `src/host/library.{hpp,cpp}`：ROM 解析与去重，按阅读语言缓存，窗口线程调用。
- `src/native/ui/frontend.cpp`：标题角落按钮（`home_sync`）、设置通用页入口、`library_panel`／`library_select`／`library_move`；挂在设置窗口的 `settings_open` 上，所以输入接管与 MOD 管理器一样。
- 词条：`content/locales/*.json` 的 `library_*`，已登记 `UI_KEYS`。
