## 2. 接管方式

源码：[`swap_page.cpp`](../../src/host/swap_page.cpp)（游戏线程适配器）、[`frontend.cpp`](../../src/native/ui/frontend.cpp) 的 `swap_sync`（页面）、[`game_hooks.cpp`](../../src/host/game_hooks.cpp) 的包装（`swap_build`／`swap_step`／`swap_frame`，十个钩子在 `generate_cpu.py` 的 `NATIVE_HOOKS`）。设置页「场间画面」选原版时五个构建入口都交回原画面；`SRW64_NATIVE_SWAP=0` 或不加载 profile 时整次运行保留原画面。

| 原函数 | 包装 |
| --- | --- |
| `801D25A4`／`801D4164` 列表初始化 | 不调原函数。保留背景调用（含随机数）与候选表生成、行副本、`D_801DEC5C` 写入 |
| `801D263C`／`801D41FC` 列表每帧 | 移动／翻页适配器自己写（每页 9 行）；确认／返回注入 A／B |
| `801D2758`／`801D42FC` 目标列表初始化 | 不调原函数。保留背景与目标表生成；`D_801DD3A0` 先按光标写好 |
| `801D2A24` 机体列表每帧 | 移动／翻页写页、行与 `D_801DD3A0`；确认／返回注入 A／B |
| `801D4578` 妖精目标每帧 | 列表模式：移动自己写；确认由适配器切到弹窗模式（原版 A 分支只建弹窗精灵与文字）；返回注入 B。弹窗模式：はい 注入 A（原版完成上机并回画面 20）；いいえ／取消由适配器关窗 |
| `801D2B64` 确认初始化 | 不调原函数。保留背景；`D_801DECBC` 照原版写成当前机体的運動性 |
| `801D3A90` 确认每帧 | 光标移动自己写；确认／返回注入 A／B（はい 时原版执行换乘） |

**快照**：`status.swap_page`：`screen`（`pilots`／`fairies`／`targets`／`fairy_targets`／`confirm`）、`serial`、`labels`；列表有 `page`、`pages`、`cursor`、`rows[]`（`index`、`number`、`name`、`full_name`、`level`、`unit`、`art`）、`sub{name,level}`；目标列表另有 `pilot{…,unit}`、行（机体：`slot`、`name`、`pilot`、`hp`；驾驶员：同列表行），妖精目标有 `mode`、`window_cursor`；确认页有 `pilot`、`from{name,pilot,sub,art}`、`to{slot,name,hp,limit,mobility,sub,art}`、`evade`／`hit{value,after,now,over}`、`terrain`、`cursor`。事件日志 `swap-page-events.jsonl`。

**调试**：稳定 ID `swap:N`（列表行）、`swap-yes`／`swap-no`；键盘 ↑↓、←→（翻页）、Enter／Z、Esc／X；等待条件 `swap_page`。

## 3. 实机验证（2026-09-23）

```sh
.venv/bin/python tools/recomp/debug/check_swap.py            # 构建、跑测试关卡并检查
.venv/bin/python tools/recomp/debug/check_swap.py --reuse-build
```

第一话通关存档没有可换乘对象（主菜单直接蜂鸣）。候选条件（`801C5618`）：驾驶员类别（驾驶员 ROM 记录 `+0xB`，运行时 `+0x32`）非 0，且名册里同类别（机体 ROM 记录 `+0x12`，运行时 `+0x1A`）、`+0x0C & 0x80` 的机体有两台以上（类别 1 另可用类别 7、类别 3 另可用类别 4）。原创机（类别 0）永远不是候选，所以测试关卡 `config/recomp/mini-stages/swap-test.json` 在 `flow.json`（无战斗、`3D4A` 结束）的开场用 `3D5A 95,0,117,500`、`3D5A 91,0,115,500` 登记 ヒイロ／ウイングガンダム 与 五飛／ガンダムシュピーゲル（都是类别 3），关卡跑完进入场间画面后 のりかえ 就有候选。**用 `3D5A 999,0,机体,500` 登记无人机体会破坏名册**：战术回合里 `800ABF70`→`800ABF08` 读到坏指针崩溃。

运行 `build/recomp/debug/20260923T042217.100733Z/`：`swap-checks.json` 12 项通过，退出码 0。

| 检查 | 结果 |
| --- | --- |
| 候选列表 | ヒイロ／ウイングガンダム、五飛／アルトロンガンダム；↓ 移动 |
| 机体列表 | ヒイロ 的可乘机体只有 アルトロンガンダム（五飛 已在上面；シュピーゲル 不在名单——原版 `801C59AC` 的规则，页面照抄其结果） |
| 确认页 | ヒイロ → アルトロンガンダム：限界 330、回避 120+115 (220)、命中 113+115 (213)、地形 CABA；↓ 到 いいえ、Z 回机体列表 |
| はい | 原版执行换乘：候选列表里 ヒイロ 变为 アルトロンガンダム，五飛 变为 ウイングガンダム；再换回 |
| 返回 | X 回主菜单，光标在 のりかえ |

原版对照（`build/recomp/debug/20260923T041326.824813Z/swapo-confirm.png`，设置切原版后同一流程）：确认页地形为 空 C 陸 A 海 B 宇 A——`800A6194` 是两者 rank 之和分档，页面第一版按较低一档算成 `-ABA`，已改正；机体名在战斗图下方 (184,120)，两行说明「制限をうける能力／( )内は本来の能力」在左侧，页面第二版照此排版。
