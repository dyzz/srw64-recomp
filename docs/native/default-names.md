# 默认姓名的三语显示

2026-09-27。用户定下：主角、搭档的名字和部队名都**不让玩家改**，默认名按阅读语言显示中文、英文或日文。部队名那一半（跳过第 33 话的命名选择、`3D5E` 兜底）见[部队名固定](fixed-unit-name.md)。

## 做法

**存储不变。** 姓名区（`8010F5F8` 起，见[主角选择与确认页](native-name-entry.md)）和部队名 `8010F698` 只存原版字形，也就是 ROM 默认名的日文。存档格式不变，本移植版写出的存档原版也能读。ROM 字库只有约两千个日文用字，「布拉德」这类中文名存不进去；不许改名以后，字库也就不需要扩充了。

**显示时替换。** [`default_names.hpp`](../../src/native/game_adapter/default_names.hpp) 的 `DefaultNames` 判断一个字段是否还是默认名：

- 内容等于某个默认名的日文（首尾空格不算），就显示它在阅读语言里的译名；
- 其他内容原样显示，三种语言相同。包括旧版本里玩家输入的名字，以及在原版游戏里改过名的存档；
- 名字、姓氏、昵称、部队名分开判断，只比同一类字段；
- 全名按原版中点「・」（字形 `0xE7`）拆成两段，分别判断，再用该语言的分隔符连起来：中文「·」、英文空格、日文「・」。所以只改过姓的旧存档显示成「布拉德·ヒカリ」；
- 日文一律原样返回，和游戏画面上画出来的原文逐字相同，对白适配器要拿它来比对。

**数据只有一处。** 八个人的译名直接取自[词条表](localization-terms.md)的 `default_names` 分区，不另建表：ROM 记录 487–494 是简称，同时就是默认昵称（`801C3744` 从名字截取：一般 5 格，アークライト 3 格，得到 アーク）；495–502 是全名，名字和姓氏按该语言的分隔符从全名拆开。`add_people()` 在 `dialogue::configure` 里从语言目录登记。改词条表并重跑 `apply_terms` 后就生效。某语言的全名拆不成两段时，这个语言的名字和姓氏显示日文，事件日志记一条 `default_names_unsplit`。部队名 マーチウィンド 由 `unit_name.cpp` 登记，界面词条是 `unit_default_name`。

共享实例是 `names::default_names()`（[`native_name_entry.hpp`](../../src/host/native_name_entry.hpp)）：启动时写入，游戏线程和界面线程之后都只读。

## 接入点

| 显示处 | 取名方式 |
| --- | --- |
| 台词里的 `{HeroName}` 等占位符（`<G:0124>`–`<G:012C>`） | `native_dialogue.cpp` 的 `expand(ram, text, locale)` 读字段，经 `shown_name` 按语言显示 |
| 对白说话人、回看、战斗台词 | `speaker_name`。回看每种语言各存一份，每份用自己语言的默认名 |
| 原生页面上的驾驶员名：战前确认、能力、のりかえ、強化パーツ、改造 | `ui_text` → `record_text`：原版取字函数 `8008CF14` 把记录 4407–4414、4768–4775 换成姓名字段，宿主照做，再按语言显示 |
| 原版界面的文字覆盖层（战术地图、战斗画面标签） | `label_text`，同上 |
| 存档页和标题画面的读档列表 | `save_page.cpp` 的 `slot_json`：存档头里存的是主角昵称 |
| 选角卡片与确认页 | `frontend.cpp` 的 `sync()` 在交给页面前换成阅读语言 |

**切换语言**（F7 或设置）立即生效：对白框和回看按新语言重排，各原生页面按原有的 `relocalize` 重建，存档列表随页面重建。

## 选角流程

- **新版**（默认）：选主角 → 确认 → 开始故事，确认页上的「返回角色选择」回到选角页。选定路线时，宿主照原版提交姓名的方式写入两人的默认名：把名字、姓氏、昵称放进编辑缓冲 `801C71E0`，再对主角、搭档各调一次原版校验函数 `801C474C`，由它写出名字、姓氏、昵称、全名四个字段。校验按理不会拒绝默认名；万一拒绝，就退回原版姓名页，日志记 `defaults-rejected`。
- **原版**（设置「主角选择」选原版）：原版选角页的「はい」之后，同样写入默认名并置 `801C70F4 = 2`，淡出结束后直接进入路线序章，不进原版选字页。日志记 `original-started`。
- `SRW64_NATIVE_NAME_ENTRY=0`：整次运行保留原版的全部页面，包括改名，只用来复现旧基线。

旧的姓名编辑页、输入法组字、字符校验、`E000..` 虚拟文本记录，以及 23 条界面词条都已删除。

## 存档兼容

- **旧存档**：默认名自动按阅读语言显示；以前改过的名字原样显示。
- **新存档**：内容与原版一致，原版游戏、旧版本移植都能读。
- **代价**：旧版本里手打的名字如果恰好与默认名一字不差，也会被当成默认名，随语言切换。
