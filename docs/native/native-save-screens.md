日期：2026-09-23。场间菜单第 1 项。两个原版画面（画面号 1、9）由 RmlUi 页面接管，保持原构图；页面自己走状态机，只调用原版的存档头读取与 SRAM／コントローラパック 写入例程。原版画面可在设置页「场间画面」选回，见[场间主菜单](native-intermission-menu.md)。

## 2. 接管方式

源码：[`save_page.cpp`](../../src/host/save_page.cpp)（游戏线程适配器）、[`frontend.cpp`](../../src/native/ui/frontend.cpp) 的 `save_sync`（页面）、[`game_hooks.cpp`](../../src/host/game_hooks.cpp) 的包装（`save_build`／`save_step`／`save_frame`，四个钩子在 `generate_cpu.py` 的 `NATIVE_HOOKS`）。设置页「场间画面」选原版时两个构建入口都交回原画面；`SRW64_NATIVE_SAVE=0` 或不加载 profile 时整次运行保留原画面。

| 原函数 | 包装 |
| --- | --- |
| `801CEA30` 介质选择初始化 | 不调原函数。保留背景调用（含随机数），清 `D_801DDA30`、`D_801DECD8` |
| `801CEABC` 介质选择每帧 | 光标由适配器写 `D_801DEBC8`；确认由适配器置 `D_801DDA30=1`、`D_801DECD8=30` 并显示 データを調べています。，此后每帧交回原函数倒计时与转场（不画东西）；返回注入 B |
| `801CECE8` 存档栏初始化 | 不调原函数。保留背景；Pak 时 `80094168` 定状态，否则 `80085CD4(介质, D_801DD118)` 读两栏 |
| `801CEEF8` 存档栏每帧 | 不调原函数（原版的 A 与 Pak 拔出分支自己画弹窗）。适配器照原版状态机：写入调 `80092678`／`80094168`＋`80093FD4`，成功淡出重进画面 9，失败进提示模式；提示模式每帧 `800906A0`，A 走 `80090844`／`80094168` 重查；模式<2 且 Pak 时每帧 `8009412C` |

**快照**：`status.save_page`：`screen`（`choice`／`slots`）、`serial`、`labels`（rom、pak、save_to、checking、slot、level、episode、clear、turns、funds、overwrite、ask、yes、no）；介质选择有 `cursor`、`waiting`；存档栏有 `medium`、`cursor`、`mode`（0 列表、1 覆盖确认、2 提示）、`window_cursor`、`status`、`slots[]`（`index`、`used`、`name`、`protagonist`、`level`、`episode`、`title`、`turns`、`funds`、`art`）、提示模式另有 `message[]`（`text`、`x`、`y`）。事件日志 `save-page-events.jsonl`（`open`、`choose`、`window-open`／`window-close`、`write`、`recheck`、`pak-removed`、`back`、`close`／`left`）。

**调试**：稳定 ID `save:N`（介质或存档栏）、`save-yes`／`save-no`；键盘 ↑↓、Enter／Z、Esc／X；等待条件 `save_page`。

## 3. 实机验证

```sh
.venv/bin/python tools/recomp/debug/check_save.py            # 构建、读第一话存档并检查
.venv/bin/python tools/recomp/debug/check_save.py --reuse-build
```

存档 `intermission-cold-1.source.sram`（第一话通关，栏 1 マナミ 等级 2、第 1 話「出撃!スイームルグ」、7 回合、14500）。运行 `build/recomp/debug/20260923T044601.424135Z/`：`save-checks.json` 19 项通过，退出码 0。

| 检查 | 结果 |
| --- | --- |
| 介质选择 | 光标 0，↓ 到 コントローラパック，Z 后 データを調べています。（`waiting`）约半秒进入存档栏 |
| 存档栏 | 栏 1 名字由字形码解出 マナミ，头像为名字输入页的 28 号脸（类别 3）；栏 2 空 |
| 空栏写入 | ↓ 栏 2、Z：`80092678(1)` 后画面重进，栏 2 与栏 1 内容一致 |
| 覆盖确认 | 栏 1 上 Z 开窗，↓ いいえ、Z 关窗；再开窗 はい 写入后重进 |
| 返回与 Pak | X 回介质选择；コントローラパック 路径进提示模式（状态 7：修复提示七行），X 回介质选择，再 X 回主菜单光标 0 |

原版对照（`build/recomp/debug/20260923T041741.927962Z/save-*.png`，`80090778` 钩子生效后的原画面）：构图一致；提示框里原版把同一行拆成两段文字（例如 0x1B8＋0x1B9），页面按 y 合并成一行。
