# 改键

2026-09-28。用户要求：按键设置加手柄图对照，加上本作的附加按键，按一下就能识别并设置。过程：先用了用户给的 N64 手柄图（两版，第二版在 L／R 下加了虚拟的 L2／R2、十字键四向各一个标签）；看了[原版按键分析](../gameplay/original-controls.md)后用户认为原版有用的键不多，改成**按功能**组织、用 Steam Deck 的布局（“就用 steamdeck 吧”），图照用户给的扁平风格（深灰底、白色按键形状、键名写在形状上）由我们自己画。同日用户又决定**不要图**（“感觉还是不要图了”）：手柄默认按 Steam Deck 设好，键盘默认照 PCSX2 的做法。定下来的做法：

- 改键后原生页面跟着新键走，Enter、Esc、方向键始终可用；
- 摇杆不单独改（用户：摇杆不需要），跟十字键一样是“移动”；
- 手柄默认值按功能重排，键盘默认用 PCSX2 的布局、与手柄同位置同功能（见下面「数据」）；
- 操作页只有功能表，不画手柄图。

## 数据

[`input_bindings.hpp`](../../src/host/input_bindings.hpp)（不依赖 SDL，键码与手柄编号照 SDL，`graphics.cpp` 里 `static_assert` 核对）：

- **动作**：N64 的 A、B、Z、START、L、R、C 四向、十字键四向、摇杆四向，加六个本作按键——设置窗口（视图键）、功能 1（L2：对白自动阅读开关、地图上一个敌人）、功能 2（R2：对白快进、地图下一个敌人、战斗中结束演出）、战斗动画开关（Y）、切换语言（L3）、原版／HD（R3）。
- **绑定**：每个动作一张键盘键列表（扫描码）和一张手柄输入列表（按键，或某个轴的一个方向，过 16000 算按下）。手柄默认值 2026-09-28 改成功能优先（用户看了[原版按键分析](../gameplay/original-controls.md)后定的方向）：A、B、START、LB/RB、十字键、左摇杆照原版；Z 在列表里只是 L 的别名、单独只剩 Z＋START 回标题，不再给键；X 按住是 C←（原版按住 C↓／C← 地图光标加速）；Y 切换战斗动画；按下左、右摇杆切换语言与原版／HD；右摇杆仍是 C 键（↑↓ 对白字号、标题曲目 ±10）；视图键与两个扳机归宿主。
- **键盘默认**（用户 2026-09-28：“PC/MAC 的默认键位用 PCSX2 的默认设置方式”）：PCSX2 的键盘自动映射（`pcsx2/Input/InputManager.cpp` 的 `GetKeyboardGenericBindingMapping`）给手柄的每个键一个键位，我们让每个键做手柄同位置键的事：

  | 手柄（Deck） | PCSX2 键 | 功能 |
  |---|---|---|
  | A（下） | K | 确定（A） |
  | B（右） | L | 取消（B） |
  | X（左） | J | 按住光标加速（C←） |
  | Y（上） | I | 战斗动画开关 |
  | 菜单 | Enter | START |
  | 视图 | Backspace | 设置窗口（另有固定的 Ctrl/Cmd + ,） |
  | L1／R1 | Q／E | L／R |
  | L2／R2 | 1／3 | 功能 1／功能 2 |
  | 按下左／右摇杆 | 2／4 | 切换语言／原版·HD（另有固定的 F7／F6） |
  | 十字键 | 方向键 | 十字键 |
  | 左摇杆 | W A S D | 摇杆 |
  | 右摇杆 | T F G H | C 键（F 也是 C←） |

  Z 和手柄一样不给键。改动前的键盘表（Z＝A、X＝B、空格＝Z、IJKL＝C…）留作 `classic_keys()`：调试接口的虚拟键固定按它算，原生页面的代码也用它的键名（见下）。
- **抢占**：把一个输入给某动作时，它替换该动作在这个设备上的全部输入；原来占着它的动作失去它，如果因此没键了，就拿到本动作原来的第一个键——等于互换，不会有键丢失。
- **存盘**：`input.json`（启动器放在用户目录，`SRW64_INPUT_SETTINGS`；开发运行放在 presentation 设置旁），只写与默认不同的动作，按 SDL 名字（`"Z"`、`"Return"`；`"a"`、`"leftshoulder"`、`"righty-"`）。读到不认识的名字就丢掉。
- **每帧**：`graphics.cpp` 按绑定算 N64 位和宿主位；调试接口按住的虚拟键不看绑定，固定按 `classic_keys()` 算，所以脚本里 `z` 仍是 A。读 L2/R2/视图键的三处（对白、敌方切换、设置入口）读合并后的状态，所以绑到键盘也能用。

## 提示与页面

- 提示词条的记号是动作（`{A}` `{Start}` `{L}` `{CUp}` `{DPad}` `{Settings}` `{AuxL}` …），显示当前绑定：手柄提示显示按键图标（按手柄家族），键盘提示显示键帽图标或键名（跟键盘布局）。组合记号在默认时显示一个整体图标。页面固定键 `{Enter}` `{Esc}` `{Tab}` 和方向键图标不随绑定变。见 [`button_prompts.hpp`](../../src/native/text/button_prompts.hpp)。
- 原生页面：页面代码按旧键盘表认键（Z 确定、X 取消…）。键盘事件进来时，绑到某 N64 键的键翻成该键在旧表里的键（A→Z、L→Q、十字键／摇杆→方向键…，`frontend.cpp` 的 `follow_bindings`）；Enter、Esc、Tab、方向键不翻；没绑任何功能的字母键在页面上不起作用（否则默认下 Z、X 仍会确定、取消）；绑到设置窗口的键开关设置窗口；绑到功能 1、2 的键在页面上不起作用。调试接口按的键没有窗口号，按旧表直接进页面。姓名页不再有输入框（名字固定），也跟随绑定。手柄经 `pad_keys` 已经按 N64 位走，天然跟随。
- 对白底栏提示在宿主拍帧快照时展开（`Frame.controls_text`），可移植的场景绘制不需要 SDL。

## 操作页

`frontend.cpp` 的 `controls_page`：

1. **识别到的手柄**：SDL 报告的手柄名，插上即识别（`SteamDeck=1` 时按 Deck）；没有手柄时写“未连接”。按键图标按手柄家族（Xbox／Deck／PlayStation／Nintendo）换。下一行说明键盘默认是 PCSX2 的布局。
2. **改键**：每个功能一行（`control_rows[]`：确定、取消、START、上一个、下一个、功能 1、功能 2、光标加速、字号放大、字号缩小、战斗动画、设置窗口、语言、原版／HD、十字键四向、Z），右边两列是键盘和手柄的当前绑定。选中一行，弹出“请按下给「…」的新按键”，下一个键盘键或手柄键（按键或把摇杆、扳机推到底）就绑给它，从哪个设备按的就改哪个设备。Esc 取消，6 秒没按也取消；F5–F8、F11、F12、Print Screen 被拒绝。手柄按下后要等全部松开，页面才重新接受手柄导航。
3. **固定快捷键**与**恢复默认按键**：Ctrl/Cmd + , 设置、F5 重载台词、F6 原版／HD、F7 语言、F11（或 Alt+Enter）全屏、F12 截图、Esc 退出，不可改。

原来的四组只读键位表（`settings_key_*`／`settings_bind_*`）由这张功能表代替，词条已删。曾有的 Steam Deck 手柄图（绘图脚本 draw_deck_diagram.py、图片目录 content/ui、`SRW64_UI_ASSETS` 与打包里的 ui 目录，见 8b7518d 及以前）随“不要图”一并删去。

## 测试

- `make recomp-input-bindings-test`：键盘默认是 PCSX2 布局且与手柄绑同样的功能、旧表、互换规则、存盘副本只在真变化时存。
