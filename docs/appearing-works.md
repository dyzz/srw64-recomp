# 出场作品整理

本清单把《超级机器人大战64》的作品来源分成三层，避免把本体参战、外部联动
和“只借用机体/情节”的作品混为一谈。机器可读版本见
`reference/appearing-works.csv`。

## 结论

- 授权作品共 **25 部**：本体直接可用 22 部，必须通过 Game Boy Color
  《スーパーロボット大戦リンクバトラー》联动加入 3 部。
- 另有 **Banpresto 原创**一类，包括四组可选原创主人公及其机体。
- 其中 **3 部是 SRW64 首次参战**：《机动战士高达 第08MS小队》、
  《大铁人 THE ANIMATION 地球静止之日》、《六神合体God Mars》。
- 另有 4 个补充来源只贡献部分机体、设计或情节，不应额外计作完整剧情参战。

这里的“25部”采用官方 SRW SEARCH 的作品口径，把《剧场版魔神系列》和
《真・盖塔机器人（原作漫画版）》分别计为作品。ROM 自己的作品分类只有 25 个，
原因是它把这两部并入魔神/盖塔系，同时额外设置了一个 `MSV` 分类；再加上原创，
最终仍是 25 个内部分类标签。两个数字相同，但口径并不相同。

## 原创系

ROM 内部作品标签为 `オリジナル`，对外通常写作 `バンプレストオリジナル`。
当前先把它作为一个作品来源处理；主人公路线、人物和机体的进一步术语表另行
拆分，不与授权作品数相加。

## 只提供部分元素的补充来源

- `Ζ-MSV`、`M-MSV`：提供部分机体，ROM 统一归到 `MSV` 分类。
- `新機動戦記ガンダムW Endless Waltz`：提供部分机体设计，ROM 归入高达W。
- `超獣機神ダンクーガ GOD BLESS DANCOUGA`：终盘采用部分情节，ROM 归入
  《断空我》。

这些条目用于术语和机体来源追踪，不另算“完整参战作品”。

## ROM 内部证据

日版 Rev 0 的 `t00_00060` 至 `t00_00084` 是连续的作品分类标签，共 25 条；
它们已由 `make inventory` 写入 `build/text-inventory/text-inventory.csv`。范围内
包含三部联动限定作品、`MSV` 和 `オリジナル`，证明相关数据确实存在于 ROM。

外部资料只用于解释参战口径和联动条件：官方
[SRW SEARCH](https://www.suparobo.jp/index.php/search) 将结果定义为作品参战游戏，
官方 [LINE UP](https://www.suparobo.jp/srw_lineup) 记录 SRW64 于 1999年10月29日
在 N64 发售；具体的首次参战、Link Battler 限定和补充元素由
[スーパーロボット大戦Wiki](https://srw.wiki.cre.jp/wiki/スーパーロボット大戦64)
与 [Akurasu 作品表](https://akurasu.net/wiki/Super_Robot_Wars/64/Series)
交叉核对。外部页面不是 ROM 解析输入。

简体中文名目前是汉化工程的工作术语，不宣称是版权方正式译名；后续建立角色、
机体和武器术语表时可以审校，但稳定 `id` 和日文原名不要随意改变。
