# SRW64 原始 3D 与模型替换分析

2026-09-10 更新：5600 的[原生 GPU 水滴替换](native-model-replacement.md)已完成女主开场到第一话战术地图的有界验证。现代浮点网格与 Metal 材质已接入场景绘制顺序，原游戏提供姿态和相机。

2026-09-09。对象为本仓库日版 Rev 0 ROM，以及当前 N64Recomp + RT64/Metal 原生宿主。战斗画面的基本结构明确为 **3D 背景 + 2D 机体精灵**。原作有可提取的立体几何，适合从剧情标记、战斗场景背景和舰船形状资源入手；普通战斗机体的 2D 演出需要按另一类工程处理。

## 原作哪些部分用了 3D

| 部分 | 当前证据与判断 | 模型替换的意义 |
| --- | --- | --- |
| 战斗背景 | 3D 背景，与 2D 机体精灵组合呈现。ROM 几何资源中可见地面、起伏面、竖立背景片和建筑形状。待确认的是每个背景 ID 对应的场景、相机和绘制调用 | 最值得扩大美术投入的方向，可逐场景替换地形、建筑、远景几何与材质，同时保留原机体精灵和战斗脚本 |
| 剧情世界地图 | 5604、5605 各有 70 个矩形面、140 条三角形绘制。所有用于绘制的顶点 Y 坐标均为 0；原图山脉主要属于纹理 | 可以替换承载地图的网格；增加真实山体属于在原平面基础上新增立体地形 |
| 剧情地图立体标记 | 5600 原版合计 16 条三角形绘制。已完成归属确认、菱形 8 → 96 面回放，并通过实验 ROM 实际开场运行到第一话战术地图 | 已验证原加载器、旋转、剧情位置变化和切场；下一步验证重入／存档恢复及更多场景 |
| 舰船／飞行器形状资源 | 5584–5597 中的多个资源已提取出明显具有舰体、翼面等结构的几何，部分附带平面部件。具体舰名、用途和出现镜头尚未绑定 | 原始网格存在，可以作为低模升级候选；先确认调用场景、尺度、姿态和各部件用途 |
| 部分背景层／效果候选 | 5598、5610 等是平面或多个平面部件；5599 等混合多个部件。没有完整解析动画和场景组织关系 | 平面本身也能进入 3D 渲染；需要结合纹理和时间序列区分背景、效果帧与实体部件 |
| 第一话战术棋盘 | 已查看地图 GPU 图片；所检查的 `female-map-audio-*` 最后任务快照以纹理矩形绘制为主，未出现顶点加载／三角形命令。建筑的立体观感不足以证明有可替换建筑模型 | 高清图块属于现有纹理流程；把棋盘城镇、森林立起来需要新增地图场景渲染。此结论限于已检查地图和任务 |
| 普通战斗机体、人物头像、UI | 制作人明确说明本作机器人本身采用 2D。已查看第一话大泰坦 3 战斗图片；不能把缩放和透视感当作骨骼模型证据 | 继续使用 2D 高清素材最直接；改成 3D 机体需要新建模型、动作和演出绑定，现有证据不支持把它描述成简单换模 |

制作人直接访谈：[电击在线，2022-02-11](https://dengekionline.com/articles/109826/)。访谈对背景使用“疑似 3D”措辞；本报告按“3D 背景 + 2D 机体精灵”明确工程分类，避免将该措辞理解为背景只有平面图片。3D 场景可以同时包含立体网格和带纹理的平面，各背景元素的具体组成仍需逐项绑定。本次没有据此推断全部武器特效的实现。

## 本次 ROM 静态勘测

输入 SHA-256：`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`。

- 扫描压缩资源表全部 **6,436** 个条目。
- 资源 **5584–6066** 共 **483** 个具有 `36340038` 头，与已有地图解析器识别的容器一致。
- 对这些容器内类型 0／5 的 **606** 个显示列表解析了顶点加载和三角形引用；全部到达结束命令，引用与范围检查通过。624 条 MoveWord 均为灯光颜色设置，不改变此次统计的顶点位置。
- 将每个容器已引用顶点的局部坐标合在一起检查：**182** 个共面，**301** 个非共面。多个不同平面拼接也可能非共面，不能据此称为 301 个封闭实体、301 个机体或 301 个已绑定场景模型。
- 解析器未解释场景层级、动画、条件裁剪和完整材质。5638 还含类型 8 描述符，本次不解释其作用。ROM 其他区域和运行时生成的几何也不在这个容器统计口径内。
- 5604／5605 的顶点位置集合、三角形条数与既有地图提取结果交叉一致。

诊断图根据提取的原始坐标绘制，未加载原贴图、材质、游戏相机或动画。英文形状标签属于候选分类，不是已确认的游戏资产名称。

## 运行时证据边界

初次分析复核的是磁盘上已有的任务／RDRAM 快照。随后针对 5600 完成了独立副本的 RT64/Metal 回放、单独隐藏、固定拓扑顶点变形及 96 面高模替换。2026-09-10 又将高模编译为独立 ROM 资源，使用原加载器完成从空 SRAM 开始、女性开场对话至第一话战术地图的 16,800 VI 实际运行。加载、旋转、剧情位置变化和切场均有任务／GPU 证据；完整路线与 N64 硬件未验证。详见 [本地资源页与验证记录](native-model-viewer.md)。

`build/recomp/gfx-probes/female-story-2/` 中，5604 完整解压内容匹配内存 `0x2BF9F0`，其显示列表入口 `0x2E4480` 被根任务调用；5600 完整内容匹配 `0x2BDE68`，入口 `0x2BF7D0` 被调用。地址仅属于这份快照，不能写成全场景固定地址。

`first-map-reload-2` 末尾快照还驻留 5729、5734、5878、5879、5974、5975；`first-map-turn5-reload-1` 驻留 5746、5747、5748、5920、5975。该时刻未观察到根任务调用它们的几何显示列表，因此它们只提供后续场景追踪线索，不能直接归为当前可见背景。

已查看的既有 GPU 图片：世界地图 `worldmap-runtime/live-v6/present-3540.png`、战术棋盘 `female-map-audio-1/present-6660.png`、战斗大泰坦 3 `first-map-reload-2/present-3780.png`。图像观察、静态几何、内存驻留和显示列表调用分别记录，不互相替代。

## 当前原生工程能做到哪里

现有 [`graphics.cpp`](../tools/recomp/native-host/graphics.cpp) 在 `send_dl()` 中接收原任务，并允许经 `display_copy` 修改后再提交 `processDisplayLists()`；这是研究局部几何替换的现成入口。现有字体、头像和世界地图高清化走 `loadReplacementDirectory()`，属于纹理替换。

固定使用的 RT64 为 `43373749dac9bbc1b653e6a02aed40a9e1783bed`。其 README 以及本次检查的[上游说明](https://github.com/rt64/rt64#features-in-development-in-priority-order)仍把 Model replacements 列为开发中。当前宿主没有 glTF／FBX／OBJ 换模包加载器，不能承诺把模型放进纹理包目录即可替换。

当前已完成的实验与后续工程：

1. **任务回放与 5600 实际开场已通过。** 菱形 8 → 96 面后沿用原位置、尺寸和虚线环，真实游戏对照帧的差异限定在菱形检查区。保留原显示列表入口，将新几何追加到资源内部并使用 segment 4 相对指针，原加载器负责资源内存；不把快照固定地址带进运行时。
2. **通用网格导入及更广覆盖仍需实现。** 当前为 5600 专用编译器，未建立 OBJ／glTF 导入与任意场景识别系统。其他资源仍要分别验证材质、透明、深度、裁剪、相机、容量和生命周期；5600 的再次进入与存档恢复也未验收。

ROM 直接换模仍受压缩容量、内存和旧显示列表约束。5600 实验以重定向资源表项到 ROM 空白池解决容量增长；这只证明该资源和本次流程可用。原生宿主也可另做资产与渲染接入，现有高清纹理功能不会自动提供通用几何替换。

## 推荐优先顺序

| 顺序 | 对象 | 选择理由与下一项验证 |
| --- | --- | --- |
| 1 | 5600 剧情标记 | 已完成 96 面实验 ROM 开场运行，验证旋转、位置变化及切场；后续补重入、存档恢复和更多路线 |
| 2 | 一种常见战斗背景 | 可见收益最高。捕获战斗中稳定帧，将地面、远景和建筑分别绑定到 ID，再做单场景样片 |
| 3 | 一艘已经绑定场景的舰船 | 已能提取网格；先补纹理和镜头归属，验证部件、朝向与移动，再扩大到其他舰船 |
| 4 | 剧情世界地图立体化 | 原版是平面，可以增加山体或地标；要保持海岸、地名／剧情标记位置和原镜头表现 |
| 后续独立方向 | 战术棋盘全 3D、战斗机体全 3D | 前者需要地图场景生成与选择／遮挡规则，后者需要动作与武器演出系统；工作范围显著大于已有几何的替换 |

当前建议为“原机体 2D 演出 + 更精细的场景几何 + 高清纹理”，先用标记验证技术，再以战斗背景验证画面收益。全路线资产命名和全部场景覆盖尚未完成，本报告给出的是已验证入口与候选范围。
