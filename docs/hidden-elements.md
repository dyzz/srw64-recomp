# 隐藏要素：脚本实现与攻略对照

2026-09-17。本文基于锁定的日版 Rev 0 `rom.z64` 做静态分析：从 `build/original-data/records/stage_events.jsonl` 的指令 IR 读出每个隐藏要素的判定位置、所用变量和入队效果，再与社区攻略 [Akurasu Wiki：Super Robot Wars/64/Secrets][wiki]（同日检索）逐项对照。**本轮没有运行游戏验证，也没有写回 ROM。** "一致"只表示脚本结构与攻略描述吻合；回合数、击坠时机这类细节仍需实机确认，这些条目在第 5 节单独列出。

攻略的说法只作为对照线索，不作为判定依据；二者冲突时，以脚本为准列出差异，不据此改动游戏规则。

> 关卡名按当前目录的解码结果书写，以便在数据浏览器中搜索。其中「銀河帝国軍先遣闘隊」「スウィートウォーター固衛戦」「アクシズの攻固」「月は地球だ!」「理想、抱えて」等疑为字形表错误（应为 艦隊／防衛／攻防／地獄／潰えて），另行修正。

## 1. 结论摘要

- 游戏没有专门的隐藏要素系统，所有条件都用脚本变量实现：200 个 2 位值（`8015E818`）。其中 0–54 段跨关卡保存，是隐藏要素的进度；100–114 与 128–139 由 `8009DE7C` 在每关开始时置 3，只在单关内使用。
- 攻略清单上的角色、机体类隐藏要素基本都能对应到一个专用进度变量（第 3 节）。其中 20 余项的写入点、判定和入队效果都能在脚本里找到，与攻略吻合（第 4 节）。
- 说服就是类型 9 事件：表头是 [说服者, 被说服者]，全部 71 个事件都能对上攻略里的说服组合。但"第 N 步要求先完成第 N−1 步"这类前置条件不在脚本里，由尚未追踪的 overlay 决定执行哪个说服事件（2.3 节）。
- 借助攻略对照，定下了两个悬而未决的名册字段：`+0x14` 是击坠数，`+5` 是等级（2.4 节）。
- 新游戏的变量初值很可能是 3，有两条独立链路支持（2.1 节）。
- 有 7 处与攻略存在出入（第 5 节），另有 7 项攻略未记载的条件、分歧或结果（第 6 节）。

## 2. 实现机制

### 2.1 变量

| 指令 | 作用 |
| --- | --- |
| `3E13 变量, 值` | 写入 |
| `3E0E` / `3E0F` | 加 1 / 减 1（模 4），用作计数器 |
| `3E03 变量, 值, 值2` / `3E02 变量, 值` | 等于 / 不等于时进入条件块 |

变量只有 2 位，所以一个隐藏要素的进度最多四档，常见用法是：`0`、`1`、`2` 表示进度，`3` 表示未开始或已失败。

**初值推断为 3**（静态推断，未经运行确认）：

- カーツ 计数器 `var20` 在每次被ブラッド击坠时加 1，加到 2 就被压回 1（见 4.1 节）。只有初值为 3，才恰好满足攻略所说的"击坠至少两次 → `var20==1`"（3→0→1→1…）。
- `var21==3` 表示从未满足カーツ条件，此时发放スーパーアースゲイン；这个值只能来自初值。
- OZ 路线不经过写 `var11` 的「梁山泊の戦い」，而 `ノイエ・ジール` 要求 `var11==0`，OZ 路线确实拿不到它，符合初值非 0。

### 2.3 说服事件（类型 9）

类型 9 在触发表里称"游戏指定索引触发"。本次对照确认它就是说服：全部 71 个事件的表头前两字都是 [说服者, 被说服者]，对白也正是说服场面。

常驻代码 `8009EC3C` 的逻辑是：`engine+0x992 ≠ −1` 且 `engine+0x9AA == 6` 时，以 `+0x992` 为事件槽号，把该槽状态置为 `0x2000` 并执行，然后把 `+0x992` 清回 −1；状态已是 `0x2000` 的槽不会再执行。`8009DE7C` 在进入关卡时把 `+0x992` 置为 −1。这说明：

- 每个说服事件每关最多执行一次；
- 由谁把槽号写进 `+0x992`（即玩家说服时选哪个事件、说服指令是否出现）不在常驻代码中，应当在战术 overlay 里，尚未追踪。

所以脚本里只能看到"每一步写进度"，看不到"下一步要求前一步"。例如「海と大地の狭間より」对カミーユ→フォウ有两个事件：`001A43F4` 只有对白，`001A4420` 写 `var2=2`。选择哪一个应当由 overlay 按当前进度决定。第 4 节标为"前置条件未见于脚本"的条目都属于这种情况。

### 2.4 名册字段

| 字段 | 结论 | 依据 |
| --- | --- | --- |
| `+0x14` | 击坠数 | `3E0D` 共 6 处，读取的是大作 ×2、マーベル ×2、ブラッド、豹馬；除豹马外的 5 处阈值（大作 20／30、マーベル 30／30、ブラッド 100）与攻略的击坠条件一致 |
| `+5` | 等级 | `3E06` 仅 2 处，都是比较 カミーユ 与 ジェリド，与攻略"卡缪等级 ≥ 杰里德"一致 |

证据强度是"代码结构 + 社区实测"相互印证，还没有运行验证。布局锁 `conditions` 中这两条的名称仍写作"名册[角色]+0x14／+5"，本轮未改。

### 2.5 入队、离队与换乘

- `3D5A 角色, 参数, 机体, 模式`（运行时已确认）：模式 500 为登记；小于 2000 时表示旧机体编号，即换乘；2000 移除驾驶员；4000 连同机体一起移除。机体 999 表示不配机体。
- `3D58 角色, 0`：把在场单位转为我方，用于当场加入，例如ガラリア、アイシャ、ヒルデ。
- `3D45 组`：部署配套记录组，隐藏单位常以增援形式登场，例如トッド、マシュマー／キャラ。

## 5. 与攻略的出入（需实机确认）

1. **OZ 路线銀鈴的判定时机**：`3E0B[30]` 位于トールギス破壊 的**开场**事件，也就是进入这一关时击坠数就要够，这一关里打出的击坠不算。攻略写的是"这一关结束前"。
2. **阈值的等号**：IA 的 `3E09[20]` 是 ≥ 20，攻略写"超过 20"；シルキー的 `3E0B[30]` 是 ≥ 30，并在第 2 回合我方阶段判定，所以第 1 回合打出的击坠也算，攻略写"本关开始前"。アイシャ的残存触发按布局锁是"敌方 ≤ 9／≤ 7"，攻略写"少于 9／7"。
3. **カーツ 的第二次击坠**：`var21=0` 只在分歧关的击破触发里写入，而且先计数再判断。所以在分歧关用ブラッド击坠カーツ是**必需**的，而且这一次计入"两次"。攻略写的是"本关之前两次"。另外，攻略总表说击坠 100 要在混沌の地球圏 结束前达成，但脚本在決着の時 里判定，与攻略的分项说明一致。
4. **トッド 与ガラリア**：トッド增援只检查 `var6==1`；`var4==0`（ガラリア）只出现在シルキー的条件里。攻略把"招到ガラリア"列为トッド的第一步，如果这一前置存在，只能在说服选择的 overlay 里（2.3 节）。
5. **エルリッヒ（IA）的第一步**：攻略说「理想潰えて」开场选第 2 项。脚本里这个三选写的是 `var8`，属于レラ支线（第 6 节），与 `var18` 没有任何直接关联。
6. **ガトー离队时机**：生と死の未来 结束时，若 `var43==0`（在前一关选择与ハマーン合作）则移除；決戦!皇帝ズールとの対決! 後 结束时的移除以"选择寄存器为第 2 项"为条件，但该结束事件自己没有选择肢，依赖的是先前选择留下的值。攻略写"选择合作会提前一关离队"，脚本读起来可能相反，需实机确认。
7. **エルリッヒ（OZ）不一定要走ロームフェラ侧**：トレーズ暗殺指令 中写 `var18=1` 的条件有两个分支：ロームフェラ侧（`var38==0`）要求在月は地球だ! 已说服（`var18==0`）；ムーンアタック侧（`var38==1`）没有前置。两个分支都要求敌方剩余 ≤ 13 时アーク在场，攻略没有提到这一点。
