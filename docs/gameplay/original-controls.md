# 原版按键绑定（静态分析）

2026-09-28。本文回答「游戏本体怎么读手柄、每个键在每个画面里做什么」。全部结论来自反汇编（`build/recomp/cpu-scan/<overlay>/*.text.s`）和 ROM 数据表，**没有实机验证**；已有实机记录的地方注明出处。宿主侧（键盘／手柄 → N64 掩码、重映射）不在本文范围，见 [Steam Deck 键位](../design/steam-deck-controls.md) 与 `src/host/input_bindings.hpp`。

扫描方法：找出全部读取输入表的指令（318 处），记下所在函数与之后测试的掩码，再按 overlay 与状态表归类；脚本在 `tools` 之外的会话临时目录里，没有提交。

## 1. 采样层（常驻段）

| 函数 | 作用 |
| --- | --- |
| `80087730` | 初始化：`osContInit` 得到连接掩码 `D_8010F6C0`，清空所有表，输入锁 `D_8010F6BA=0` |
| `8008163C` | 主循环每次调用：`80087A48` 对口 0 发起读取（`osContStartReadData`／`osContGetReadData` → `OSContPad D_800F97B0[4]`），`80087AA4` 把这次读到的键 **OR 进**累加字 `D_8010F1A4[口]`，摇杆折算的方向 OR 进 `D_8015F73C[口]`。只有到了游戏帧（`D_80172D0C ≥ D_8010F0C8`）才继续：`80087DD4` 算边沿，`80087C9C` 用当前值重新播种，`80081D60` 合成三张表 |
| `80087AA4` | 摇杆→方向：`|x|≥45` 给左右位、`|y|≥45` 给上下位；存的摇杆值只往外走，往回收就清零（棘轮），所以松杆不会抖 |
| `80087C9C` | 帧末重播种：阈值改用 ±50 |
| `80087DD4` | 每口：有效标志 `D_80178D24[口]`、输入锁为 0 时才算；`press = new & ~old` |
| `80081D60` | 合成：摇杆有方向时用摇杆的 `0xF00` 位**替换**十字键位；连发字见下 |

两次游戏帧之间的多次采样按 OR 累计，短按不会丢。

### 三张表（每口一个 u16，口 0 在最低地址）

| 表 | 含义 |
| --- | --- |
| `D_8015D9FA` / `D_8015CAF0` | 原始按住 / 原始边沿（不含摇杆） |
| `D_8010F124` / `D_8010F724` | 摇杆折算的方向 按住 / 边沿 |
| `D_800F97D0` **按住** | 原始按住，摇杆有方向时方向位换成摇杆 |
| `D_80178A08` **按下** | 同上的边沿版；绝大多数画面读它 |
| `D_801612E0` **连发** | 本帧有按下 → 连发＝按下，计数 12；否则计数到 0 且有按住 → 连发＝按住，计数 3。即首次延迟 12 帧、之后每 3 帧一次。**连发是整字**，不只方向键：读连发字的地方按住 A、L、R 也会连发（标题曲目、地图 L／R 切换都是） |

位：A `0x8000`、B `0x4000`、Z `0x2000`、START `0x1000`、上 `0x800`、下 `0x400`、左 `0x200`、右 `0x100`、L `0x20`、R `0x10`、C↑ `8`、C↓ `4`、C← `2`、C→ `1`。

- 游戏逻辑只读口 0（表首元素）；只有调试菜单的 `1p–4p ON/OFF` 和两个查看器按口循环。
- 场间 overlay 另有一份同算法的私有连发表 `D_801DD62C`／计数 `D_801DECE0`（`801C4538`，`801C4A20` 等读它）。
- 输入锁 `D_8010F6BA`：置 1 时四口全清零。`800A344C`（全屏闪白／淡入淡出，脚本 `3D3B` 一族）和战术 `801F2AAC` 置位，完成后清零。
- 对白推进 `8008D748` 读的是**原始边沿** `D_8015CAF0` 的 A，不经合成表。

## 5. 对重映射有用的结论

- **Z 在列表里就是 L 的别名**：所有「上一个」都测 `0x2020`，「下一个」测 `0x10`；Z 单独的用途只有 Z＋START 重置和 BTLINIT。给 Z 另配一个键不会丢功能。
- **C 键在正常流程里只有三处**：地图光标加速（C↓、C←）、标题曲目 ±10（C↑、C↓）、战斗里按住 C↑ 清一个标志。C→ 正常流程不用。
- **START 在正常流程里只有**：PRESS START、Z＋START、母舰 発進 项、战败提示的「任意键」。战斗动画开关走选项窗，不走 START（那个 START 切换是死代码）。
- **十字键与摇杆等价**，摇杆有方向时覆盖十字键位；斜向在地图光标表里有定义。
- **连发是整字**：把某键映射成「按住」会在读连发字的画面里连续触发（L／R 切单位、曲目切换）。
- 对白只认 A 的原始边沿，任何合成、快进都是宿主做的。
- 短按不会丢（帧间 OR 累计），但按键必须跨过一次游戏帧采样才被看见；注入按键时给一帧边沿即可（场间接管已这样做）。
