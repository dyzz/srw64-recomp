# 数值 MOD：格式与 ID 表

给 MOD 作者看，也可以把整个文件夹交给你的 AI 助手，让它照着表写配置。实现与原版机制在 [MOD 包](../../design/mod-packages.md) §5 末尾，包的通用规则在同一份文档 §2。

**现状（2026-10-26）**：能改的只有**机体和驾驶员的地形适应**，0.5.0 之后的下一个版本起生效。HP、装甲、武器等别的数值还没做，`data/` 里的其他文件会被忽略并在日志里报「暂不支持」。

## 1. 包的结构

```text
<包 id>/
  mod.json
  data/
    units.json      按机体号改机体
    pilots.json     按人物号改驾驶员
```

两个文件都可以只写一个。`mod.json` 的写法见 [MOD 包](../../design/mod-packages.md) §2；发布时把文件夹压成 zip，扩展名改成 `.srw64mod`，拖进游戏窗口就会安装。

## 2. 写法

```json
// data/units.json
{ "262": { "terrain": { "space": "A" } } }
// data/pilots.json
{ "196": { "terrain": { "space": "A", "sea": "A" } } }
```

- 键是编号，十进制、不补零：机体号 0–362（[units.csv](units.csv)），人物号 0–359（[pilots.csv](pilots.csv)）。
- `terrain` 里写要改的通道：`air`（空）、`land`（陸）、`sea`（海）、`space`（宇），值是 `A`、`B`、`C`、`D` 或 `-`。没写的通道保持原版。
- 规则很严：不认识的字段、通道或等级，编号超出范围，没有能力记录的人物，都算错。**一个文件有错就整份不用**，游戏日志里有一行 `SRW64_MOD_DATA_PROBLEM` 写明哪个包、哪个文件、什么原因。
- 几个包改了同一项时，MOD 管理列表上面的包优先。

## 3. 实战里怎么算

- **机体侧的适应是机体和驾驶员两个等级相加再分档**：A=4、B=3、C=2、D=1、-=0，和 0 是 `-`，1–3 是 D，4–5 是 C，6–7 是 B，**8 以上才是 A**。所以机体本身已经是 A 时，要改驾驶员才能让实战变成 A。例：ゴーショーグン（184）宇 A，真吾（133）宇 B，合起来 7，在宇宙只按 B 算。
- 倍率：A 120%、B 100%、C 80%、D 60%、- 0%。攻击力乘攻方的这个倍率，装甲乘守方的。
- 武器的地形适应只看武器自己，另乘一次。武器也有编号（0–1328），但现在还不能改。

## 4. 什么时候生效

- 装上、启用或停用包后不用重启。
- **读场间存档时，全部机体和驾驶员都从 ROM 重建**（机体实例按 ROM 记录重建，驾驶员按经验整套重算），所以旧存档读档就是新数值。
- 其他时候：机体在游戏下一次重算它的能力时更新（改造、换乘、装卸部件等都会重算），驾驶员在升级时更新。关卡里中途启停包、或者读关内的中断存档，要等这些时机才变（中断存档的情况还没实测），所以最好在关卡外启停。
- 图鉴显示改过的数值。

## 5. 共用能力记录

一部分人物共用同一条能力记录（多为同一人物的另一份编号，比如ドモン 4、273、274），改其中一个，共用的人一起变。[pilots.csv](pilots.csv) 的 `shares_record_with` 列出了共用者。

## 6. 表

| 文件 | 列 |
| --- | --- |
| [units.csv](units.csv) | `unit` 机体号，`name_ja`／`name_zh`／`name_en` 名字，`air`／`land`／`sea`／`space` 原版地形等级 |
| [pilots.csv](pilots.csv) | `pilot` 人物号，三语名字，`record` 能力记录号，`shares_record_with` 共用这条记录的人物号，四个地形等级 |

只列有能力记录的人物；副驾驶员、妖精也有记录，四项多是 `-`。同名的条目是不同的编号（形态、敌我版本、剧情专用），改之前对一下等级。

表由 `tools/content/export_data_tables.py` 从 ROM 生成，同时写官网的 ID 表数据（`web/src/data/data-mods.json`）。

## 7. 示例

仓库里的 [`config/recomp/mods/space-a`](../../../config/recomp/mods/space-a/)：把我方主力里宇宙不到 A 的 20 名驾驶员与 21 台机体的宇宙改成 A。
