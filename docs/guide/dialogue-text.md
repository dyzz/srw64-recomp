# 台词文本文件：格式、存放位置与修改方法

日期：2026-09-23。剧情对白、选择肢和战斗台词不写进语言目录 `content/locales/<locale>.json`，每种语言单独一套纯文本文件，玩家可以直接修改。名称、界面标签与系统提示仍走[词条表](../native/localization-terms.md)。

## 放在哪里

| 位置 | 用途 |
| --- | --- |
| `content/dialogue/<locale>/`（仓库）；应用包内 `Contents/Resources/dialogue/<locale>/` | 程序附带的译文。按剧情场景、战斗台词区段分文件，更新程序时整套替换 |
| 用户目录下的 `dialogue/<locale>/`（macOS 应用：`~/Library/Application Support/SRW64Recomp/dialogue/<locale>/`；开发试玩 `scripts/Play SRW64 Native.command`：`build/recomp/profile-play/dialogue/<locale>/`；调试会话：各自运行目录下的 `dialogue/`） | 玩家自己的修改。**逐条覆盖**附带译文，文件名和目录结构随意；更新程序不会动这里 |

`<locale>` 是 `zh-Hans`、`en` 或 `ja`（`ja` 目录用来改日文原文的显示，可选）。程序读取某语言的所有 `*.txt`：先读附带的，再读用户目录的；同一条台词以用户目录为准。

想改哪一句，就把附带文件里那一条（或整个场景文件）复制到用户目录再改。没改的条目不必复制，否则以后附带译文更新了，你的旧副本仍会盖住它。

## 格式

UTF-8 纯文本，一个文件放任意多条。示例：

```text
# 第一话「出撃！スイームルグ」
@17412 ローレンス
> お嬢様、お茶のご用意ができました。本日はロシアンティーでございます。
小姐，茶已经准备好了。今天是俄罗斯红茶。
---
> どちらにお持ちしましょう？
要送到哪里呢？

@17413 {HeroNick}
> ……ローレンス、お茶のことはいいわ。
……劳伦斯，茶的事就算了。

@18020 选择肢
> * 協力する
> * 断る
* 合作
* 拒绝
```

| 写法 | 含义 |
| --- | --- |
| `@17412 ローレンス` | 一条的开始。数字是文本表 0 的记录号；后面是备注（通常写说话人），程序不读 |
| `> …` | 日文原文，只作对照。程序会与 ROM 原文比对，对不上说明记录号写错了，这条不生效。可以删掉不写 |
| 其他行 | 译文。每行就是游戏里的一行，换行位置随意；太长的行由程序自动折行 |
| `---` | 翻页（原版按一次 A 才出现的下一页）。页数必须和原文一样 |
| `* …` | 选择肢的一个选项，一行一个，个数必须和原文一样 |
| `# …` | 注释 |
| 空行 | 无意义，可以随便加 |

动态姓名写成占位符，游戏里换成玩家起的名字：

| 占位符 | 内容 | 占位符 | 内容 |
| --- | --- | --- | --- |
| `{HeroNick}` | 主角昵称 | `{PartnerNick}` | 搭档昵称 |
| `{HeroName}` | 主角名字 | `{PartnerName}` | 搭档名字 |
| `{HeroSurname}` | 主角姓氏 | `{PartnerSurname}` | 搭档姓氏 |
| `{HeroFull}` | 主角全名 | `{PartnerFull}` | 搭档全名 |
| `{HeroMech}` | 主角机体名 | `{G:0104}` | 其他特殊字形（原样保留） |

一页里的占位符要和原文那一页用到的一样多、种类一样，顺序可以按译文语序调整。

要让某行译文以 `>`、`*`、`#`、`@`、`\` 开头或整行是 `---`，在前面加一个 `\`（例如 `\*`）。译文里不能出现半角 `<`，请用全角 `＜`。

## 生效、重新载入与错误

- 启动时读取。游戏中按 **F5**（或应用菜单「重新载入台词」）重新读取全部台词文件：当前这句从头按新文本显示，回看也换成新文本。
- 有错误的条目整条不生效，回退到下一层：用户目录 → 附带译文 → 日文原文，其他条目照常。每次读取后会在窗口顶部提示条数和错误数，并把明细写到用户目录的 `dialogue-report.txt`（文件名、行号、记录号、原因）。
- 常见错误：页数（`---`）和原文不一致；选项个数不一致；占位符拼错或少了；原文行（`>`）和记录号对不上；译文里有半角 `<`。
- 战斗台词只替换显示，原版的推进节奏不变。一页放不下时会自动缩小字号，不会分页，所以尽量简短。

## 附：给工具作者

- 读取实现：`src/srw64_native/dialogue_text.py`（Python，供生成与检查）与 `src/native/localization/dialogue_text.hpp`（游戏内）。两者规则一致，由 `tests/test_dialogue_text.py` 与 `tests/native_content.cpp` 共同约束；两者对同一批附带文件的展开结果逐条一致。
- 一条展开成语言目录形式：行之间 `<BR>`、页之间 `<STOP>`、占位符变成 `<G:0124>`–`<G:012C>`，末尾 `<END>`。原文里一个姓名占多格（同一字码重复）时，只写一个占位符；游戏内按一个姓名显示。
- 保留：`@intro:<资源号>` 是开场缩放文字的条目，现在只读取、不显示，不做 ROM 比对。
