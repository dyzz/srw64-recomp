# 한국어 용어집（韩文演示包的专名表）

韩文第一关演示包（`config/recomp/mods/lang.ko`）翻译时 8 个子代理共用的专名与系统用语表，2026-11-03。接着翻后面的关或另做韩文包时可以沿用、扩充；写法见同一文件夹的 [README](README.md) §3。

번역 원칙
- 원문은 일본어 ROM 텍스트(`ja`/`>` 줄)다. 영어(`en`)·중국어(`zh`)는 참고용 기존 번역이며, 의미는 원문을 기준으로 한다.
- 한국 정발 슈퍼로봇대전(OG, V, X, T, 30 등)과 한국 건담 정발 표기를 따른다. 모르는 고유명사는 일본어 발음을 표준 외래어 표기법으로 옮긴다.
- 존댓말/반말은 원문 캐릭터의 말투를 따른다(군인 보고체 "~입니다", 아크는 젊은 남자 반말, 크와트로는 침착한 존댓말·반말 혼용, 게릴라는 거친 말투).
- 문장부호: 큰따옴표 “ ”, 말줄임표 …… 또는 ..., 느낌표/물음표는 그대로. 반각 `<` 는 쓰지 않는다.
