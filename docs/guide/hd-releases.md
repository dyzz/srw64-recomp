# HD 包各版更新内容

HD 包有自己的版本号，内容变了才发新版（构建与安装见 [发布构建](release.md)）。这里按版本记下每一版相对上一版改了什么，写发布说明、博文和更新视频时照这里取。数字都是拿两版的美术清单 `content/art/stage1-hd.json` 绑定的包逐行比出来的，不是估算。

## 下一版（未锁定）

| 清单项 | HD 1.3 | 下一版 |
| --- | --- | --- |
| `backgrounds`（场间背景＋战斗天空与滚动背景） | `whole-v7`，114 张 | `whole-v8`，129 张 |
| `battle_sprites`（多一张战斗鉴赏「地球」场景缩略图） | `pack-v20` | `pack-v21` |

- 补齐 15 种战斗天空配色（`assets/hd-ai/battle-skies/missing-v1`，配方和其他天空相同）：地球 6068/6118、月球 6073/6126 这两张第二层远景，和 13 种已有 HD 图的换色版。图鉴目录按地面模型和第一层天空分组，看不到这些配色；`battle_sky_hd.py` 现在从 ROM 背景表取全部 106 种。

## HD 1.3（2026-11-04 锁定，未发布）

基准是 HD 1.2 发布时的提交 `36ba4a06`；美术清单比到 `8ae7d741`（`battle_sprites` pack-v20），之后清单没再动，只有模型包的韩文名牌又改过一次。清单里变了的只有五项：

| 清单项 | HD 1.2 | HD 1.3 |
| --- | --- | --- |
| `source`（地图图标等 RT64 贴图） | `worldmap-surfaces/pack-v12` | `pack-v15` |
| `battle_sprites`（战斗 cut-in、道具、特效） | `cutins/pack-v3`，739 行 | `pack-v20`，6880 行 |
| `units`（机体立绘） | `unit-poses/whole-v1`，332 张 | `whole-v2`，335 张 |
| `unit_extras`（机体额外图） | `unit-extras-derived/pack` | 同一目录，内容更新 |
| `backgrounds`（场间背景＋战斗滚动背景） | `backgrounds/whole-v4`，108 张 | `whole-v7`，114 张 |

另外模型包由 `tools/models/build_native_models.py` 在打包时生成，这一版多了韩文名牌。

### 发布前

- **要配 0.5.3**：完全相同的图共用一个文件以后，要靠新程序按每一行分别换色（`0f5adb70` 的 `native_sprite.cpp`）。0.5.2 只按文件名区分，几种换色会混成一种。所以 HD 1.3 和 0.5.3 从同一个提交一起打；发布说明的「配 Marchwind64 {version} 或更新」会自动写成 0.5.3。这一点是读代码得出的，没在 0.5.2 上实测。
- **几项改动在程序里，不在包里**：图标按阵营朝向、地面剪影阴影和空中阴影、能力页的 W 标记。这些是 0.5.3 本身的改动，装不装 HD 包都有，写发布说明时放在程序那边。
- **图片来源**（`tools/release/hd-release-notes.md` 与 `hd-notice.txt`）已按这一版补齐：Codex 的整张重画（7 张、东方不败、断空我身体与头像、大铁人表外帧）；本地放大模型从原版放大的战斗特效与滚动背景，属原版衍生；程序画的光束内部和着地阴影。
- 打包前先推送；`build_release.py` 从提交构建，HD 版本号自动加一。HD 1.3 用 `--version 0.5.3 --switch-hd` 打，输出在 `build/release/hd-1.3-<提交>`，程序版发布时用 `--switch-hd <那份 zip>` 照用。
