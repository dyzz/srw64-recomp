# 音乐与战斗语音 MOD：格式与对应表

给 MOD 作者看，也可以把整个文件夹交给你的 AI 助手，让它照着整理文件和写配置。设计与原版机制在 [音乐替换与战斗语音](../../design/audio-mods.md)，包的通用规则在 [MOD 包](../../design/mod-packages.md)。

**现状（2026-10-26）**：「按歌号替换音乐」和「按人物／机体改战斗曲」都已经实现，0.5.0 之后的下一个版本起生效。「战斗语音」只定了格式，程序还没做，现在放进包里不会生效。

**做音乐包最简单的办法是官网的网页工具**（[BGM MOD 制作](https://srw64.dreamquest.club/zh/mods/bgm/)）：拖入音频、设循环点和音量，直接导出 `.srw64mod`，下面的格式由它自动生成。玩家向的说明在官网技术文档的「MOD 指南」。

## 1. 包的结构

```text
<包 id>/
  mod.json
  audio/
    music/<歌号>.ogg              替换第 N 首（已实现）
    music.json                    可选：循环点、音量、曲名、改战斗曲
    voice/battle/<记录号>.ogg     某一句战斗台词的语音（未实现）
```

- 只放用得到的文件。音乐和语音可以放在一个包里，也可以分成两个包。
- 发布时把这个文件夹压成 zip，扩展名改成 `.srw64mod`。拖进游戏窗口就会安装。
- 音频一律用 **Ogg Vorbis**（`.ogg`），采样率任意，单声道、立体声都行。别的格式先转换，例如：`ffmpeg -i in.wav -c:a libvorbis -q:a 6 out.ogg`。
- 文件名里的数字都写十进制，不补零：`7.ogg`、`12772.ogg`。

`mod.json`：

```json
{
  "schema": "srw64.mod.v1",
  "id": "yourname.battle-voices",
  "version": "1.0.0",
  "name": { "ja": "…", "zh-Hans": "战斗语音", "en": "Battle Voices" },
  "description": { "zh-Hans": "…" },
  "authors": ["yourname"],
  "license": "CC-BY-NC-4.0",
  "game": ">=0.5"
}
```

- `id` 写成「作者.名字」的形式，发布后不要再改。
- `version` 写成「主.次.修」。
- `license` 只能填可以再分发的许可证：`CC-BY-4.0`、`CC-BY-SA-4.0`、`CC-BY-NC-4.0`、`CC-BY-NC-SA-4.0`、`MIT`、`GPL-3.0-or-later`、`CC0-1.0`。
- `mod.json` 里不认识的字段会报错，不要自己加字段。
- **版权**：歌曲和配音必须是你有权再分发的。我们不提供任何音频。

## 2. 音乐

一个 OGG 顶替原版一首歌，游戏里所有放这首歌的地方都会换掉。曲名和歌号对照见 [`songs.csv`](songs.csv)。

- 卡拉OK 例外，保留原曲，因为歌词节奏对不上。
- 同一首歌有多个包都替换时，MOD 管理页里排在上面的包生效。
- **想加一首新曲**：选一个不常用的歌号顶替，在 `music.json` 里写上曲名。音乐鉴赏里那一行会显示新曲名，并标 `MOD`。

`music.json`（整个文件可选；只放 OGG，就是整首循环、原音量、原曲名）：

```json
{
  "schema": "srw64.music.v1",
  "tracks": {
    "7":  { "loop": [441000, 5292000], "gain": -2.0,
            "title": { "ja": "…", "zh-Hans": "…", "en": "…" } },
    "38": { "loop": false }
  },
  "battle": {
    "pilot": { "36": 7 },
    "unit":  { "50": 12 }
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `tracks.<歌号>.loop` | `[起点, 终点]`，单位是**采样数**（不是秒）。终点之后跳回起点。写 `false` 表示只放一次。不写时，读文件里的 `LOOPSTART`／`LOOPLENGTH` 标签；标签也没有，就整首循环。 |
| `tracks.<歌号>.gain` | 音量修正，单位 dB，负数表示调小。 |
| `tracks.<歌号>.title` | 音乐鉴赏里显示的曲名，按语言写。 |
| `battle.pilot.<人物号>` | 这个人物在我方时，战斗放哪首歌（值是歌号）。人物号见 [`pilots.csv`](pilots.csv)。 |
| `battle.unit.<机体号>` | 交战双方都不是我方时，按攻方机体选曲。机体号见 [`units.csv`](units.csv)。 |

原版怎么选歌：

- **战斗曲**：只要交战有一方是我方，就放**我方主驾驶员**的人物曲，不论谁攻谁守；双方都不是我方时，放攻方的机体曲。
- **固定规则**：下面几种情况固定放某一首，而且优先于 `battle` 表：
  - ヴァル＝ア、アヴィ＝ルー、ジェイ＝レン 三人任一方在场；
  - ゴッドガンダム 的明鏡止水形态（H）；
  - シャッフル同盟 的 S 形态；
  - V-MAX 发动中。
- **战后不换回关卡曲**：战斗曲会一直放到下一个阶段开始，做循环时要考虑这一点。
- **敌增援 jingle**：歌号 38 默认只放一次，放完游戏自己换回关卡曲；写了 `"loop": true` 或循环区间就会循环。
- **关卡曲**：每个阶段开始都会重放。

## 3. 战斗语音（未实现）

- 每句战斗台词有一个**记录号**，语音文件名就是这个记录号。台词出现时放语音；同一侧下一句开始、战斗结束或中止演出时停止。
- 台词框按原版节奏翻页，不会等语音放完。所以每句语音最好控制在台词框显示的时间内，大约两三秒。具体时长还没测。
- 语音不分语言：玩家切换阅读语言时，放的都是同一个文件。
- 关掉战斗动画时没有台词，也就没有语音。

全部台词在 [`battle-voices.csv`](battle-voices.csv)，每行一句：

| 列 | 内容 |
| --- | --- |
| `record` | 记录号，也是文件名：`audio/voice/battle/<record>.ogg` |
| `speaker`、`speaker_ja/zh/en` | 说这句的人：人物号和名字。按这一列找配音演员 |
| `voice_part` | 这句属于哪个人物的台词表（声部号）。合体技对话里，别人的台词表也会引用你的人物，所以这一列和 `speaker` 不一定是同一个人 |
| `trigger` | 什么时候出现。例如「攻击（通用，3/14）」表示攻击时从 14 句里随机抽一句；「使用〈武器〉」表示用这件武器时说；「合体技〈…〉」表示多人对话中的一句 |
| `text_ja` | 原文（日语） |
| `text_zh`、`text_en` | 游戏里的中文、英文译文。多页的用 ` / ` 隔开 |

配音时要注意：

- **按随机池配全**。「通用，k/n」的 n 句是随机抽的，只配其中几句，就只有一部分时候有声音。一个人物配全通用台词的话，就是 `trigger` 里带「通用」的那些行。
- **合体技**是连续几条、几个人轮流说，每条各自是一个文件。
- `trigger` 写「原版不会显示」的 39 句，游戏里根本不会出现，不用配。
- 「旗舰被击坠」那几句（舰长台词）和普通台词的显示方式不同，能不能放语音要等实现时确认。
- [`pilots.csv`](pilots.csv) 的 `battle_lines` 列是每个人物共有多少句，可以用来估计工作量。

## 4. 对应表

| 文件 | 内容 |
| --- | --- |
| [`songs.csv`](songs.csv) | 49 首歌：`song` 歌号（也是文件名）、`sound_select_row` 音乐鉴赏里的第几行、`title_ja` 曲名、`karaoke` 卡拉OK 里有没有这首、`uses` 游戏在哪里放它（谁的战斗曲、多少张地图的关卡曲、固定用途）。`uses` 为空的歌只在剧情事件、标题、结局等地方放，没有逐一统计 |
| [`pilots.csv`](pilots.csv) | 361 个人物：`pilot` 人物号、名字、`battle_song` 原版战斗曲（-1 表示没有，停乐）、`voice_part` 声部号、`battle_lines` 战斗台词数 |
| [`units.csv`](units.csv) | 363 台机体：`unit` 机体号、名字、`battle_song` 双方都不是我方时的战斗曲 |
| [`battle-voices.csv`](battle-voices.csv) | 11548 句战斗台词，列的含义见 §3 |

- 这几张表由 `tools/content/export_audio_tables.py` 从 ROM 和文本导出生成，不要手改。
- 名字有重复的（同名的杂兵、剧情里的复制人物），按编号区分。

## 5. 交给 AI 时可以这样说

> 读 `docs/guide/audio-mods/README.md` 和同目录的 CSV。我手上有这些音频：……。请按 README 的格式整理出一个 MOD 包文件夹：文件改名成歌号或记录号、转换成 OGG、写好 `mod.json` 和需要的 `music.json`。不确定对应哪首歌或哪句台词的，列出来问我，不要猜。
