Mod 格式、宿主、托管与投稿

核查范围

2026-11-05。源码固定于 77705f8bb95ef7b7dca4675b149c4bcb6a48da34；读取公开登录入口、社区规范、目录 API，并对下载链接发 HEAD 请求。没有登录作者后台，没有上传，也没有执行外部插件。

包格式

统一 .dusk ZIP，根目录 mod.json；资源目录 res/，光盘文件或归档内部单文件覆盖 overlay/，哈希命名纹理 textures/。原生代码放 lib/<平台-架构>/mod.dll 或 mod.so；macOS 包同样使用 mod.so 文件名。Luau 设置 runtime=dev.twilitrealm.luau@1.0，入口 res/main.luau。Mod API 文档 · 打包规则

运行宿主

原生插件由操作系统动态链接到游戏进程，使用 C 服务接口，也能调用游戏函数、访问字段与 hook。服务按 major/minor 独立版本化，可选导入允许为空；Mod 自己也可提供服务。宿主管理 initialize/update/shutdown 和依赖顺序；重新加载服务提供者会重启依赖者。资源替换可能要切场景或重启才被游戏重新读取。原生插件没有进程隔离；Luau 仅开放指定服务，64 MiB 内存上限，普通回调 250 ms、生命周期调用 5 秒限制。动态库加载 · 加载与生命周期

网站和文件托管

客户端使用 https://twilitrealm.dev/api/v1/games/dusklight 下的目录、详情及 update-check API。详情返回下载 URL、大小、SHA-256、平台、原生代码标记、mod ABI 与服务导入。实查 dev.albt.albw 0.3.0 下载地址直接 HTTP 200 返回 5,450,009 字节附件，SHA-256 为 91cffa72a066569e481a284a549c90700adfd9d1dc8c52ca936188261aba8d98；没有跳转 GitHub。响应经过 Cloudflare，但不能据此确定对象存储是 R2、S3 或其他后端。目录客户端 · 实查 API

安装和更新

客户端以 HTTPS 下载，核验大小、SHA-256、包 ID 和版本；随后暂存并原子替换。更新检查上传平台、应用版本、ABI、服务清单与已装 Mod 状态，用于兼容选择。iOS/tvOS 禁止在线安装原生库，要求随 App 签名打包；包列出 ios-arm64 不等于能在 iOS 动态装入。下载校验 · 安装替换 · 平台限制

制作和发布

官方 mod-template 使用 CMake 与固定 Dusklight SDK 版本；GitHub Actions 编译 Windows、macOS、Linux 的两种架构、Android 和 iOS，再合并为单个跨平台 .dusk。推送 tag 会建立带合并包的 GitHub Release。网站另有 Discord/GitHub 登录入口，明确用于发布和管理 Mod。源码 PR、GitHub Release、网站收录是不同流程；没有证据说明推 tag 就自动收录到官网。官方模板 · 作者登录

投稿规则与尚未确认的部分

公开社区规范要求作品归属、无恶意内容等，并要求使用 AI 的作品适当标记；管理者可移除 Mod 或账号。未登录后台，因此上传文件还是导入 URL、必填字段、大小上限、首次审核和更新审核、自动验证方式均未确认。主程序 README 不接受主要由 AI 生成的源码贡献，这与社区 Mod 的 AI 标记规则不同。社区规范 · 主程序贡献规则

对 SRW64 的建议

近期继续保持数据包：可优先借鉴官网与客户端共用目录、版本化下载信息、SHA-256 校验、能力／平台过滤和作者投稿元数据。现有“只读在线索引、玩家自行下载”的决定不因本次调研自动改变。若确实需要轻量动态配置，可另评估受限脚本层；原生 DLL/SO 插件会额外承担 ABI、跨平台构建、崩溃和卸载状态的长期维护成本。
