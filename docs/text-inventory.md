# 全文本清单与工作量统计

`srw64-text-inventory` 对 W0 已验证的 20 张文本表做一次只读整理。它复用相同的
ROM 身份门禁和表结构，但统计结果独立写入 `build/text-inventory/`，不会修改 ROM。

## 生成

先准备与 `config/srw64-jp-rev0.json` 匹配的 `rom.z64`，以及 provenance 固定的
韩版参考仓库，然后执行：

```sh
make inventory
```

也可以直接使用安装后的命令：

```sh
.venv/bin/srw64-text-inventory \
  --rom rom.z64 \
  --baseline config/srw64-jp-rev0.json \
  --glyph-map "ref-project/SRW N64/reference/srw64_glyph_map_seed.csv" \
  --unknown-glyph-policy \
    "ref-project/SRW N64/reference/srw64_unknown_glyph_policy.csv" \
  --overlay translations/w1-slice.json \
  --work-dir build/text-inventory
```

生成命令会先核对 ROM、字形表、未知字形策略和 W1 overlay。任一普通字形无法
解析，或 overlay 的 key/token 不合法时，命令失败，不会报告 `passed`。

## 产物

- `text-inventory.csv`：51,174 条物理记录逐条列出。包含 table/text key、ROM
  偏移、8 字节头、长度、控制符、完整源文、重复组、W1 目标文和状态。
- `translation-catalog.csv`：按完整的 16 位单元序列去重后的 36,348 条目录。
  每组仍保留全部上下文 key；相同日文在不同位置可以采用不同译法。
- `summary.json`：机器可读的总量、20 表分布、长度、控制符、重复组、字形覆盖
  和 overlay 进度，并记录所有输入及两个 CSV 的 SHA-256。

源文使用显式 token：`<BR>` 是换行，`<STOP>` 是分段/停顿，`<END>` 是终止，
`<G:XXXX>` 是已登记但语义需要运行时确认的动态字形。不能删除或重排这些结构
token。`decoded_characters` 按 Unicode 字符计数；一个字形映射成多个字符时会全部
计入。`visible_glyph_cells` 则按 ROM 字形单元计数，更适合估算版面。

## 当前基线统计

数据来自日版 Rev 0，ROM SHA-256 为
`ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e`。

| 指标 | 全部记录 | 完全相同序列去重后 |
| --- | ---: | ---: |
| 记录/序列 | 51,174 | 36,348 |
| 可翻译记录/文本序列 | 51,006 | 36,209 |
| 可见字形单元 | 1,246,676 | 984,728 |
| 解码字符（含空格） | 1,236,861 | 976,403 |
| 解码非空白字符 | 1,186,583 | 934,673 |
| 空格 | 50,278 | 41,730 |
| 保留动态 token | 10,205 | 8,625 |

其余结构量：

- 文本 payload 共 3,091,672 字节、1,341,140 个 16 位单元；51,174 个描述符
  都指向独立物理记录，没有别名描述符。
- 控制符共有 51,174 个 `<END>`、29,562 个 `<BR>`、13,728 个 `<STOP>`。
- 51,006 条含普通文本；138 条只有动态 token；30 条只有空格；没有未登记字形。
- 可见长度中位数 17，P90 52，P95 68，P99 107，最大 225 个字形单元。
- 14,826 条是重复实例。28,812 个序列只出现一次；最大重复组是
  `「…………」<END>`，出现 402 次。
- 使用 1,963 个非空白字形 ID：1,935 个由字形表解码，28 个由 policy 显式保留
  为 token。普通文字出现次数覆盖率为 100%。
- W1 的 50 条 overlay 占 51,006 条候选记录的 0.098028%；按去重目录看，42 组
  已全部翻译、8 组部分翻译、36,159 组待翻译。

20 张表中，表 0 含 50,975 条记录，表 1–19 合计 199 条。当前没有足够证据给
这些表贴上“剧情”“菜单”等语义标签，因此目录只保留稳定的数值 table ID 和
结构分类。语义分类应在对应游戏画面或代码引用得到验证后另加字段。

## 统计口径与边界

“去重”只用于估算和组织，不会合并 ROM 记录。序列哈希覆盖包含控制符在内的
完整 big-endian u16 序列；只要换行、停顿或终止结构不同，就不是同一组。

这份清单证明的是 W0 定义的 20 张动态字形文本表已完整枚举，并不声称涵盖所有
屏幕可见文字。图像内嵌字、独立资源或程序绘制文本仍需资源扫描和运行时证据。
8 字节记录头目前也按原始数据保留，而不猜测字段语义。
